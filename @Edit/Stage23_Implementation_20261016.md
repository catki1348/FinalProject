## 외형 복원 정정

사용자의 기존 프리팹 외형 복원 지시를 반영했다. 초기 구현의 벽돌 띠 잘라내기 방식은 폐기했다. 원본 Platform_Stage2_Jungle 프리팹의 동일 텍스처에서 전체 불투명 블록(상단 식생·옆면·하단)을 보존하고, 투명 여백만 제거한 전용 Sprite를 사용한다. 원본 PNG/공용 프리팹/임포터는 수정하지 않았다. Sprite border로 양쪽 끝을 보존하며 가운데만 Tiled/Continuous로 반복한다. 깊이는 원본 비율 약1.357유닛으로 복원하고 그림 윗면이 기존 충돌체 윗면과 맞도록 pivot을 지정했다. 장식 하단은 충돌체 아래로 내려오지만 충돌 두께0.5는 유지한다.

21개 발판을 수정해 Stage2에 저장하고 다시 열어 좌표·충돌체 크기/offset·autoTiling=false·7개 이동형의 경로 참조/경유점/속도를 배치 데이터와 대조했다. 외형 변경으로 프리팹 컴포넌트 참조가 재생성되는 경로는 제거하고 이동형 설정을 재연결해 확인했다. 몬스터 배치와 경로는 변경하지 않았다. 임시 Test024에서 정면·후면·좌·우·상면을 확인했고 검사 이미지와 임시 씬을 삭제했다. 보고용 정면 미리보기는 Stage23_OriginalPrefab_Restored.png에 보존했다. 물리 배치와 운행값이 같아 전체124초 물리 검사를 다시 반복하지 않았다.
