## 거리·좌표

기본 속도8 기준 거리1=8유닛, **120×5=600유닛**이다. ★=(0,0), ○=(579.169,11.400). 상대 좌표의 Y는 발판 윗면이다. 정확한 좌표는 `MapDesign_Stage5-4.json`과 `MapDesign_Stage5-4_Placement.md`가 기준이다.

구간 연결 기준점 → 다음 발판 진입 중심 → 이동형의 진행 편도 경로 → 다음 기준점으로 측정한다. 연결 점프는 다음 구간에 포함하며 제외·중복하지 않는다. 질주는 연결 기준점에서 목표 마커까지 수평 거리다. 실제 점프 포물선·대기·전투 시간은 거리에서 제외한다. 거리75는 실플레이75초 보장이 아니다.

## 구간별 동작

**P1:** 최신 1-4 수정안을 기준으로 서로 직접 갈아타지 않는 리프트2개를 둔다. 각각 수직3, 속도3.2/3.6, 지연0/0.35초, 끝점1초 정지. 전투대 폭6에 지상 정찰1마리를 배치하고 경로는 중앙±1이다. 소멸 발판은 접촉0.9초 뒤 소멸,2초 뒤 복귀. 점멸은 켜짐2.4/꺼짐1.2초. 피해 발판은 안전2.4/활성1.6초, 피해8·첫 지연0.5·반복0.5초를 기준으로 한다. 기본 방어·무적을 적용한다.

**P2:** 원본25개 이동형을 전부 복사하지 않고 대표 이동형4개를 사용한다. 수평6, 수직4, 대각(6,-3), 편도(6,-2)이며 속도4.0/4.4/4.8/5.2, 지연0/0.35/0.7/1.05초다. 사이에 일반 안전대를 추가해 환승을 독립시킨다. 원본의 이동형만 사용하는 조건·25개 수량·Loop 분기는 이 압축 구간에 승계하지 않는다. 편도형은 **첫 탑승 후 지연을 계산해 출발**하고 도착 후 유지한다. 입장 시 멀리서 먼저 출발하면 진행 불가가 되므로 금지한다. `OnceOnBoard`는 설계 상태명이며 기존 MovingPlatform의 실제 enum이 아니다. 구현 시 별도 탑승 이벤트 제어가 필요하다.

**P3:** 상승8과 대각 하강(12,-6)을 일반 안전대로 연결한다. 화살 스위치2개는 안전대 중앙, 발사기는 오른쪽8·윗면+0.9에 두고 왼쪽으로 발사한다. 예고0.5초·속도14·수명2·쿨다운3·기본 피해15를 사용한다. 고공 안전대 바로 아래(윗면−4~−2.5)에 폭4의 낙하 복귀 센서를 두어 해당 안전대로 돌려보낸다. 정상 진행은 센서 위를 지나며 나머지 추락은 낙사다. 복귀는 적·아이템·기믹을 재생성하지 않는다. 안전대 위로 돌아오는 텔레포트는 이동속도와 발판 탑승 참조를 정리하고 카메라를 즉시 맞춘다.

**P4:** 안전대 접근 중 최대 가속5중첩을 부여하고 P4 종료까지 고정한다. 낙하형15개는 폭 약3.006, 틈1.8로 연결한다. 안전대 오른쪽 끝 통과를 t=0으로 하고 **첫 낙하t=3, 이후1초 간격, 마지막t=17**이다. 원본4-4의150개·1200유닛·첫 낙하1초·무틈 직선을 그대로 축소하지 않고, 점프 필수 수칙에 맞춰 틈을 추가하고 초기 여유를 늘린다. 비행 추적3마리를 낙하 코스25%·55%·80% 지점에 배치해 시계 시작 때 한 번 활성화한다. 처치·회피 중 어느 쪽으로도 통과할 수 있어야 한다.

**P5:** 1-4의 소멸·점멸·피해, 2-4의 이동형(8,2), 3-4의 화살1개, 4-4의 순차 낙하6개를 연속 연결한다. 질주 이전에는 안전대에서 기다릴 수 있고 낙하는 진행되지 않는다. 마지막 안전대에서 최대 가속을 다시 부여하고 오른쪽 끝 통과부터 첫 낙하3초·이후1초 간격으로 시작한다. 비행 추적3마리는 같은25%·55%·80% 비율이다. 마지막 낙하는8초. 마지막 종료 마커까지 속도10의 연속 이동 계산은 약6.532초이며 점프·전투 때문에 지연될 수 있다.

## 상태와 보상

최대 가속 고정은 P4와 P5 마지막 질주에만 적용한다. P4→P5에서는 P4 전용 고정을 해제한다. 일반 아이템 가속은 출처를 분리해 기존 타이머를 따른다. 4-4 전용 범위를 하드코딩한 기존 제어기를 복사만 해서 동작한다고 가정하지 않는다. 각 질주에 진입·시계 시작·이탈 참조를 명시적으로 연결하도록 확장한다. 5-3 분노는5-4 진입 전에 해제하며 5-4에서 분노를 새로 지급하지 않는다.

몬스터는 플레이어 크기의50%, 공격·방어 기본10, 비행종 중력0·Flying 전용 패턴이다. 일반 몬스터의 최신 드롭 규칙을 따르며 확정 분노·회복을 추가하지 않는다. 체력은 기본 장비1~2타 목표로 구현 시 실제 피해 계산에서 정한다. 함정은 아이템을 드롭하지 않는다.

사망·재시작 시 모든 낙하·시계·편도형·스위치·적·드롭·활성화 플래그를 초기화한다. 재진입 중복으로 시계가 다시 시작되지 않게 한다. 일시정지 시 시계와 물리를 함께 정지한다. 낮은 프레임에서는 경과한 모든 낙하 시각을 처리한다. 발판 낙하 시작 즉시 지지 충돌을 해제하며 잔해가 아래에서 다시 받치지 않게 한다.
