# 4-2 맵 설계 — 질주

상태: **2026-10-15 Unity 구현 완료**. 아래 설계 좌표는 시작점 기준 상대 좌표다. 실제 배치 시작 X=110, 종료 X=590이며 적용·검증 기록은 `Stage42_Implementation_20261015.md`를 참조한다.
사용자 지정: 거리 60, 전 구간 일직선 대미지 발판, 0.5초마다 피해 1, 거리 10마다 공중 추격형 10마리, 각 몬스터가 회복과 가속을 모두 확정 드롭.

## 1. 플레이 흐름

★ 진입 → 지속 피해를 받으며 전진 → 저공으로 접근하는 몬스터를 이동 공격으로 처치 → 사망 위치의 회복·가속을 함께 획득 → 가속 중첩을 유지하며 다음 무리를 돌파 → ○ 종료.

몬스터 전멸은 종료 조건이 아니다. 종료점 도착으로 4-3으로 이동한다. 강제 대기·문 잠금·추가 함정·중간 안전 발판은 두지 않는다. 몬스터는 함정 소환물이 아닌 구간 전용 일반 배치 몬스터로 취급한다.

## 2. 지형과 거리

기존 MapEdit 기준 **거리 1 = 기본 이동속도 8로 1초간 이동하는 8유닛**이다. 가속을 먹어도 설계 거리의 척도는 바꾸지 않는다.

| 항목 | 설계값 |
|---|---|
| 시작 / 종료 | ★(0, 0) / ○(480, 0), 발판 윗면 기준 |
| 실제 진행 거리 | 480유닛 = 설계 거리 60 |
| 바닥 | `Damage_4-2_Runway` 하나, x=-4~484, 윗면 y=0, 두께 1 |
| 발판 중심 / 크기 | (240, -0.5) / (488, 1) |
| 양 끝 여유 | 각각 4유닛, 진행 거리에는 포함하지 않음. 여유 부분도 대미지 발판 |
| 높이 변화 / 단절 | 없음 / 없음 |
| 영역 외곽 제안 | x=-8~488, y=-8~12. 시작·종료 트리거와 비행 동선을 포함 |

거리 10의 표시는 바닥 무늬·배경 표식으로 구분한다. 콜라이더나 발판을 6개로 나누지 않는다(MapEdit 규칙 13). Scale=(1,1,1), SpriteRenderer Tiled/Continuous, size=(488,1), BoxCollider2D autoTiling=false, size=(488,1), offset=(0,0) 기준이다. Stage4 전용 피해 발판 프리팹 변형을 사용하고 원본 공용 발판 수치는 변경하지 않는다.

실제 배치에서는 4-1 오른쪽에 영역 전체를 평행 이동하여 배치한다. 기존 4-3·4-4와 겹치면 함께 위치를 조정하며 5영역은 기존 하단 중앙 규칙을 유지한다. 현재 문서는 실제 씬 겹침 검증을 수행한 결과가 아니다.

## 3. 바닥 피해 — 반드시 실제 체력 1 / 0.5초

- 안전 주기 없음(`safeDuration=0`). 접지 상태 누적 0.5초마다 실제 체력 1 감소, 기본 초당 피해 2.
- 진입 즉시 추가 피해는 없고 첫 피해는 접지 누적 0.5초 시점이다.
- 공중에서는 누적을 일시 정지하고, 재착지 시 남은 시간을 이어간다. 짧은 점프·접촉 흔들림으로 타이머를 초기화하여 피해를 무한 회피할 수 없게 한다. 재시작·영역 이탈 때 초기화한다.
- 바닥 지속 피해는 방어력·일반 피격 무적·방어 동작과 분리한다. 일반 피격 무적을 새로 만들거나 연장하지 않고, 기존 몬스터 피해의 무적도 취소하지 않는다. 바닥 피해로 넉백·공격 취소를 발생시키지 않는다.
- 일반 체력이 소진되면 기존 무장해제/게임오버 전환을 그대로 사용한다. 체력 UI·사망 이벤트도 기존 경로로 통지한다.

**현재 코드와 차이:** `DamageFoothold`는 이탈 시 exposure를 초기화하며 `IDamageable.TakeDamage`를 호출한다. `PlayerHealth` 기본 무적은 1초이므로 필드만 1/0.5로 바꾸면 요구한 실제 체력 감소를 보장하지 못한다. 구현 시 바닥 전용 피해 진입점과 구간별 접지 누적 상태가 필요하다. 공용 무적 시간을 0으로 낮추는 방식은 쓰지 않는다.

## 4. 몬스터 60마리 배치

‘거리 10마다 10마리’는 **전체 60을 10씩 6구간으로 나누고 각 구간에 10마리**로 해석한다. 종료점에 별도 7번째 무리는 만들지 않는다.

| 무리 | 설계 거리 | 월드 상대 X 범위 | 10마리의 X 좌표 |
|---|---|---|---|
| G01 | 0~10 | 0~80 | 8,14,20,26,32,38,44,50,56,62 |
| G02 | 10~20 | 80~160 | 88,94,100,106,112,118,124,130,136,142 |
| G03 | 20~30 | 160~240 | 168,174,180,186,192,198,204,210,216,222 |
| G04 | 30~40 | 240~320 | 248,254,260,266,272,278,284,290,296,302 |
| G05 | 40~50 | 320~400 | 328,334,340,346,352,358,364,370,376,382 |
| G06 | 50~60 | 400~480 | 408,414,420,426,432,438,444,450,456,462 |

모두 `FlyingChasePattern`, gravityScale=0. 크기는 플레이어의 약 50%로 맞추고 중심 Y는 2.2 / 3.0을 번갈아 쓴다. 기본 원형 대기 반경 0.35, 각속도 60도/초, 감지 크기 (24,10), 추격속도 9유닛/초를 초안으로 제안한다. 공격력·방어력은 기본 10을 유지한다. 체력은 **기준 장비의 일반 공격 2회 처치**를 목표로 하며, `2 × max(1, 기준 1타 공격력 - 10)`으로 산출한다. 기준 공격력이 미확정이므로 체력 절대값을 임의 확정하지 않는다.

스폰은 공중이지만 플레이어를 향해 내려와 달리는 상태의 공격 범위에 진입해야 한다. 적 중심이 바닥에 파묻히지 않도록 추격 높이 하한을 몬스터 콜라이더 반높이+0.1로 제한하는 전용 설정을 제안한다. 기존 패턴에는 이 하한이 없으므로 별도 구현 항목이다. 실제 공격 판정 높이·공격 주기·동시 타격 수에 따라 Y와 체력을 조정한다.

G01만 진입 시 활성화하고 이후는 플레이어가 각 80유닛 구간 시작선을 통과할 때 한 번 활성화한다. 무리는 한 지점에 겹쳐 생성하지 않고 위 좌표에 미리 배치한다. 이전 구간의 생존 적은 유지하되 다음 무리는 미리 추격하지 않는다. 재진입으로 추가 생성하지 않고 사망한 적은 해당 시도에서 재생성하지 않는다. 감지 범위는 현재 코드처럼 스폰 중심에 고정되므로 영역 전체 추격으로 오인하지 않는다. 추격 해제 이후 복귀 이동이 순간이동하지 않는지도 적용 시 확인한다.

## 5. 처치 보상

| 보상 | 매 몬스터 드롭 | 효과 |
|---|---|---|
| 소형 체력 회복 | 100%, 1개, 체력 조건 없음 | +20, 현재 상태 최대 체력 초과 불가 |
| 가속 | 100%, 1개, 체력 조건 없음 | 1중첩당 +5%, 최대 5중첩, 5초 공유 타이머 갱신 |

두 항목 모두 `Always`, `chance=1`, `lowHealthMultiplier=1`로 명시한다. 회복 또는 가속 중 하나를 뽑는 방식이 아니라 **한 마리 처치마다 둘 다** 드롭한다. 전부 처치하면 각각 60개, 총 120개 생성이다. 저체력 보정·일반 회복 확률 10%는 이 구간 전용 몬스터의 확정 회복 항목에 적용하지 않는다. 별도 보상 추가는 현 설계에 포함하지 않는다.

드롭은 기존 원칙대로 **사망 위치 그대로** 생성한다. 바닥으로 이동시키거나 자동 획득시키지 않는다. 추격 높이와 이동 공격 범위를 조율해 달리는 중 몸이 두 아이템에 닿아 획득하게 한다. 제자리 호버링, 가속 수명 12초, 회복 수명 20초를 사용한다.

기존 필드 상한은 전체 20개다. 한 무리 10마리를 동시에 잡으면 두 종류 합계 20개이므로 이전 무리의 잔여 아이템이 있으면 오래된 것부터 소멸할 수 있다. **확정 드롭은 확정 획득을 뜻하지 않는다.** 순차 처치·즉시 획득을 기본 흐름으로 삼고, 상한을 임의 상향하지 않는다.

## 6. 질주 리듬과 수치 검토

| 조건 | 속도 | 이동만 걸리는 시간 | 계속 접지했을 때 바닥 피해 상한 |
|---|---|---|---|
| 가속 없음 | 8 | 60초 | 120 |
| 처음부터 최대 가속 유지(이론 하한) | 10 | 48초 | 96 |

실제 시간은 초기 중첩·공격 중 감속·아이템 수집·피격에 따라 길어진다. 목표 플레이 시간은 **55~75초의 초안**으로 두고 실측 후 확정한다. 공격 중 이동이 멈추는 캐릭터라면 목표를 충족하는지 먼저 확인한다.

같은 무리의 좌표 간격은 6유닛으로, 이동만 기준 처치 기회 간격은 기본 0.75초 / 최대 가속 0.6초다. 이전 무리의 마지막 좌표에서 다음 무리 첫 좌표까지 26유닛이므로 3.25초 / 2.6초다. 모두 가속 유지 5초보다 짧아 연속 처치 시 중첩 유지가 가능한 배치다. 이는 적 이동과 전투 시간을 제외한 **좌표상 검토**이며 실제 처치 간격 보장은 아니다.

바닥 피해만 보면 회복 1개(+20)가 접지 10초분이다. 무가속 한 구간의 바닥 피해도 20이므로 구간당 1개 획득으로 상쇄할 수 있다. 전부 먹으면 총 잠재 회복량은 1200이나 최대 체력 제한으로 상당량이 버려진다. 따라서 **10마리 모두 처치가 생존에 필수인 설계는 아니다.** 사용자가 지정한 피해 1/0.5초와 기존 회복 +20을 유지하며, 지속 처치의 이득은 회복 기회의 안정성과 가속 유지에 둔다. 더 강한 처치 강제를 원한다면 별도 지시로 회복량·몬스터 압박을 재설계한다.

## 7. 적용 시 구현·검증 목록

1. 기존 Stage4 피해 발판/비행종/아이템 프리팹을 확인하고 구간 전용 변형으로 설정한다. 반복 에셋을 새 장면 오브젝트만으로 대체하지 않는다.
2. 구간 Manager는 진입·6개 활성화선·종료·재시작만 관리한다. 피해 누적, 비행 패턴, 드롭, 아이템 효과는 각각 별도 책임을 유지한다. 이벤트/Inspector 연결을 사용하고 GameObject.Find는 쓰지 않는다.
3. 임시 Test 씬에서 5초 접지 시 실제 체력 -10을 확인한다. 방어·몬스터 피격 무적·접촉 흔들림·점프 후 재착지에서도 명세를 확인한다.
4. 60마리/무리당 10마리, 활성화 중복 없음, 몬스터마다 회복+가속 각 1개 생성, 저체력 여부와 무관한 드롭을 검증한다. 아이템 상한과 생성 확률은 구분한다.
5. 기본 장비 이동 공격으로 2타 처치, 공중 아이템 획득 가능, 가속 최대 5중첩/재획득 5초 갱신을 실측한다. 첫 조우·무리 사이·마지막 18유닛의 가속 유지도 확인한다.
6. 바닥 피해가 몬스터 공격 무적을 제공하지 않는지, 동시에 처치·회복·사망할 때 기존 체력 전환이 안전한지 확인한다.
7. 4-1/4-3 연결, 최대 속도에서 종료 트리거 누락 없음, 영역 비중첩, 발판 Tiled와 콜라이더 일치, 과도한 파티클 생성 여부를 확인한다. 폭 488에 기본 밀도 14를 그대로 적용하면 초당 6832개이므로 화면 인근 방출 방식으로 조정한다.

## 8. 설계 산출물과 검증 범위
