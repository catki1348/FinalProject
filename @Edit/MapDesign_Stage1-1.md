# 1-1 — 이중 레인 가속 러시 (재설계안)

2026-10-14. 테마 기준(스피디 플랫포머, 영역 1~2분 이내, 대기 요소 없음, 가속 버프 중심)으로 검토한 뒤 재설계한다.
**설계 단계이며 Unity에는 적용하지 않았다**(MapEdit.md 규칙 1). 적용은 사용자 요청 시 진행한다.

## 1. 검토에서 나온 보완점 → 재설계 대응

| # | 보완점(기존 1-1) | 재설계 대응 |
|---|---|---|
| 1 | 약 40유닛(주행 약 5초)이라 가속 버프를 쓸 구간이 없음 | 길이 196유닛(=설계 길이 24.5)으로 확장. 버프 5초 × 중첩을 연속으로 활용 가능 |
| 2 | 평지·구멍·단차뿐이라 현란한 이동 경로가 없음 | 지상 레인 + 상단 점프 체인 이중 레인. 상단은 점프를 이어 가는 연쇄 구간 |
| 3 | 가속 드랍 연결 불확실, 버프 보상 구조 없음 | 상단 레인에 몬스터 5마리를 연속 배치해 중첩 5단계(+25%)를 채우는 구조. 마무리 구간이 버프를 쓰는 직선 |
| 4 | 문서 범위(0~54)와 실제(약 0~40.5) 불일치 | 이 문서를 1-1 기준으로 하고 범위를 0~196으로 갱신 |
| 5 | 직선 지형이 타일 조각 수십 개 | 규칙 13에 맞춰 지상 레인을 발판 1개로 통합(Tiled) |

## 2. 기준 수치 (Player_Warrior 프리팹)

- 이동 속도 8, 점프 상승 속도 9, 중력 29.43(스케일 3 × 9.81).
- 점프 100%: 높이 약 1.38, 체공 약 0.61초, 수평 도달 약 4.9.
- 점프 80%(규칙 14 기준): 높이 약 0.88, 체공 약 0.49초, 수평 도달 약 3.9.
- 가속 +5%/중첩(최대 5) 시 수평 도달이 +25%까지 늘어난다(ItemDropDesign.md).
- 규칙 14: 일반 틈은 80% 점프로 닿아야 하므로 **틈 ≤ 3.9, 단차 상승 ≤ 0.8**. 틈 최소 3.4로 걸어서 건널 수 없게 한다.
- 규칙 15: 설계 길이 1 = 플레이어 1초 이동 = 8유닛.

## 3. 구성 (좌표: 월드 유닛, 시작 발판 윗면 (0,0) 기준)

### 지상 레인 (안전 경로, 점프 부담 적음)

| 발판 | X 범위 | 윗면 Y | 비고 |
|---|---|---:|---|
| G (지상 전체) | 0 → 196 | 0 | **하나의 긴 발판**, Tiled, 구멍 없음 |
| H1 단차 블록 | 128 → 132 | +0.8 | 점프 1회 필요 |
| H2 단차 블록 | 150 → 154 | +0.8 | |
| H3 종점 단차 | 176 → 180 | +0.8 | |

- 시작 `ZoneStartPoint` (2, +1.2), 종점 `ZoneEndPoint` (192, +1.2).
- 지상 레인에 낙사 구멍은 없다. 틈이 없어 상단에서 떨어져도 사망/대기 없이 이어진다.

### 상단 레인 (가속 보상 경로, 점프 체인)

진입: 단차 블록 ST1(x 30→32.4, 높이 0.8) → ST2(33.4→35.8, 1.6) → ST3 = U1 기둥(36.8, 2.4). 각 단 상승 0.8로 80% 점프에 닿는다.

|---|---|---:|---:|---:|---|
| U1 | 36.8 → 46.0 | 9.2 | 2.4 | - | Monster_1-1_Random_2 |
| U2 | 49.4 → 60.0 | 10.6 | 2.4 | 3.4 | Monster_1-1_Chase_1 |
| U3 | 63.6 → 73.0 | 9.4 | 2.4 | 3.6 | Monster_1-1_Random_3 |
| U4 | 76.4 → 88.0 | 11.6 | 2.4 | 3.4 | Monster_1-1_Random_4 |

- 틈 5개(3.4~3.6)는 모두 80% 점프로 도달 가능하고 걸어서는 건널 수 없다.

- 상단 발판 아래 여유 높이는 1.4다. 지상 레인 주행과 겹치지 않도록 상단 구간(x 36~116)에는 지상 단차 블록을 두지 않는다.

## 4. 속도 흐름

1. 0~28 시동: 평지 + 몬스터 1마리로 첫 가속 드랍을 받는다.
2. 30~116 러시: 상단을 선택하면 몬스터 5마리를 연속으로 쓰러뜨려 중첩 5단계에 도달. 지상을 선택하면 단순 주행.
3. 116~196 마무리: 구멍 없는 직선 + 낮은 단차 3개. 쌓인 버프로 가속 상태를 유지한 채 돌파한다.

## 5. 통과 시간 추정 (이동 속도 8 기준, 미검증 추정치)

- 순수 주행 196 ÷ 8 ≈ 24.5초.
- 점프·몬스터 처치 지연 합계 약 10~15초.
- 예상 **약 35~45초**(버프 활용 시 더 짧음). 상한 1~2분 이내, 대기 요소 없음(이동형 발판·타이머 문·스위치 미사용).

## 6. 구현·검증 시 확인할 항목

1. 1-1 몬스터 11마리가 가속 아이템을 100% 드랍하도록 연결되는지 확인(ItemDropDesign.md 기준 설정 여부).
2. 상단 발판 아래 여유 높이 1.4에서 플레이어 콜라이더 높이와 충돌하지 않는지 확인. 충돌하면 상단 Y를 3.2로 올리고 진입 단차를 4단으로 늘린다.
3. 틈 3.4~3.6이 80% 점프(수평 약 3.9)로 도달 가능한지 시뮬레이션 검수(플레이어 폭 포함).
4. 상단 몬스터가 발판 폭 안에서 순찰하고 낙하하지 않는지 확인.
5. Tiled 설정(Scale 1, drawMode Tiled, 콜라이더 size/offset 명시)을 적용하고 저장 후 재검증.
6. 적용 시 `Section_1`의 `Boundary_1_2`를 영역 폭 196에 맞춰 이동하고, 이후 영역(1-2~1-4)과 겹치지 않게 위치를 조정(규칙 12, 16).
7. 카메라 범위(`CameraBounds_1-1`, `ZoneBackground_1-1`)를 새 폭에 맞춰 갱신.
