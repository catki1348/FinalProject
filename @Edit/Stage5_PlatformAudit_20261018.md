## 2. 위반·미흡 상세

### 2-2. 규칙 20·21 — 5-1 `P29_R-M1 → P41_F-L0`

## 3. 해석이 필요한 항목

1. **규칙 13**: 같은 높이로 맞닿은 정적 발판 4쌍 — `S4_Runway`(피해 바닥) ↔ `S3_K`·`S4_K`, `S5F4_Runway` ↔ `S5F3_K`·`S5_K`. 종류가 달라 나눈 것으로, 이전 5-2 검수(`Stage52_Audit_20261016.md` §3)와 같은 판단 대상이다.
2. **외형 두께 ≠ 콜라이더 두께**: 227개 전부 외형 0.785 / 콜라이더 0.5(프리팹 공통). 길이 조절 기준의 “콜라이더는 설계 두께·표면 높이 유지”와 충돌하는지는 설계 의도에 달렸다(외형이 위·아래로 0.1425씩 더 두껍다). 위반으로 세지 않았다.
3. 5-3 `P3_Special2`는 폭 4, 나머지 이동형은 폭 2~3으로 다르다(규칙 위반 아님, 참고).

## 4. 방법과 한계

- 파싱: 장면의 프리팹 인스턴스와 변형 프리팹(Prefab Variant, 상속 오브젝트 ID = 베이스 ID ⊕ 변형 PrefabInstance ID)을 풀어 위치·크기·이동 설정을 복원했다. 이동형 50개 전부 경로·속도·지연·끝점 대기를 읽었다.
- 이동 모델: `MovingPlatform.FixedUpdate`와 `MoveSynchronizedCycle`을 복제(0.02초 간격 400초). 탑승 시 출발(`startOnFirstBoard`)은 탑승 전 정지로, Once 이동형은 탑승 전/도착 후 두 노드로 평가했다.
- 점프 기준: 상승 속도 9√0.8(높이 80%), 중력 9.81×3, 좌우 8, 목표 가장자리 안쪽 0.15. 이전 5-2 검수의 모델과 같은 값이다.
- **한계**: 위 점프 판정은 계산식이며 실제 물리·입력 시험이 아니다(5-2 수정 때 한 62쌍 실제 착지 같은 검사는 하지 않았다). 경로 접근은 발판 간 가장자리 간격과 높이 차만 보고, 점프 궤적이 다른 발판·몬스터·추락 띠에 막히는 경우는 포함하지 않았다. 피해/점멸/소멸/낙하 발판의 상태 변화, 몬스터, 5-5 보스존 바닥은 이번 범위가 아니다. 대기는 모든 입력 상황의 보장값이 아니다.
- 검수 스크립트는 임시 작업 폴더에서만 사용했고 프로젝트에는 추가하지 않았다.
