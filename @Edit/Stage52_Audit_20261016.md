# 5-2 점검 — S1_B5 진행 불가와 수칙·설계 대조

요청: “S1_B5 발판에서 다음으로 진행이 불가하다. 5-2의 수칙 위반 및 설계와 다른 부분을 확인하라.”

## 2. S1_B5 (P1 1-2 방식의 5번째 이동형)

씬 값(설계와 동일, X는 월드 좌표): B4 `(541.62,-41.32) ↔ (551.52,-31.42)` 속도 3 / 지연 6.39, B5 `(541.81,-50.38) ↔ (541.81,-38.38)` 속도 5 / 지연 5.53, C1 `(553.33,-56.19)` 폭 3.2.

1. **B4의 왼쪽 끝이 B5의 승강 경로 위에 놓인다.** B4 끝점 `(9.62, -41.07)`는 B5 경로 `x=9.81, y -50.1 ~ -38.1` 중간이다. 두 발판의 왕복 주기는 B4 9.33초, B5 4.80초라 **168초마다 같은 위상**으로 돌아오므로, 설계 검증기의 60초 표본(0.2초 간격)으로는 겹침을 못 봤다.
2. 400초 시뮬레이션(0.02초 간격): **B4~B5가 7.2초 동안 서로 겹치고**, B5 탑승자의 머리 공간(발판 윗면 위 1.29 + 여유)을 B4가 침범하는 시간이 26.7초다. 첫 겹침은 79.8초 시점이다. B5에 타고 있는 동안 B4가 B5를 통과하면 탑승자가 끼이거나 밀려난다.
3. B5에서 C1로 건너는 점프는 B5가 **윗부분**에 있을 때만 가능하다. B5가 가장 낮은 위치(윗면 -50.1)면 수평 간격 8.7이 점프 도달 거리를 넘는다. 성공 가능한 시점은 시험한 336초 중 약 81%이고, **가능한 시점이 없는 구간은 최대 5.8초**다. B4→B5는 최대 6.2초다(설계 문서는 B5→C1 3.7초로 적었다).
4. 정상 진행 점프가 추락 판정 띠(`P1_step_B4`, y -43.6)에 걸리지는 않는 것을 확인했다.

한계: 위 판정은 제 시뮬레이션이다(점프 상승 속도 8.05 = 높이 80%, 좌우 속도 8, 몸 0.98×1.29, 모든 발판과의 충돌 포함). Unity 실제 플레이로 재현하지는 못했다(에디터 플레이 모드가 창 비활성 상태에서 시간이 거의 흐르지 않아 자동 점프 시험이 불가능했다). **영구적으로 못 넘어가는 구조는 모델에서 확인되지 않았고**, 겹침으로 끼이거나 6초 가까운 대기가 생기는 구조까지는 확인됐다. 실제 증상이 다르면 알려 달라.

## 4. 설계 문서와의 차이

1. **검증 범위**: 설계 검증기의 이동형 겹침 검사는 60초 구간만 봤다. 연속 이동형은 주기가 다르면 위상이 168초 뒤에 반복되므로 겹침이 늦게 나타난다. `MapDesign_Stage5-2.md` §7의 “35쌍 전부 점프 가능, 최대 대기 3.7초”는 **발판 겹침과 몸 충돌을 보지 않은 근사 판정**이었다.
2. **점프 가능 판정 기준**: 문서는 가장자리 간격과 높이 차만 보았다. 충돌 포함 모델에서는 점프 궤적이 다른 이동형에 막히는 시점이 더해져 가능 시간이 줄어든다.
3. 문서 §10의 이동형 대기 상한 합(P1 15.4 등)과 플레이 시간 추정은 위 3.7초 기준이라 낙관적이다.
4. Unity 씬에 이름만 있고 내용이 없는 빈 오브젝트 `P3`(월드 532,0)가 `Generated_5-2` 아래에 있다. 설계에 없는 오브젝트다. 영향은 확인하지 못했다.
5. 구현 보고서(`Stage52_Implementation_20261015.md`)의 “이동형 20개 경유점 재도달”은 이동 자체의 검증이며 통과 가능성 검증이 아니다. 전체 연속 완주 검사는 하지 않았다고 이미 명시돼 있다.

## 5. 수정 방향 (미적용, 승인 필요)

1. P1 B1~B5(그리고 가능하면 F1 B1·B2)를 **같은 왕복 주기**로 맞춘다. 속도는 서로 다르게 두되 경로 길이를 `주기×속도/2`로 정해 위상을 고정하고, 한 주기 동안 겹침과 머리 공간을 검사한다(수칙 23과 양립).
2. B4 끝점을 B5 승강 경로에서 떼어 교차는 유지하되 같은 시점에 같은 자리를 지나지 않게 한다.
3. F1 `B1`의 위끝을 `S4_K` 아래 1.8 이상으로 내리거나 B1을 K 바깥으로 옮긴다.
4. 생성기에 **장시간(400초 이상) 겹침·머리 공간 검사**와 충돌 포함 점프 검사를 넣고, 최대 대기 4초 기준을 이 모델로 통과시킨다. 대기가 긴 P2 `M1`·`M2`·`M6` 속도·출발 지연도 함께 조정한다.
5. 설계와 `MapDesign_Stage5-2.md`를 고친 뒤 Unity에서 해당 발판만 다시 배치한다.
