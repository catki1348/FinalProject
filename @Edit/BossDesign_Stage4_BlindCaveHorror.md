# 보스 설계4 — 눈먼 동굴 괴수 (Blind Cave Horror)

작성일: 2026-10-13
상태: 설계 및 공격 4종 키포즈 생성 완료. 공격 PNG 8장·GIF 4개·재생 시안을 제작했다. 기본 모션 4종과 독립 VFX 제작, Unity 구현 및 실전 검증은 미실행.

## 1. 테마와 제작 기준

기준 이미지: `Assets/Sprites/Bosses/Stage4_DemonCave/02_BlindCaveHorror_pixel.png`.
스테이지4의 도트 후보를 이번 설계의 기준으로 선택한다. 기존 보스2의 모션·공격 수량을 그대로 계승한다.

창백한 회백색 피부, 길고 마른 여러 팔, 붉은 갈고리 발톱, 등과 머리의 돌기, 세로로 크게 벌어지는 입, 드러난 갈비뼈와 보라색 복부를 보존한다. 새 무기·갑옷·용암 효과는 추가하지 않는다. 이름의 ‘눈먼’ 설정은 시각 추적 대신 진동·소리에 반응한다는 연출로 표현한다. 테마의 붉은 얼굴 표식은 보존하되 눈에서 광선을 발사하지 않는다.

게임용 원화는 오른쪽을 보는 측면이다. 팔이 많은 외형은 유지하면서 전방 공격 팔과 지면 지지 팔의 역할을 분명히 구분한다. 동굴의 좁은 전장을 긴 팔로 압박하고, 포효와 낙석으로 이동을 유도하는 지상형 보스다.

| 규격 | 보스2와 동일한 목표 |
|---|---|
| 기본 모션 | 대기·이동·그로기·사망 4종 |
| 공격 모션 | 일반2 + 특수2 = 4종 |
| 전체 클립 | 10종, 별도 피격 클립 없음 |
| 본체 원화 | 22장 |
| 별도 VFX 원화 | 음파·낙석 2장 |
| 본체 캔버스 | 1432×1198px |
| 접지 피벗 | (0.5, 0.006678) |
| 임포트 | Sprite Single, PPU100, Point, 무압축 |
| 클립 샘플레이트 | 60 |
| 방향 | 오른쪽 원본, Visual만 좌우 반전 |

4K는 생성 요청 원본의 목표다. 실제 생성 크기를 기록하고 게임용 캔버스로 정렬한다. 여러 팔과 돌기가 잘리지 않도록 가장 넓은 공격 자세까지 수용하는 여백을 확보한다. 몸통 배율과 발 접지 위치는 모든 프레임에서 같아야 한다.

## 2. 기본 스탯과 행동

| 항목 | 초기 설계값 |
|---|---|
| 체력 | 220 |
| 이동 속도 | 2.0유닛/초 |
| 감지 거리 | 16 |
| 근접 추적 정지 거리 | 2.4 |
| 표시 높이 | 보스2처럼 약3.3유닛, 가장 높은 팔까지 실측 |
| 일반 공용 쿨다운 | 공격 시작 기준1.2초 |
| 특수 공용 쿨다운 | 첫 인식4초 후, 특수 시작 기준7초 |
| 그로기 | 단일 피해20 또는 누적30 → 3초 |
| 이동 방식 | 걷기(기본) + 점프 + 돌진 (섹션 10) |

스탯은 제안값이며 전투 밸런스 검증 전이다. 보스는 일반 몬스터 규격과 분리한다.
우선순위: 사망 > 그로기 > 진행 중 공격 > 사용 가능한 특수 > 일반 > 추적 > 대기.
공격은 중첩하지 않는다. 발판 끝·보스존 경계에서 추적을 멈추고 공격 시작부터 회복 종료까지 바라보는 방향을 고정한다. 루트 물리와 몸체 충돌은 반전하지 않으며 판정 위치는 같은 facing 값으로 계산한다.

거리2.4 이내에서는 일반2종을 50:50으로 선택한다. 거리2.4 초과3.4 이내에서는 하단 휩쓸기만 선택한다. 특수는 포효와 낙석을 교대하되 거리·지면 조건이 맞지 않으면 다른 사용 가능한 특수를 선택한다. 모두 불가능하면 일반 행동을 이어간다.

## 3. 공격 패턴 — 정확히4종

피해는 방어 적용 전이다. 기존 플레이어 피격 무적1초를 유지하고 신규 강제 경직·실명·석화는 추가하지 않는다.

| 구분 | 패턴 | 발동 거리 | 피해 | 준비 / 판정 | 전체 길이 | 회피 |
|---|---|---|---|---|---|---|
| 일반1 | 발톱 베기 ClawSlash | 2.4 이내 | 16 | 0.35초에 단발 | 0.7초 | 뒤로 빠지기 |
| 일반2 | 하단 휩쓸기 LowSweep | 3.4 이내 | 14 | 0.4초에 단발 | 0.8초 | 점프 |
| 특수1 | 음파 포효 SonicRoar | 2.5~7 | 16/틱, 최대2틱 | 0.5초 시작, 1.2초 지속 | 1.9초 | 사거리 밖 또는 보스 뒤 |
| 특수2 | 천장 낙석 CaveCollapse | 2.5~16 | 20, 대상당1회 | 0초 경고 → 0.8초 낙석 판정 | 1.4초 | 경고 범위 밖으로 이동 |

### 일반1 — 발톱 베기
전방의 긴 팔을 뒤로 당김 → 붉은 발톱으로 앞을 크게 베기 → 기본 자세 복귀. 다른 팔은 몸을 지지한다. 전방 길이2.6, 바닥 기준 높이0.8~2.6의 상자 판정을 사용한다. 0.35초에 한 번만 검사하고 같은 대상의 여러 Collider를 중복 타격하지 않는다.

### 일반2 — 하단 휩쓸기
낮은 팔을 바닥 가까이 접음 → 전방 지면을 긴 발톱으로 쓸기 → 팔 회수. 전방 길이3.6, 높이1.0의 낮은 상자 판정으로 0.4초에 한 번 타격한다. 발톱의 실제 경로와 판정이 일치해야 하며 점프한 플레이어의 몸까지 넓히지 않는다.

### 특수1 — 음파 포효
몸통을 웅크리고 입을 벌릴 준비 → 0.5초부터 입에서 보라색·회백색 음파를 전방으로 방출 → 입을 닫으며 회복. 판정은 입 앞 길이6.5, 높이2.2다. 입 위치와 지면을 실측하여 플레이어 머리 위로 판정이 뜨지 않게 맞춘다. 0.5초와1.5초에 각16 피해를 검사하며 1.7초에 판정을 종료한다. 같은 틱에서 대상당1회, 틱 간격1초. 회복0.2초 후 종료한다. 조준은 공격 시작 방향으로 고정하며 뒤쪽에는 판정이 없다.

### 특수2 — 천장 낙석
위쪽 팔을 치켜들고 포효 준비 → 동굴을 울리는 동작과 함께 낙석 → 팔을 내리며 회복. 시작 시 플레이어 발밑 지면1곳을 확정하고 폭1.8의 바닥 경고를 표시한다. 0.6초에 경고 중심 위3유닛에서 돌을 나타내고 0.8초에 지면에 도달하게 한다. 지면 도달 시 폭1.8·높이2.4의 상자 판정을 한 번 검사하여 점프만으로는 피하기 어렵고 옆으로 이동하게 한다. 돌의 하강은 시각 연출이며 별도 공중 피해 판정을 중첩하지 않는다.

**4-5 보스존의 은신 지붕(`RockShelter`) 아래에서는 낙석이 지붕에 막혀 피해가 없다**(`MapDesign_Stage4-5_BossArena.md` 10절). 낙석의 목표는 보스존의 유효 발판 안으로 제한한다. 대상 발밑 지면을 찾지 못하면 발동하지 않는다. 위치 확정 후 플레이어를 따라 이동하지 않는다. 판정 이후 돌은 부서지며0.6초 안에 사라진다. 실제 동굴 천장이 없어도 보스존 연출 높이를 기준으로 실행하도록 설계한다.

## 6. 피격·그로기·사망과 종료점

피격은 짧은 색 변화로 표현하고 별도 Hit 클립을 만들지 않는다. HP 감소는 기존 Boss 체력 이벤트를 재사용한다. 그로기 중 재진입을 막고 종료 후 누적 기준을 초기화한다.
그로기·사망 진입 시 포효 판정, 낙석 예약, 활성 돌, 경고, 공격 타이머를 취소한다. 체력0에서 사망을 한 번만 실행하고 AI와 몸체 충돌을 중단한다. 사망 자세는 붉은 발톱의 색을 유지한 채 모든 팔과 몸통이 바닥으로 가라앉는 형태다.
보스 처치 이벤트로4-5 종료점을 활성화하고, 종료점 도착 시 스테이지 클리어 후 Stage5로 이동한다.

## 7. 사운드와 구현 역할

사운드 지정: 대기 호흡, 이동 접지, 발톱 준비/베기, 하단 준비/휩쓸기, 포효 준비/방출, 낙석 준비/돌 충돌, 그로기, 사망, 전투BGM. 빈 필드는 무음이며 같은 사망 이벤트를 중복 재생하지 않는다. 기존 BossSfx 번호는 유지하고 필요한 값만 끝에 추가한다.

`BlindCaveHorrorController`는 추적·공격 선택·중단을 담당한다. Boss는 체력·처치 이벤트, BossSound는 음원 선택, SoundManager는 실제 재생을 맡는다. 반복 생성 낙석은 풀링 가능한 프리팹을 사용한다. 대상 탐색은 명시 참조 또는 Manager 캐시를 사용하고 GameObject.Find와 태그·이름 문자열 탐색을 사용하지 않는다. 판정용 버퍼를 재사용한다.

## 8. 제작 및 검수 계획

연결된 이미지 워크플로우에서 기준 측면 원화1장을 생성하고 동일 기준을 참조하여 나머지21장과VFX2장을 제작한다. Run All 대신 독립 노드를 실행하고 실패 노드만 재처리한다.
공통 프롬프트: 4K resolution, reference Blind Cave Horror, game-ready pixel-art sprite, pale gray skin, multiple elongated arms, red hooked claws, dark dorsal spikes, wide vertical tooth-filled mouth, exposed ribs and purple abdomen, strict right-facing side profile, identical proportions and scale, fixed ground contact, transparent background, entire arms and claws visible, no text, no border, no scenery. 각 프레임의 자세만 추가한다.

검수 기준: 본체22장·효과2장·클립10종·공격4종·이동2종, 오른쪽 방향, 알파 배경, 동일 캔버스·접지·몸통 크기, 팔 개수와 붉은 발톱 유지, 각 공격 자세와 판정 위치 일치. 신규 이미지가 없으므로 테마 원본을 이동·변형한 결과를 모션 생성 완료로 표시하지 않는다.

원본 테마와 공통 측면 원화를 함께 참조했다. 회백색 피부, 여러 긴 팔, 붉은 발톱·얼굴 표식, 등 돌기, 보라색 복부, 긴 입을 기준으로 검수했다. AI가 생성한 자세 사이에 세부 팔·목·피부 묘사 차이는 남아 있으며, 관절 리깅으로 동일한 원화를 변형한 결과는 아니다.
생성 원본은 실제1024×1024다. 4K는 프롬프트 요청이며 실제4K로 표시하지 않는다. 녹색 배경 제거, 분리된 효과 제거, 비율을 유지한 크기 보정 및 발 접지 정렬 후 게임용1432×1198 RGBA로 저장했다. 모션마다 적용한 균일 배율과 접지 기준은 `animation_manifest.json`에 기록했다.

최종PNG8장의 크기·RGBA·알파, GIF4개의 프레임 수, 원화 잘림, 브라우저 이미지 로딩과 컨트롤, 브라우저 오류0을 확인했다. 실제 충돌과 피해·밸런스·Unity 검수는 아직 수행하지 않았다.

## 10. 이동 방식 추가 — 점프·돌진 (2026-10-13, 설계안)

공격 4종은 그대로 두고 이동 방식만 2종 추가한다. 수치는 제안값이며 전투 밸런스 검증 전이다. 점프는 피해가 없는 이동, 돌진은 몸통 접촉 피해가 있는 이동 겸 위협이다.

| 구분 | 이동 | 사용 조건 | 길이 | 피해 | 회피 |
|---|---|---|---|---|---|
| 이동2 | 점프 Jump | 거리 3.4 초과 ~ 8 또는 플레이어가 높이 1.5 이상 위 발판. 쿨다운 5초 | 0.8초 (준비0.3 + 공중0.5) | 없음 (착지 충격 없음) | 착지 지점에서 벗어나기 |
| 이동3 | 돌진 Charge | 거리 3.4 초과 ~ 10, 같은 높이 지면. 쿨다운 8초 | 1.5초 (준비0.6 + 돌진0.9) | 18, 돌진 중 몸체 앞 높이 0.9 이하 접촉 시 대상당 1회 | 점프 정점 또는 반대로 달리기 |

### 이동2 — 점프
몸을 낮추고 다리를 접음(0.3초) → 긴 팔을 앞으로 뻗으며 도약, 포물선으로 이동 → 착지 후 Idle 복귀. 도약 시점의 플레이어 위치를 목표 X로 고정하고 이후 추적하지 않는다. 수평 이동 최대 6, 최고 높이 2.2. 목표 지점에 유효 발판이 없으면 가장 가까운 발판 끝에 착지한다. 보스존 경계를 넘지 않으며 공중에서는 피격되지 않는 것이 아니라 일반 피해만 받는다. 착지 후 일반 쿨다운 0.5초를 둔다.

### 이동3 — 돌진
준비 0.6초 동안 낮게 웅크려 발톱으로 바닥을 긁고 바닥에 붉은 경고선(전방 길이 8)을 표시한다 → 0.6초에 속도 7.0유닛/초(걷기의 3.5배)로 0.9초 전진 → 벽·발판 끝·보스존 경계·최대 거리에서 멈춤 → 0.5초 회복. 돌진 중 방향은 고정한다. 몸체 접촉 판정은 몸체 앞 길이 1.2·높이 0~0.9 상자(2026-10-14 낮춤)이며 대상당 1회, 기존 피격 무적 1초를 따른다. 그로기·사망 진입 시 돌진과 경고선을 즉시 취소한다. 발판 끝에서는 떨어지지 않고 멈춘다.

### 선택 우선순위 변경
기존 우선순위(사망 > 그로기 > 진행 중 공격 > 사용 가능한 특수 > 일반 > 추적 > 대기)에서 추적 단계에 이동2·3을 둔다: 사용 가능한 특수 > 일반 > **점프·돌진(조건 충족 시 50:50, 쿨다운 중이면 걷기)** > 걷기 추적 > 대기. 점프·돌진은 근접 거리 3.4 이내에서는 선택하지 않는다.

### 추가 프레임 4장 (본체 18장 → 22장) — 이 4장 키포즈는 제작 완료, 본체 22장 전체는 미완료

| 19–20 | 19_jump_crouch / 20_jump_air | 몸을 낮춰 다리를 접음 → 팔을 앞으로 뻗은 공중 자세 |
| 21–22 | 21_charge_windup / 22_charge_run | 낮게 웅크려 발톱을 바닥에 긁음 → 몸을 앞으로 눕힌 질주 |

원화 기준은 기존과 같다(오른쪽 측면, 1432×1198 기준 접지 피벗, 같은 몸 배율). 공중·질주 자세는 팔이 길게 뻗으므로 하단 휩쓸기처럼 캔버스를 넓힐 수 있다.
