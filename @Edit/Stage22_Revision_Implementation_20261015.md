# 2-2 수정 설계 Unity 적용 결과

**적용·검증 완료.** `Assets/Scenes/Stage2.unity`에 [수정 설계](MapDesign_Stage2-2_Revision.md)를 반영했다.

## 반영 내용

- 일반 10개·이동 5개·소멸 3개를 전용 프리팹 3종으로 교체했다. 이동·소멸 컴포넌트는 프리팹 원본에 저장했고 씬에는 외부 경로와 크기·배치값만 연결했다.
- 발판의 유효 Scale을 (1,1,1)로 맞추고 Tiled/Continuous 및 명시적 콜라이더 크기를 적용했다. 기존 정글 텍스처의 내부 Rect를 사용하는 Full Rect 스프라이트를 별도로 만들어 공용 텍스처·임포터는 유지했다.
- D1·D2·D3 폭을 1.6, 소멸 구간 틈을 3.8, 매 착지면 높이 차를 0.4로 수정했다. 소멸 0.4초·복구 대기 2초를 유지했다.
- 이동형 5종의 경로·속도 2·시작 지연 0·경유 대기 0을 유지했다. 경로 오브젝트는 발판 외부에 연결했다.
- 카메라 X 범위를 [50,172]로 확장하고 2-3·2-4 및 관련 경계를 +12 이동했다. 하단 보스 영역은 X=236.025, Y=-60 중심으로 옮겼다.
- 시작점 (70.450,0.555), 종료점 (163.220,4.150)을 적용했다. 종료 콜라이더의 Trigger와 다음 영역·카메라 참조를 명시적으로 저장했다.

## 검증

| 검사 | 결과 |
|---|---|
| 저장 후 씬 재열기 | 구조 111개 검사 통과: 프리팹·외형·경로·충돌 좌표·영역 분리·보스 중앙 배치·누락 스크립트 |
| 실제 Physics2D | 29개 검사 통과: 인접 17쌍 착지, 이동형 5종 경유점, MP2 탑승 이동, 우회 6쌍 차단 |
| 인접 착지 성능 | 수평 속도 상한 6.4(기본 8의 80%), 점프 초기 속도 9로 실제 착지 |
| 승강 탑승 | MP2에서 플레이어 발 높이가 약 3.200유닛 상승 |
| 소멸 구간 연속 통과 | 실제 프레임에서 속도 6.4와 8 각각 N8→D1→D2→D3→N9 통과. 점프 사이 위치 순간이동 없음 |
| 실제 소멸 타이머 | 위에서 충돌 후 약 0.474초에 소멸, 약 2.475초에 복구 확인. 실제 프레임 관측 지연 포함 |
| 종료점 | 실제 Trigger 접촉으로 2-2→2-3 진행 및 이동된 시작점 도착 확인 |
| 외형 | 정면·후면·좌측·우측·상단 임시 렌더 5장 확인. 반복 사이 빈 여백과 Scale 늘어짐 없음 |
| 콘솔 | 검사 종료 시 오류·경고 0건 |

우회 검사는 최대 가속 속도 10 및 공중 대시 속도 5.625·지속 0.2초의 속도 동작을 물리 스텝에 적용하고, 출발 위치 5곳·대시 시작 시점 31개를 샘플링했다. 분석 상한 계산도 병행했다. 실제 키 입력으로 모든 대시 시점을 전수 검사한 것은 아니다.

전체 2-2는 연결별 물리 검사를 했고, 소멸 구간은 실제 시간으로 연속 통과했다. 전체 구간의 수동 연속 플레이는 수행하지 않았다. 80% 검사는 **수평 이동 속도** 기준이며 점프 높이까지 80%로 줄인 검사가 아니다.

테스트는 기존 Test000을 보존하고 새 Test001 복제본에서 수행했다. 검사 중 위치 이동 동기화와 재사용된 일회성 종료 트리거 상태를 테스트 함수에서 초기화하도록 정리했다. 소멸 복구 관찰 중 낙하 게임오버가 시간을 멈추지 않게 테스트 복제본에서만 낙하 트리거를 비활성화했다. 메인 씬의 게임오버 동작은 유지했다.

소유한 Test001과 임시 확인 이미지 5장은 검사 후 삭제했다. Unity는 수정된 Stage2 씬의 편집 모드로 복귀했다. 적용 전 씬은 `@Backup/Stage22_Revision_20261015/Stage2.before.unity`에 보존했다.
