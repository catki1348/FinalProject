# 1-2 곡선 지형 슬라이드 이동 설계

상태: 2026-10-08 코드 및 Stage1 Unity 씬 적용.

## 의도

대각선 발판은 경사진 지면을 의미한다. 움직이는 발판에 탑승하는 기능과는 별개다.
1-2의 곡선 지형을 따라 내려갈 때 자동으로 슬라이드하고, 얻은 속도로 다음 굴곡을 통과한다.
기존 맵 문서의 초기 좌표는 현행 배치를 나타내지 않으므로 이번 설계에서는 배치를 변경하지 않는다.

## 이동 규칙

| 상황 | 동작 |
|---|---|
| 내리막 접지 | 기울기 12도 이상에서 자동 슬라이드 시작. 입력 없이도 낮은 쪽으로 이동 |
| 곡선 연결부 | 실제 지면의 접선 방향으로 속도를 이어받아 곡선을 따라 이동 |
| 오르막 진입 | 이전 슬라이드 속도로 올라가면서 감속. 속도가 부족하면 슬라이드 종료 후 일반 이동 |
| 평지 진입 | 마찰로 감속하고 일반 이동 속도까지 내려오면 종료 |
| 반대 방향 입력 | 브레이크. 같은 방향 입력은 약한 가속 보조 |
| 점프 입력 | 즉시 슬라이드 종료. 현재 수평 속도를 유지하고 기존 점프 상승 속도 적용 |
| 발판 끝 이탈 | 접지 보정 종료 후 낙하. 빈 공간을 따라가는 자동 이동은 하지 않음 |
| 대시 | 기존 대시가 우선. 대시 종료 후 접지 상태와 경사에 따라 다시 판정 |

슬라이드는 자세 연출과 이동 상태로 정의한다. 낮은 통로 통과용 콜라이더 축소는 이번 범위에 포함하지 않는다.

## 초기 조정값

- 시작 경사: 12도. 종료 경사: 6도 이하에서 저속일 때 종료해 경계에서 상태가 반복 전환되는 것을 방지.
- 최소 진입 속도: 3유닛/초. 최대 속도: 12유닛/초. 일반 이동 속도는 실제 플레이어 설정값 사용.
- 경사 가속: 중력의 지면 접선 성분 사용. 내리막은 가속하고 오르막은 감속.
- 평지 감속: 8유닛/초². 반대 입력 브레이크: 16유닛/초².
- 위 수치는 플레이 조정 전 초깃값이며 점프 간격 통과를 보장하는 값은 아니다.

## 기존 코드와 연결

현재 `Assets/Scripts/Player/PlayerMovement.cs`는 지면 법선을 구한 뒤 경사 접선에 `moveInput * moveSpeed`를 매 물리 프레임 대입한다. 입력이 없으면 접선 속도가 0이 되므로 마찰값만 낮춰서는 슬라이드가 유지되지 않는다.

기존 지면 감지를 재사용한다. 일반 이동과 슬라이드 중 하나만 최종 속도를 적용하도록 같은 이동 처리에서 분기하고, 슬라이드 속도를 별도로 누적한다. 경사 접선이 바뀔 때 이전 속도를 새 접선에 투영해 연결부에서 속도가 갑자기 생성되지 않게 한다.

점프 직후에는 경사 속도 대입과 지면 스냅을 모두 중단한다. 현재 경사 속도 분기는 `isJumping`을 직접 확인하지 않으므로 구현 시 이 조건을 함께 정리해야 한다. `PlayerDash`의 `MovementLocked` 우선권은 유지한다.

`StageManager.enableSection2SlopeSlide`를 Stage1 씬에서 활성화했다. 기존 영역 스폰 처리에서 2영역 진입 시 슬라이드를 켜고 다른 영역 진입 시 해제한다. WarpManager로 1-2에 진입해도 동일하게 동작한다. 다른 스테이지의 설정 기본값은 비활성화다.

## 지형 설계 변경

2026-10-08 사용자의 재설계 요청으로 이전 1-2 발판 배치와 세 곡선 충돌면 설계는 폐기했다. 새 배치는 MapDesign_Stage1-2.md의 Z형 경로를 따른다. 공용 슬라이드 기능은 유지한다. 이전 Unity 배치는 새 설계 적용 시 삭제·교체하며 아직 교체하지 않았다.

## 확인 기록

`Tools > Checks > 1-2 Slope Slide` 메뉴에서 재실행 가능하다. 임시 Test 번호 씬을 만들고 계산 확인 후 닫으며 파일은 남기지 않는다.
양방향 하강, 최대 속도, 반대 입력 브레이크, 평지 종료, 영역 상태 초기화, 점프 속도 보존을 확인했다. 씬의 연속 충돌면 3개 활성 상태와 저장을 확인했다.
전체 1-2 동선을 실제 입력으로 끝까지 통과하는 플레이 확인은 아직 수행하지 않았다.

## 구현 후 확인 항목

1. 좌우 방향 내리막에서 입력 없이 낮은 쪽으로 이동하는지 확인.
2. 언덕 정점과 오목한 연결부에서 진동, 튕김, 속도 급증이 없는지 확인.
3. 오르막에서 감속하고 평지에서 일반 이동으로 복귀하는지 확인.
4. 점프가 지면 보정에 취소되지 않고 발판 간 갭은 점프로 통과하는지 확인.
5. 대시 종료 및 다른 영역 진입 후 이동 잠금과 슬라이드 상태가 남지 않는지 확인.

Unity 플레이 확인은 요청받아 적용할 때 임시 Test 씬에서 진행한다.
