# Stage2 - Section_1(2-1) 맵 설계안

> Unity 씬 작업은 진행하지 않았습니다(설계안만 작성). 아래 좌표/수치를 검토 후 승인하시면, 별도 요청 시 Unity에서 실제 배치 작업을 진행합니다(LHS_Custumer.md 규칙 9, 11 / MapEdit.md 규칙 1).

## 1. 요청 사항 정리

- 별도 컨셉 이미지 없이, 2스테이지(숲→동굴 전환 테마)의 첫 영역(2-1)을 신규 설계.
- 스테이지 도입부이므로 1-1과 유사하게 "튜토리얼 성격"의 난이도로, 일반 발판 + 갭 점프만으로 구성(이동형 발판·기믹 없음).
- 시작점(★)~종료점(○) 사이 플레이어 이동 동선 길이를 실측해 보고(요청 사항).

## 2. 기존 씬 데이터 확인 결과 (Stage2.unity)

- `Section_1`은 현재 placeholder 상태(실제 폭 약 2유닛, 지형 없음) — 이전 "전체 스테이지 재배치" 작업 때 임시 간격 기준으로만 위치를 잡아둔 상태입니다(`MapDesign_AllStages_Layout.md` 참고).
- `Boundary_1_2`는 현재 Section_1 기준 로컬 x=14(월드 x=23)에 있으나, 이는 placeholder 폭 기준의 임시값이라 이번 설계의 실제 폭(41유닛)에는 맞지 않습니다 → 실제 배치 시 이동 필요(6번 비고 참고).
- 플레이어 이동 스펙(`Player_Warrior.prefab`: moveSpeed=8, jumpForce=9, gravityScale=3, 기존 문서들과 동일):
  - 최고 점프 높이 ≈ **1.38유닛**
  - 동일 높이 기준 최대 수평 점프거리 ≈ **4.9유닛**

## 3. 좌표 기준

이하 모든 좌표는 **시작 지점(★)을 (X=0, Y=0)으로 삼은 상대 좌표**입니다.

```
Y(고도)
0.8 ┤            ╭──╮
0.0 ┤★──╮   ╭╮┄┄┄╯  ╰┄╮      ╭────────╮┄┄╮   ╭──○
    │   ┆   ││          ╲    │        │   ┆   │
    └───┴───┴┴──────────┴────┴────────┴───┴───┴──
     0   4  6.5 7.5     10  13   15   21  24.5  34 36.5 41
```
(┄ = 점프 갭, ─ = 발판, ★=시작, ○=종료)

| # | 구간명 | X 범위 | 폭 | Y | 설명 |
|---|---|---|---|---|---|
| 1 | 시작 발판 | 0 ~ 4 | 4.0 | 0.0 | 시작 지점(★). 안정된 도움닫기 구간 |
| — | 갭 1 | 4 ~ 6.5 | 2.5 | 0.0 | 최대 허용거리(4.9)의 약 51% — 여유 있는 첫 점프 |
| 2 | 디딤돌 | 6.5 ~ 7.5 | 1.0 | 0.0 | 좁은 발판, 정확한 착지 요구 |
| — | 갭 2 | 7.5 ~ 10 | 2.5 (상승 0.8) | 0→0.8 | 대각 점프(상승) |
| 3 | 언덕(고지대) | 10 ~ 13 | 3.0 | 0.8 | 튜토리얼 상 "1-1"과 유사한 리듬 |
| — | 갭 3 | 13 ~ 15 | 2.0 (하강 0.8) | 0.8→0 | 대각 점프(하강), 쉬운 난이도 |
| 4 | 중간 평지 | 15 ~ 21 | 6.0 | 0.0 | 휴식/도움닫기 구간 |
| — | 갭 4 (시그니처) | 21 ~ 24.5 | 3.5 | 0.0 | 최대 허용거리(4.9)의 약 71% — 이번 구간의 메인 긴장 포인트 |

모든 갭이 최대 허용 거리(4.9)·최대 상승고도(1.38) 이내로, 안전하게 클리어 가능합니다.

## 4. 이동 동선 길이 실측 (요청 사항)

시작 지점(★, x=0)에서 종료 지점(○, x=41)까지, 발판 위를 걷는 구간과 갭을 점프하는 구간(대각선 포함)을 모두 더한 **실제 이동 거리**:

| 구간 | 계산 | 거리 |
|---|---|---|
| 시작 발판 도보 | 0→4 | 4.000 |
| 갭1 점프 | (4,0)→(6.5,0) | 2.500 |
| 디딤돌 도보 | 6.5→7.5 | 1.000 |
| 갭2 점프(대각) | (7.5,0)→(10,0.8) | 2.625 |
| 언덕 도보 | 10→13 | 3.000 |
| 갭3 점프(대각) | (13,0.8)→(15,0) | 2.154 |
| 중간 평지 도보 | 15→21 | 6.000 |
| 갭4 점프 | (21,0)→(24.5,0) | 3.500 |
| 긴 평지 도보 | 24.5→34 | 9.500 |
| 갭5 점프 | (34,0)→(36.5,0) | 2.500 |
| 종료 발판 도보 | 36.5→41 | 4.500 |
| **합계** | | **41.279** |

**→ 이동 동선 길이 ≈ 41 (1~100 범위 값)**

(직선거리로 단순 계산하면 41.0이지만, 상승/하강 대각 구간의 실제 이동거리를 포함하면 41.28로 거의 동일 — 이 구간은 대부분 수평 이동 위주 설계라 대각 보정값이 크지 않습니다.)

## 6. 비고 / 확인 필요 사항

1. 이번 설계 폭(0~41유닛)은 `MapDesign_AllStages_Layout.md`에서 잡아둔 placeholder 간격(Section_1 로컬 0~14, `Boundary_1_2` 로컬 x=14)보다 넓습니다. 실제 Unity 배치 시 `Boundary_1_2`를 로컬 x=41 부근(월드 x≈50)으로 옮기고, 뒤따르는 `Section_2`/`Boundary_2_3` 이하도 그만큼(Δ≈27유닛) 밀어야 겹치지 않습니다(1-3 설계 때와 동일한 종류의 조정).
2. `Background_Forest`/`CameraBoundsZone`이 이 폭(41유닛)을 덮는지는 실제 배치 시 별도 확인이 필요합니다(다른 영역에서도 반복적으로 나온 이슈).
3. 좌표/폭은 설계 제안이며, 실제 배치는 Unity 작업이므로 사용자 승인 후 별도로 진행합니다(규칙 9, 11).
