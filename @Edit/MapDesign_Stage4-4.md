실제 시작 X=1126, 종료 X=2326. 발판 150개와 제안 몬스터 30마리를 적용했다. 발판의 독립 낙하는 유지하며, 온전한 발판의 BoxCollider 입력을 CompositeCollider2D로 합쳐 이음매 걸림을 방지한다. 낙하 시작 시 해당 입력 충돌을 제거하고 외형만 아래로 떨어뜨린다. 기존 공용 낙사 판정선 y=-20을 유지하고 가로 범위를 확장했다. 4-5 보스존은 상단 전체 영역 아래 중앙으로 이동했다. 일반 가속은 남은 시간대로 처리하고 4-4 전용 최대 가속은 이탈·사망·게임오버 시 해제한다.

## 기획과 확정 조건

4-2의 질주, 4-3의 분노의 질주에 이어 무너지는 길을 최대 가속으로 돌파한다. 낙하하는 발판 위에서 몬스터를 처치하거나 피하면서 종료점에 도달한다. 전멸·아이템 수집은 클리어 조건이 아니다. 종료점 도달 시 4-5 보스 영역으로 이동한다.

- 시작 시 가속 버프를 최대 5중첩으로 즉시 부여한다. 기존 가속의 네 효과를 유지한다: 이동속도·대시 거리·대시 속도 ×1.25, 대시 대기시간 ×0.75. 이동속도는 기본 8 기준 10유닛/초다.
- 4-4 내부에서는 가속이 만료되거나 중첩이 감소하지 않는다. 아이템 추가 획득으로 상한을 넘기지 않는다.
- 설계 거리 150 = 1200유닛. 가속 여부와 무관하게 기본 이동 1초 거리인 8유닛을 거리 1로 사용한다.
- 발판 150개 전체를 낙하형으로 배치한다. 시작·종료 지지면도 이 150개에 포함하며 별도 영구 안전 발판은 추가하지 않는다.
- 시작점에서 플레이어가 준비되면 낙하 시계를 한 번 시작한다. 시작점부터 종료점 방향으로 1초마다 1개씩 낙하한다. 접촉 여부·플레이어 위치·처치 수와 무관한 고정 순서다.

## 발판 배치와 낙하 시각

직선으로 틈·높이차 없이 연결한다. 이번 사용자 지정의 150개를 독립 낙하 단위로 사용한다. 이동 거리는 시작점과 종료점 사이 정확히 1200유닛이다.

| 항목 | 값 |
|---|---|
| 시작 / 종료 | ★(0,0) / ○(1200,0), 발판 윗면 기준 |
| P001 | x=-4~8, 중심 (2,-0.5), 폭 12 |
| P002~P149 | Pi의 x=8(i−1)~8i, 중심 (8i−4,-0.5), 폭 8 |
| P150 | x=1192~1204, 중심 (1198,-0.5), 폭 12 |
| 두께 / Scale | 1 / (1,1,1) |
| 첫 / 마지막 낙하 | P001: t=1초 / P150: t=150초 |
| 일반식 | Pi는 시작 후 i초에 낙하 개시 |
| 영역 외곽 초안 | x=-8~1208, y=-20~16 |

끝 발판의 바깥쪽 4유닛은 스폰·종료 지지 여유다. 150개 총 표면 길이는 1208유닛이나 시작~종료 진행 거리는 1200유닛이다. 발판은 Tiled/Continuous, Renderer.size와 Collider.size 일치, autoTiling=false를 사용한다. 부모 Scale도 1을 유지한다. 경계에서 걸림·틈이 발생하지 않도록 실측한다.

첫 낙하는 t=0 즉시가 아니라 **t=1초**로 해석한다. 시각 i가 되면 Pi의 지지 충돌을 즉시 해제하고 아래로 낙하하는 연출을 시작한다. 이후 시점 계산에서는 이미 사용할 수 없는 발판으로 취급한다. 낙하 속도·퇴장 연출은 제안값이며 난이도 여유 시간에 포함하지 않는다. 낙하 잔해가 아래에서 다시 플레이어를 받치거나 적·아이템을 밀지 않도록 한다. 해당 발판은 이번 시도 동안 복구되지 않는다.

## 시간 압박과 완주 가능성

최대 가속 보행만으로 1200÷10=**120초**. 마지막 발판 낙하는 150초이므로 끝 지점 기준 차이는 **30초**다. 이는 전 구간에서 자유롭게 쓸 수 있는 공통 대기시간이 아니다.

Pi의 오른쪽 경계 도달 예상 시각은 0.8i초(P150의 목표는 x=1200). 낙하 시각 i초와 차이는 0.2i초다. P001은 출발 후 0.8초에 벗어나므로 최초 여유는 0.2초뿐이다. 10번 발판은 2초, 50번은 10초, 100번은 20초, 150번은 30초다. 초반 지연이 특히 위험하다.

낙하한 뒤를 점프로 넘길 수도 있으므로 이 수치는 **낙하 전에 각 발판을 벗어나는 보수적 경로**의 계산이다. 점프·대시로 얻는 여유는 완주 필수 조건으로 계산하지 않는다. 대시는 기존 최대 가속 수치를 그대로 따르며 보행보다 빠른지 실제 검증하기 전 시간 단축 수단으로 보장하지 않는다.

별도 150초 일괄 게임오버는 추가하지 않는다. 종료 전 마지막 발판이 낙하하더라도 기존 점프 상태로 골인할 수 있다면 도착 판정을 허용한다. 추락 시 기존 사망·재시작 흐름을 사용한다. 추락 판정선 초안은 y=-12이며 인접 영역과 분리해 확정한다.

## 몬스터 배치 초안 — 제안값

사용자는 몬스터 수·종류·체력을 지정하지 않았다. 아래는 변경 가능한 초안이다.

- 10거리마다 2마리씩 15구간, 총 30마리. 각 구간 시작 상대 X+32, +64에 배치한다. 첫 조우 X=32로 초기 탈출 여유를 확보한다. 마지막 적은 X=1184로 종료 직전 16유닛을 비운다.
- 기존 저공 추격형 일반 몬스터를 사용하고 기준 높이 2.2를 제안한다. 각 구간 시작선 통과 시 해당 2마리만 한 번 활성화한다. 죽은 적은 재생성하지 않는다.
- 달리는 공격으로 맞힐 수 있는 높이 하한과 점프로 피할 수 있는 접촉 범위를 실측한다. 비행종은 발판 낙하로 함께 떨어지지 않으며 이동 경로를 몸으로 완전히 막지 않는다.
- 체력은 기준 장비 일반 공격 1~2타 처치를 목표로 하되 장비·방어 계산 확인 전 절대값을 확정하지 않는다. 공격 중 이동 정지와 피격 경직이 초반 여유를 소진하는지 검증한다.
- 일반 몬스터의 기존 드롭 규칙을 따른다. 4-2 전용 확정 회복·4-3 분노 드롭은 이어받지 않는다. 분노 공격력 보너스는 4-3 이탈 시 초기화한다. 처치·드롭 획득을 요구하지 않는다.

## 상태 전환과 구현 인계

1. 준비: 플레이어 위치·카메라·발판 150개·몬스터를 초기화한다. 로딩 중에는 시계를 진행하지 않는다.
2. 시작: 시작점 배치 완료 이벤트에서 최대 가속 고정과 시계 t=0을 함께 적용한다. 초반 0.2초 여유가 입력 잠금·화면 전환에 소모되지 않도록 플레이어 조작 가능 시점과 일치시킨다. 임의 대기 카운트다운은 추가하지 않는다.
3. 진행: 전역 경과시간으로 낙하 대상을 계산한다. 낮은 프레임에서 여러 낙하 시각을 넘겼다면 해당 발판들을 모두 순서대로 처리한다. 단순 1초 코루틴 누적으로 지연시키지 않는다. 일시정지는 시계·물리·적을 함께 정지한다.
4. 종료/이탈: 시계와 미실행 이벤트를 종료하고 4-4 전용 가속 고정을 해제한다. 권장안은 구간에서 부여한 가속을 제거하고 남은 일반 가속은 기존 5초 규칙으로 처리하는 출처 분리 방식이다. 영역 밖 영구 버프 누출을 금지한다.
5. 사망·재시작: 모든 낙하·위치·적·드롭·시계를 초기화하고 새 시도 시작 때 최대 가속을 다시 부여한다. 중복 진입 이벤트로 시계 재시작·발판 재생성을 허용하지 않는다.

구간 Manager는 시작/낙하 순서/종료만, 각 발판은 낙하 동작만, 가속 시스템은 버프 출처·유효기간만 담당하도록 분리한다. 반복 발판은 프리팹 기반으로 구성하고 Inspector·Manager 캐시·이벤트로 연결한다. GameObject.Find 및 매 프레임 동적 할당을 사용하지 않는다. 기존 접촉형 소멸 발판을 필드값 변경만으로 본 설계의 전역 순차 낙하로 간주하지 않는다.
