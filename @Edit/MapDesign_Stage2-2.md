# Stage2 - Section_2(2-2) 맵 설계안 (재설계, 2026-09-28)

> **구현 완료(2026-09-28)**: 사용자 승인("유니티에 적용해봐라")에 따라 `Stage2.unity` Section_2에 실제 배치를 완료했습니다. `Boundary_2_3`~`Boundary_4_5`/`Section_3`~`Section_4`를 +68 이동해 공간을 확보했고(Section_5는 별도 보스존 행이라 미이동), `ZoneEndPoint_2-2`를 로컬 x=8→77로 재배치, `Section_2`의 `CameraBoundsZone` 크기를 (20,8)→(160,16)으로 확장했습니다. 이동형 발판은 전용 프리팹이 없어 `MovingPlatform_Stage2_Jungle.prefab`(Rigidbody2D Kinematic + BoxCollider2D + `Platform_Stage2_Jungle` 스프라이트 + `MovingPlatform`)을 신규 제작했고, 소멸형은 `Foothold_Disappearing.prefab`을 복제해 `Foothold_Disappearing_Stage2_Jungle.prefab`(Visual 스프라이트만 정글 테마로 교체, 점멸형 때와 동일한 방식)을 만들어 사용했습니다. 배치 후 콜라이더 전수 겹침 검사 **0건**, Play 모드에서 이동형 발판 실제 이동 확인, 소멸형 발판이 밟은 뒤 실제로 사라지는 것까지 확인했습니다. 콘솔 에러 없음.
>
> 아래 좌표는 최초 설계안이며(로컬/상대 좌표계는 설계 그대로 유효), 실제 씬에서는 여기에 world offset(+70)이 더해집니다.

> **이전 이력**: 이전에 "점멸형 발판 20개만 사용" 컨셉으로 실제 구현까지 했으나, 사용자 지시로 전부 삭제하고 `Section_2`를 placeholder 상태(`ZoneEndPoint_2-2` 로컬 x=8, `Platform_Stage2_Jungle_2-2` 자리만 있는 빈 구간)로 되돌렸습니다. 이번 문서는 그 이후 사용자가 새로 지정한 조건(일반 발판 10개 + 서로 다른 경로의 이동형 발판 5개 + 소멸형 발판 3개)에 따른 완전히 새로운 설계입니다. **Unity 작업은 아직 진행하지 않았습니다** — 아래 내용을 검토 후 승인하시면 별도로 배치하겠습니다(LHS_Custumer.md 규칙 9·11, MapEdit.md 규칙 1).

## 1. 요청 사항 정리

- 컨셉 이미지 없이, 발판 유형과 개수를 정확히 지정: **일반 발판 10개 + 이동형 발판 5개(전부 서로 다른 경로) + 소멸형 발판 3개**, 총 18개.
- MapEdit.md 최신 수칙 준수:
  - 규칙 1: 코드/문서로 먼저 설계, Unity는 요청 시에만.
  - 규칙 11: 영역(카메라 줌 범위)이 모든 발판을 포함하도록 크게.
  - 규칙 13: 직선 구간은 발판을 쪼개지 않고 길이를 늘려서 배치(→ 이번 10개는 각자 역할이 다른 별개 구간이므로 해당 없음).
  - 규칙 14: 모든 발판 간 거리는 반드시 점프해야 닿는 거리(사이 간격 전부 ≥1.5유닛로 설계, 아래 표 참고).
  - 규칙 15: 이동 동선 거리를 1~100 척도로 산출(§5).

## 2. 기존 씬 데이터 확인 결과 (Stage2.unity, 라이브 씬 기준)

- `Section_2` 피벗 월드 x=51. `Boundary_1_2`(월드 x=23, 로컬 -28) ~ `Boundary_2_3`(월드 x=65, 로컬 +14) 사이, placeholder 간격 폭 42유닛.

- 이번 설계 폭(§4, 0~82.5유닛)이 placeholder 폭(42유닛)보다 넓으므로, 실제 배치 시 `ZoneEndPoint_2-2`를 옮기고 `Boundary_2_3` 이하(뒤따르는 영역 전부)를 그만큼 밀어야 합니다(1-3/2-1 때와 동일한 종류의 조정, §6-1 참고).

## 3. 설계 컨셉: "정글 짐(Jungle Gym) 구간"

일반 발판으로 리듬을 익히는 도입부 → 서로 다른 이동 패턴(수평 왕복/수직 승강/대각선/L자 순환/장거리 대각 왕복)의 이동형 발판 5개를 순서대로 타고 넘는 구간 → 마지막에 소멸형 발판 3개를 연속으로 밟아야 하는 긴장 구간 → 안정적인 마무리, 순서로 구성했습니다. 이동형 발판은 전부 **직접 점프로는 못 건너는 거리(6~7유닛)** 를 이어주는 용도로 배치해, "왜 이동형 발판이 필요한지"가 배치 자체로 드러나게 했습니다.

## 6. 비고 / 확인 필요 사항

1. **구간 폭 재조정 필요**: 이번 설계 폭(82.5유닛)이 현재 placeholder 폭(42유닛)보다 훨씬 넓습니다. 실제 배치 시 `ZoneEndPoint_2-2`를 로컬 x≈82.5 부근으로 옮기고, `Boundary_2_3`·`Section_3` 이하 전부를 그만큼(Δ≈41유닛) 뒤로 밀어야 다음 영역과 겹치지 않습니다(규칙 12).
2. **`CameraBoundsZone` 확장 필요**(규칙 11): 이번 설계는 Y가 0~3.2까지 오르내리므로, 기존 `Background_Forest`의 영역 크기도 이 X/Y 범위 전체를 포함하도록 재계산해서 넓혀야 합니다.
3. **이동형 발판 프리팹 신규 제작 필요**: 기존에 이동형 발판 전용 프리팹이 없어, `MovingPlatform`+`Collider2D`+정글 테마 스프라이트로 새 프리팹을 만들고, 각 인스턴스마다 자식으로 `PlatformPath`(경유점 Transform들)를 붙여야 합니다. (점멸형 때와 동일하게 외형은 스테이지 테마 스프라이트로, 기능 코드는 그대로 재사용)
4. **소멸형 발판**: 기존 범용 `Foothold_Disappearing.prefab`을 재사용할지, 점멸형 때처럼 정글 테마 외형으로 교체한 `_Stage2_Jungle` 변형을 새로 만들지는 실제 배치 시 확인이 필요합니다.
5. 기존 `Platform_Stage2_Jungle_2-2`(시작 지점 아래 placeholder)는 이번 설계의 N1이 대신하므로 제거 대상입니다.
6. 좌표/경로/타이밍은 설계 제안이며, 실제 배치는 Unity 작업이므로 사용자 승인 후 별도로 진행합니다(규칙 9, 11).
