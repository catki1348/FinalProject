## 실행 방법

1. **Unity Editor 열기**
   - `Assets/Scenes/Stage2.unity` 열기

2. **배치 스크립트 실행**
   - 메뉴: `Tools > Deploy > Stage 2-1 배치`
   - 자동으로 다음 작업 수행:
     - Section_1 생성 (미존재시)
     - 6개 발판 배치
     - ZoneStartPoint/EndPoint 설정
     - CameraBoundsZone 설정
     - 씬 자동 저장

3. **검증**
   - Play 모드 진입
   - 플레이어가 각 발판을 정상 밟는지 확인
   - 갭 점프 안정성 검증
