# 1-2 — 점프 착지로 유도하는 Z 진행

2026-10-08. 이전 연속 Z 발판·보호 터널 설계는 완전히 폐기한다. Unity의 Map_1-2_Z를 제거하고 Map_1-2_JumpRoute로 교체했다.

## 원칙

**Z는 플레이어의 진행 방향이다. 발판 자체를 Z로 이어 그리지 않는다.**
독립된 점프 발판과 착지점의 높이·간격으로 오른쪽 → 왼쪽 아래 → 오른쪽 진행을 유도한다.
기존 잔디·돌 외형과 짧은 곡선 형태를 사용한다. 하강 B1~B8은 아래 변경안의 움직이는 발판이며, 긴 대각선 슬라이드 발판·연결 레일·Z 터널은 사용하지 않는다.

## 진행

| 구간 | 플레이 | 유도 |
|---|---|---|
| A0~A10 | 오른쪽으로 점프 이동 | 높이가 조금씩 다른 짧은 독립 발판 |
| A10→B1 | 왼쪽 아래로 방향 전환 | 오른쪽 발판이 끝나고 왼쪽 아래 착지점이 보임 |
| B1~B8 | 왼쪽 아래로 점프·착지 반복 | 수평 발판을 서로 다른 낙차와 간격으로 배치 |
| B8→C1 | 오른쪽으로 방향 전환 | 왼쪽 발판이 끝나고 오른쪽 다음 발판이 보임 |
| C1~C10 | 오른쪽으로 점프 이동 후 종료 | 높낮이가 다른 독립 발판과 마지막 종료점 |

총 29개 발판, 28개 점프 구간이다. 발판은 모두 독립되어 있으며 사이를 연결하는 충돌면을 만들지 않는다.
A3·A7·C3·C7은 짧은 곡선 형태를 사용하되 착지 중앙부는 평탄하게 유지한다. B1~B8은 수평 표면의 움직이는 발판이고, 나머지는 수평 일반 발판이다.

## 점프와 낙하 유도

- 상단·하단의 작은 높이 차와 빈 공간은 점프로 통과한다. 독립 발판 사이를 걷기만 해도 건너가는 작은 틈은 만들지 않는다.
- 하강 발판의 모서리 간 간격은 약 7.66~8.25유닛이다. 낙차는 약 7.76~9.25유닛이다.
- 속도 8, 점프 상승 속도 9, 중력 29.43, 보수적 플레이어 폭 1.33을 기준으로 B1~B8 모두 걸어서 떨어지는 도달 한계보다 멀고 점프 도달 한계보다 가깝게 계산했다.
- 다음 발판은 카메라에 미리 보이도록 한다. 첫 왼쪽 하강 착지점이 화면 밖에 숨지 않게 한다.
- 상단에서 하단 종료로 바로 떨어지는 우회는 높이별 추락 판정으로 막는다. 정상 점프 궤적과 착지점을 충분히 포함하는 통과 공간을 남긴다.
- 발판을 바로 아래에 쌓아 여러 착지점을 건너뛰는 배치를 피한다. 진행 표시는 보조로만 사용하며 배경에 Z 선을 그리지 않는다.

## Unity 적용 시

1. Map_1-2_Z와 전용 보호 레일을 제거하고 독립 발판 29개를 새로 생성한다.
2. 발판별 콜라이더만 사용한다. 발판 사이를 이어 그리는 EdgeCollider2D는 금지한다.
3. 새 시작·종료점과 카메라·배경·추락 판정을 조정하고 다른 영역과 겹치지 않게 배치한다.
4. 1-1 진입 연결, A10→B1과 B8→C1의 방향 인지, 28개 점프를 임시 Test 번호 씬에서 확인한다.
5. 실제 플레이어 궤적이 오른쪽·왼쪽 아래·오른쪽 순서로 진행하는지 확인한다. 단순히 발판 배치의 외곽이 Z인지 검사하는 것으로 대체하지 않는다.

## 하강 이동 발판 변경 — 2026-10-08

B1~B8을 기존 잔디·돌 외형의 MovingPlatform으로 교체한다. A·C 구간은 유지한다.
총 29개 중 고정 발판 21개, 움직이는 발판 8개다. 이전 B 좌표는 고정 위치가 아니라 이동 경로의 중심이다.

- 각 발판의 한쪽 끝→반대 끝 이동 거리: **2 = 16유닛**. 왕복 이동량은 32유닛이다.
- 모든 경로는 동일한 왼쪽 아래 45도 방향의 평행 경로. 플랫폼 표면은 수평을 유지한다.
- 이동 속도 2유닛/초. 편도 8초, 왕복 주기 16초. PingPong으로 같은 경로를 돌아온다.
- 시작점은 중심에서 오른쪽 위로 8유닛, 끝점은 중심에서 왼쪽 아래로 8유닛.
- 인접 발판은 출발 시간을 2.5초씩 다르게 한다. 모두 같은 순간에 출발시키지 않는다.
- 승객이 점프하면 발판에서 분리된다. 공중의 목표 발판이 이동하는 위치를 기준으로 착지를 계산한다.

### 점프로 건너가는 시간대

출발 시간과 왕복 위상으로 발판 사이 간격이 변한다. 다음 발판이 접근해 점프 가능한 간격에 들어올 때 이동한다.
각 발판의 경로 길이가 16유닛이라는 뜻이며 발판 사이 간격을 16유닛으로 고정한다는 뜻은 아니다.

다음은 게임 시작 후 32~48초 구간에서 찾은 **설계용 예시 시간대**다. 정상 왕복 상태에서는 16초마다 반복한다.
이동하는 목표의 착지 시각 위치를 계산했다. 점프 상승 속도 9, 중력 29.43, 공중 수평 속도 최대 8을 사용했다.
0.1초 단위 출발과 0.02초 단위 비행 시간을 표본 계산한 결과이며 실제 Unity 착지 보장은 아니다.

| 이동 | 점프 출발 예시 시간대 |
|---|---|
| B1→B2 | 40.5~47.9초 |
| B2→B3 | 43.1~47.9초 |
| B3→B4 | 32.0~38.2초 |
| B4→B5 | 32.2~40.2초 |
| B5→B6 | 34.5~42.9초 |
| B6→B7 | 37.1~45.2초 |
| B7→B8 | 39.7~47.4초 |

시간대 계산에는 모서리 간 간격이 단순 걸어 떨어짐의 보수적 도달 한계보다 0.2유닛 이상 멀다는 조건을 포함했다.
표의 모든 시간대에 최대 속도를 고정하는 방식이 아니라 목표 위치에 맞춰 공중 수평 이동량을 조절한다.
해당 창 밖에서도 걸어 떨어지거나 점프로 접근할 가능성은 있으므로, 모든 시점의 점프 강제를 보장하는 것으로 해석하지 않는다.

A10→B1은 B1이 너무 멀어지기 전에 진입할 수 있는 창을, B8→C1은 B8이 중간 높이로 돌아와 점프로 이탈할 수 있는 창을 별도로 확보한다.
B8의 가장 낮은 위치에서 C1로 올라가게 설계하지 않는다.
추락 판정의 안전 통과 공간은 기준 좌표만이 아니라 각 발판의 전체 왕복 범위와 정상 점프 궤적을 포함한다.

### 길이와 검증 범위

기준 경로 30은 각 이동 경로의 중심점을 순서대로 연결한 길이로 유지한다. 발판을 타고 기다리는 동안의 추가 이동은 실제 플레이 동선에 더해진다.
Unity 적용 시 7개 인접 쌍 및 양 끝 진입·이탈을 각각 검사하고, 한 번의 연속 플레이로 전 구간 통과가 가능한지도 확인한다.
발판의 전체 주기 동안 충돌·겹침과 정상 동선의 추락 판정 간섭이 없는지 확인한다. Unity Stage1의 Section_2에 적용했다. 실제 플레이어의 전 구간 연속 통과 확인은 아직 완료하지 않았다.
