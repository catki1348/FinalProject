# 2-3 최신 발판 업데이트 설계 — v10

상태: **업데이트 설계안 / Unity 미적용**. 기존 v9의 발판·몬스터 구성은 유지하되 2026-10-12 이후 Tiled 규격과 MapEdit 18·20~23, MovingPlatform_IdealLayout을 적용한다. 이 문서가 기존 MapDesign_Stage2-3.md의 v9 이하 발판 설명보다 우선한다. 수치 초안과 적용 전 통과 조건을 구분한다. 현재 씬을 새 설계로 업데이트했다는 의미는 아니다.

## 유지하는 구성

- 이동거리 **30 = 240유닛**. 이번 2-3은 5-3의 거리75를 가져오지 않는다.
- 일반14개(Start/Goal/Rest1/Rest2/N1~N10), 이동형7개(M1~M7), 합계21개. 소멸·피해·점멸형을 추가하지 않는다.
- 이동형마다 **5개 이상의 경유점**, PingPong. 경로는 모양을 보여주기 위한 장식이 아니라 실제 탑승 이동 경로다.
- 몬스터30마리: 일반 중간 발판12개에 지상형12, 이동 동선의 공중 경유점에 비행형18. 시작·골인에는 배치하지 않는다. 기존 확정 외형·애니메이션과 일반 드롭 규칙을 유지한다.
- 기본 진행 순서: Start → M1 → N1,N2,N3 → M2 → N4,N5,Rest1 → M3 → N6,N7 → M4 → N8,N9,Rest2 → M5 → N10 → M6 → M7 → Goal.

## 1. 외형·충돌 규격 업데이트

일반과 이동형 모두 같은 기준을 사용한다.

| 항목 | 신규 기준 |
|---|---|
| Transform | localScale=(1,1,1), 상위 오브젝트 배율까지 확인 |
| SpriteRenderer | Tiled / Continuous, size로 폭·두께 지정 |
| 스프라이트 | Full Rect. 기존 정글 외형을 재사용하며 반복 경계에 투명 틈이 있으면 전용 반복 에셋 사용 |
| 콜라이더 | BoxCollider2D autoTiling=false, size·offset으로 윗면과 외형 일치 |
| 두께 | 0.5유닛 초안, 경로 좌표는 항상 발판 윗면 기준 |
| 일반 폭 | N1~N10 최소3.0, Rest1/2 최소4.0, Start/Goal 최소4.0 초안 |
| 이동형 폭 | 3.0 초안, 모든 이동형 공통 |
| 이동 물리 | Kinematic, gravityScale=0, 외부 PlatformPath 명시 연결 |

기존의 ‘Tiled가 잘려 보이면 Simple+Scale로 전환’ 해결책은 폐기한다. 반복 원본의 여백·Mesh Type·Border를 해결하며 이미지를 늘려서 맞추지 않는다. 넓어진 발판 때문에 간격이 사라지지 않도록 **폭 변경과 좌표 재배치를 함께** 수행한다. 기존 중심 좌표에 새 폭만 대입하는 방식은 금지한다.

## 2. 일반↔이동형 승하차

M1~M5와 M6 진입/ M7 종료는 앞뒤 일반 발판에서 각각 독립적으로 탑승·하차한다.

- 승하차 끝점에서 가장자리 공백 **2.4~3.0**, 상승 단차 **0~0.5**를 목표로 한다. 점프 높이80% 이내에서 통과 가능하도록 한다.
- 경유점의 높이 굴곡은 탑승 중 경험하게 하고, 승하차 순간에 다음 발판이 머리 위로 멀어지는 구조를 피한다.
- 끝점 대기 **0.35초**로 승하차 입력 시간을 준다. 중간 경유점에서 정지하지 않는다.
- 정적 간격만 검사하지 않고, 발판의 도착 전후 이동을 포함한 점프 궤적을 검사한다. 발판 옆면 충돌과 아래쪽 충돌도 실패로 센다.
- 기본 이동속도8, 점프 상승속도9, 중력29.43, 플레이어 충돌 폭0.98을 설계 기준으로 사용한다. 실제 프리팹 값이 다르면 적용 전 재계산한다.

## 3. 이동 경로·속도 초안

| 발판 | 유지할 역할 | 기본 속도 | 최초 지연 | 끝점 대기 |
|---|---|---:|---:|---:|
| M1 | 첫 완만한 5점 파형, 탑승 학습 | 4.8 | 0.0 | 0.35 |
| M2 | 오르내림이 있는 파형 | 5.2 | 0.35 | 0.35 |
| M3 | 상승 후 완만한 하강 | 5.6 | 0.70 | 0.35 |
| M4 | 하강 후 복귀하는 굴곡 | 5.0 | 1.05 | 0.35 |
| M5 | 후반 교차 쌍 진입 전 파형 | 5.4 | 1.40 | 0.35 |
| M6 | 교차 인계의 출발 이동형 | 5.8 | 0.20 | 0.35 |
| M7 | M6와 경로가 교차하는 도착 이동형 | 6.2 | 0.65 | 0.35 |

속도·지연은 **시뮬레이션 탐색의 초기값**이다. 표 자체를 검증 완료된 운행표로 취급하지 않는다. 기본 속도가 서로 다른 M6/M7의 위상이 장시간에 걸쳐 달라져도 인계 기회가 반복되는지 확인한다. 시야 밖 배율은1.0으로 시작하고 M6/M7의 대기를 별도 가속으로 숨기지 않는다.

편도 경로 길이는 **5점 사이 거리의 합**으로 계산해 각56유닛 이하를 요구한다. 옛 문서처럼 가장 긴 한 선분만 보고 ‘이동거리 제한 준수’라고 판정하지 않는다. 240 거리 예산을 맞출 때는 파형의 수평 길이와 일반 발판 길이를 조정하고, 점프 간격을 통과 불가능하게 벌려 보정하지 않는다.

## 4. M6→M7 — 교차 인계로 변경

기존 끝점 사이 간격만 맞추는 연결을 **실제로 경로가 교차하는 연결**로 대체한다. 새 일반 발판을 중간에 추가해 우회하지 않는다.

- 두 5점 경로의 일부 선분은 같은 공간의 교차점 C를 지난다. C는 두 경로의 끝점이 아니라 적어도 한 경로의 내부 선분/경유점이어야 한다.
- M6의 후반 운행 구간과 M7의 초반 운행 구간을 교차시켜, M6에 탑승한 플레이어 근처로 M7이 접근한다.
- C에서 두 발판을 동시에 겹쳐 태우는 것이 목적이 아니다. 교차점에 도달하기 전후의 **점프할 틈이 있는 구간**을 인계 구간으로 잡는다.
- 인계 중 가장자리 공백 **0.5 초과~3.0 이하**, 상승 단차 **0.5 이하**. 기본 속도 기준 점프 가능한 창이 반복되어야 한다. 80% 점프 성능 검증도 함께 한다.
- 교차 경로의 전체 스윕 사각형은 겹칠 수 있다. 따라서 이 쌍에 옛 ‘스윕 사각형 겹침0’ 검사를 그대로 적용하지 않는다. 대신 **같은 시각의 실제 발판 사각형 충돌·끼임·탑승자 이중 운반**을 검사한다.
- 동시 충돌이나 긴 대기가 발생하면 교차점 전후 경유점·두 경로 길이·지연·대기 시간을 함께 재탐색한다. 충돌을 무시하는 레이어나 순간이동을 임의 도입하지 않는다.

## 5. 거리 정의와 재배치 원칙

거리240은 플레이어가 진행하는 **기준 동선**으로 다시 계산한다. 시작/골인 발판 기준점, 일반 발판 기준점, 이동형 탑승점·하차점과 탑승 중 통과하는 경로를 순서대로 연결한다.

M6→M7은 실제 인계 창의 대표 점프 시각에서 이륙·착지 좌표를 기준점으로 지정한다. M6의 남은 경로와 M7의 이미 지나온 경로를 다시 더하지 않는다. 각 발판의 전체 편도 경로 한계 검사는 별도로 수행한다. ‘발판 폭+경로가 차지하는 가로 범위+간격’을 실제 탑승 동선과 혼용하던 기존 계산은 폐기한다.

정확한 240유닛 좌표는 **교차 인계 운행표가 통과된 뒤** 역산한다. 기존 v8 좌표나 이번 속도 초안을 최신 확정 배치 좌표로 오인하지 않도록 새 사양 JSON에는 `placementReady=false`로 표시한다. 이 단계에서는 새로운 좌표를 수치 검증 완료로 주장하지 않는다.

## 6. 몬스터와 영역 후속 조정

- 12개 일반 발판 위 지상형은 넓어진 발판 안에서만 순찰하게 하고 가장자리 추락을 방지한다. 접촉 센서·플레이어 착지 면을 가리지 않게 한다.
- 비행형18마리는 수정된 경로의 동선상에 다시 맞춘다. 원본 위치에 남겨 플레이어가 안 지나는 공중에 뜨게 하지 않는다.
- 특히 M6/M7의 교차 인계 창에는 몬스터를 직접 겹쳐 놓지 않고, 같은 이동 동선의 진입 전·하차 후 구간으로 옮긴다. 총수와 비행형 분류는 유지한다.
- 새 폭·전체 경로·비행 경로를 포함해 영역을 재산정한다. 옛 ‘경계 추가 이동 불필요’ 설명은 더 이상 적용 확정값이 아니다.
- 실제 적용 때 2-4 및 경계를 함께 평행 이동할 수 있으며 2-5는 하단 중앙 배치 기준을 유지한다. 카메라·시작/종료·낙사선도 함께 확인한다.

## 8. 몬스터 최신 기준 개정 — 경로 직접 충돌 금지

**이 항목은 §6의 몬스터 배치 및 이전 v9의 ‘이동형 경유점 위에 몬스터 배치’ 설명을 대체한다.** 플레이어의 진행 중 조우하는 위치라는 의미로 동선상 배치를 유지하되, 움직이는 발판이 통과하는 공간에 몬스터를 놓지 않는다.

### 충돌 금지의 판정

- 이동형 발판 7개의 **전체 경로를 따라 콜라이더가 차지하는 공간**과 몬스터30마리 각각의 **전체 경로를 따라 콜라이더가 차지하는 공간**이 교차하지 않아야 한다. 특정 같은 시각에만 충돌하지 않는 배치로는 통과시키지 않는다. 속도·지연이 바뀌어도 공간 분리가 유지되어야 한다.
- 중심선이나 경유점만 비교하지 않는다. 발판 폭·두께·콜라이더 offset과 몬스터 실제 크기·offset·Scale을 모두 반영한다. 직선 경유점 사이, 왕복 반환 구간, 순환 경로의 마지막→첫점 연결, 원형 대기 범위도 포함한다.
- 두 실제 충돌 공간 사이 최소 여유 **0.5유닛을 초안**으로 둔다. 이 값은 플레이어와 몬스터의 전투 거리와 별개다. 너무 높은 공중 배치로 공격·아이템 획득이 불가능해지면 몬스터 경로를 옆으로 이동시키거나 해당 조우를 일반 발판 인근으로 조정한다. 이동형 경로와 겹치게 되돌리지 않는다.
- 전체 경로 AABB는 빠른 후보 검사에만 쓴다. AABB가 겹치더라도 실제 선분별 스윕이 떨어져 있을 수 있으므로, 최종 판정은 콜라이더를 확장한 선분 스윕/도형 교차로 한다.
- 적용 후보가 하나라도 이 조건을 위반하면 위치·경로를 다시 산출한다. 몬스터와 발판의 충돌 레이어를 끄는 것만으로 살아 있는 몬스터의 경로 충돌을 해결했다고 보고하지 않는다.

### 지상형12마리

N1~N10 및 Rest1/Rest2에 각각1마리, Start/Goal에는0마리. 일반 발판 위 스폰, 중력 적용, `PathPatrolPattern`과 독립 `PlatformPath`를 사용한다. 경로 끝점은 양 끝에서 **몬스터 콜라이더 반폭+0.5**만큼 안쪽으로 제한한다. 기존의 폭0.6 정찰 영역 고정값은 폐기하고 최신 발판 폭에 맞춰 재산출한다.

지상형의 걷는 경로·몸체도 모든 이동형 발판의 스윕에서0.5 이상 떨어져야 한다. 일반 발판 위에 있다는 이유만으로 안전하다고 판정하지 않는다. 승하차 가장자리와 플레이어의 착지 예상 면에는 두지 않는다.

### 비행형18마리

| 조우 구간 | M1 | M2 | M3 | M4 | M5 | M6 | M7 | 합계 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 비행형 수 | 3 | 3 | 2 | 2 | 2 | 3 | 3 | 18 |

이 표는 전투 조우의 소속이며 몬스터가 이동형에 탑승한다는 의미가 아니다. 각 몬스터에게 별도 `FlyingPathPatrolPattern`과 독립 `PlatformPath`를 지정하고 공중 스폰·중력0·발판 비착지 원칙을 지킨다. 경로는 발판 경로를 그대로 복사하지 않고 위쪽 또는 옆쪽으로 이동한 독립 통로에서 왕복한다.

기존 ‘경유점 Y+0.5에 배치’, ‘중력만0으로 바꾼 지상 패턴’, ‘이동형 위에 서서 함께 운반되는 비행형’ 방식은 폐기한다. 경로 없는 비행종의 기본 체이서 동작에 의존하지 않는다. 이번2-3은 명시적 경로를 쓰므로 무제한 추격으로 안전 통로를 벗어나지 않는다. 향후 추격형으로 변경하면 추격·복귀·원형 대기를 포함해 같은 금지 공간을 지키도록 제한해야 한다.

M6/M7 인계 구간, 각 승하차 구간에는 몬스터 몸체·이동 경로를 배치하지 않는다. 이 두 구간 소속6마리는 교차점에 몰지 않고 M6 진입 전 및 M7 하차 후 플레이어가 조우할 수 있는 공중 통로로 분산한다. 물리적 조우 공간이 부족하면 일반 발판 폭·배치를 조정하되30마리 총수와 지상12/비행18 분류를 유지한다.

### 공통 최신 기준과 사망 처리

- 크기는 플레이어의50%. 확정된 기존 외형·비행 애니메이션을 재사용한다. 공격력/방어력 기본10, 체력은 현재 프리팹 값을 확인하여 보존하며 미확인 값을20으로 임의 확정하지 않는다.
- 스탯·이동 패턴·드롭은 분리한다. 일반 몬스터 드롭은 최신 ItemDropDesign 기준: 가속100%, 소형회복10%(저체력20%), 대회복10%(저체력만), 무장복귀5%(무장해제만). 분노·확정 회복을 추가하지 않는다.
- 사망 위치 드롭 원칙을 유지한다. 비행형 사망 후 중력 낙하가 이동형을 관통/가로막는 문제는 별도 검사한다. 우선 낙하 통로도 발판 스윕에서 분리하고, 불가능한 경우 **사망한 잔해에 한정해** 발판과 물리 충돌을 해제하는 구현안을 사용한다. 살아 있는 비행형의 플레이어 전투 충돌은 유지한다. 해당 잔해 처리도 아직 구현한 상태가 아니다.
- 무장/비무장 등 실제 플레이어 크기가 달라지는 경우 크기50% 기준과 검증용 몬스터 콜라이더를 함께 갱신한다.

### 산출물과 검사 상태

`Generate_Stage2-3_Monsters_v10.ps1` → `MapDesign_Stage2-3_Monsters_v10.json`에30개 몬스터의 고유ID·종류·소속·패턴·금지 영역·드롭 사양을 기록했다. 총수30/지상12/비행18/ID중복0 검사는 통과했다.

발판 좌표·운행표가 아직 미확정이므로 몬스터 경로 좌표도 임의로 확정하지 않았다(`coordinates=null`, `placementReady=false`). **경로 충돌0을 검증했다고 주장하지 않는다.** 좌표가 정해지면 모든 이동형×모든 몬스터(7×30=210쌍)의 전체 스윕 공간, 비행종 사망 낙하, 몬스터끼리의 순찰 간섭, 실제 검 공격 도달·드롭 획득 가능성을 검사한 뒤 배치 준비 완료로 전환한다. 이번 작업은 설계 수정이며 Unity 씬·프리팹은 변경하지 않았다.
