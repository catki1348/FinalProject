# 아이템 설계 충돌 검토 — 사용자 정정 반영

검토·정정: Codex (GPT-6), 2026-10-14 (KST)
수칙: LHS_Custumer.md 확인. 문서만 수정했으며 Unity·코드·프리팹은 변경하지 않았다.

## 확정 사항과 기존 지적 정정

- 보스는 일반 아이템을 드랍하지 않는다. 전용 아이템은 추후 설계한다. 일반 드로퍼와 보스 사망 이벤트의 연동 필요 지적은 철회한다.
- 함정 및 함정 스폰 몬스터는 모든 아이템을 드랍하지 않는다. 기존 함정 문서의 가속 드랍 설정과 필드명 안내는 폐기 대상이다.
- 아이템별 수명 차이는 의도된 설계다. 수명 차이를 충돌로 분류한 지적은 철회한다.
- 무장 복귀 아이템은 무장해제 상태를 무장 상태로 회복한다. 갑옷 장비 및 외형과 무관하며, 갑옷 외형 보장 문제는 아이템 설계 충돌에서 제외한다. 기존 전체 체력 회복 효과는 유지한다.
- 드랍은 사망 위치 그대로 생성하며 좌우 분산하지 않는다. 생성 후 해당 위치를 기준으로 조금씩 상하로 흔들리는 부유형으로 표현한다. ItemDropDesign.md의 좌우 분산 규정을 정정했다.

## 남은 구현 설계 검토 사항

- PlayerHealth.Active의 정적 인스턴스 등록은 향후 Unity 구현 시 수칙 35·36의 플레이어 싱글톤 금지/Manager 캐싱 기준에 맞춰 정리할 필요가 있다. 방식이 확정되지 않은 항목이므로 이번 정정에서 임의로 변경하지 않았다.
- 플레이어가 없을 때 조건부 드랍(저체력 대회복·무장 복귀)을 어떻게 처리할지 명시가 필요하다.
- 기존 직렬화 필드의 DropEntry 이전과 가속 배율의 중첩 설정 전환 방법은 구현 시 구체화해야 한다.
- ActiveMaxHealth는 현재 private이지만 제안된 HealthRatio가 내부에서 계산하면 문제없다.

현재 코드와 새 설계의 차이는 미구현 사항으로 구분한다. 관련 몬스터·함정·맵 문서에는 이전 드랍 안내가 남아 있어 이번 사용자 확정 사항을 알리는 정정 주석을 추가했다.
