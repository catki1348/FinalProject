## 1. 부적합 항목과 수정

| 검수 부적합 | 수정 설계 |
|---|---|
| 18개 발판이 Simple이고 일반 발판이 Scale로 늘어남 | 전부 Scale (1,1,1), Tiled / Continuous, Size로 폭 지정 |
| 이동·소멸 동작이 일반 프리팹의 씬 오버라이드에만 존재 | 일반·이동·소멸 전용 프리팹 원본 3종에 동작 구성 |
| N8→D2, D1→D3 점프로 소멸 발판 생략 가능 | 소멸 발판 폭 1.6, 가장자리 간격 3.8, 매 점프 표면 상승 0.4 |
| 유닛을 척도로 혼용하고 구현 상태가 충돌 | 1척도=8유닛, 기준 동선과 산식을 명시하고 문서 상태 분리 |

일반 10개, 이동형 5개, 소멸형 3개로 총 18개를 유지한다. 이동 경로 5종, 속도 2, 시작 지연 0, 경유 대기 0은 유지한다. 각 이동형 사이에 고정 발판이 있으므로 연속 이동형 쌍에 관한 속도·위상 차등 규칙의 대상은 없다. 고정 발판 사이에는 실제 점프가 필요한 틈을 둔다.

## 2. 배치 좌표

좌표는 **월드 좌표**, Y는 콜라이더 윗면이다. 중심 Y=윗면 Y−두께/2. 일반·이동 두께는 1.05, 소멸 두께는 1.0이다. 이동형 좌표는 첫 경유점 기준이다. 실제 중심·렌더러 크기·콜라이더 크기는 첨부 JSON에 기록했다.

소멸 구간 순서는 **N8 → D1 → D2 → D3 → N9**다. 네 틈의 가장자리 간격은 모두 3.8이며, 착지면은 매번 0.4씩 상승한다. 각 소멸 발판은 밟은 뒤 0.4초에 사라지고 2초 후 복구한다. 발판 중앙을 향해 연속 점프하도록 설계하며, 착지 후 오래 기다려야 하는 동작은 넣지 않는다. N9와 N10은 기존보다 X +11.25, Y +1.6 이동한다.

## 3. 이동 경로

아래 경유점도 **표면 좌표**다. 실제 경로 오브젝트에는 각 Y에서 0.525를 뺀 중심 좌표를 사용한다. 경로는 발판의 자식이 아닌 외부 오브젝트로 두고 참조를 연결한다.

| 발판 | 표면 경유점 | 방식 |
|---|---|---|
| MP1 | (84,0.525) ↔ (90,0.525) | 수평 왕복 |
| MP2 | (96,0.525) ↔ (96,3.725) | 수직 왕복 |
| MP3 | (102,3.725) ↔ (108,1.225) | 우하향 대각 왕복 |
| MP4 | (114,1.225) → (118,1.225) → (118,3.725) → 시작 | 폐순환 삼각 경로 |
| MP5 | (124,3.725) ↔ (131,2.025) | 완만한 우하향 왕복 |

최장 편도 경로는 MP5의 약 7.204유닛이다. MP4의 폐순환 전체 길이도 약 11.217유닛으로 제한 56유닛(척도 7) 이하다. 모델에서 이동형을 기다리는 연속 불가 구간은 최대 3.9초였다. 발판을 바라보며 고정 발판에서 탑승 시점을 선택할 수 있도록 경로를 유지한다.

## 4. 외형·프리팹 명세

프리팹 예정 경로는 `Assets/@ExternalAssets/@Prefab/Stage2_2/`이며 다음 3종을 제작한다. 전용 프리팹 3종과 반복용 스프라이트를 생성해 적용했다.

- `P_Stage22_Normal.prefab`: 정글 발판 외형, 명시적 BoxCollider2D.
- `P_Stage22_Moving.prefab`: 이동형 원본에 MovingPlatform과 필요한 Kinematic Rigidbody2D 구성. 씬 인스턴스에서는 외부 경로 참조와 배치별 수치만 지정한다.
- `P_Stage22_Disappearing.prefab`: 소멸 동작과 외형 복구 참조를 원본에 구성. 0.4초 소멸·2초 복구를 기본값으로 저장한다.

부모까지 유효 Scale (1,1,1), SpriteRenderer Tiled / Continuous, renderer.size=설계 폭·두께, BoxCollider2D.autoTiling=false, collider.size=동일 폭·두께, offset=(0,0)을 기준으로 한다. 기존 콜라이더 윗면을 유지한다.

정글 무늬는 여백 없는 전용 반복용 스트립을 사용하고 Full Rect로 설정한다. 공용 원본의 이미지·임포터를 바꿔 다른 영역에 영향을 주지 않는다. 가장자리 장식이 필요하면 Sprite Border로 처리한다. 길이 변경 때문에 이동 속도·경로·소멸 시간이 달라지지 않게 한다.

## 5. 영역과 거리

2-2 카메라 영역은 X=[50,172], Y=[-8,8]로 확장한다. 다음 영역 침범을 막기 위해 Section_3·Section_4와 Boundary_2_3·Boundary_3_4·Boundary_4_5 및 해당 영역의 종속 오브젝트를 X +12 이동하는 것으로 계획한다. 오브젝트가 부모·자식으로 연결돼 있으면 한 번만 이동한다. 2-3 영역 X=[172,433], 2-4 영역 X=[433,504]로 서로 맞닿게 한다. 보스 영역은 아래 행 Y=-60을 유지하고, 1~4영역 전체 범위 [-31.95,504]의 중앙 X=236.025로 영역 전체를 옮긴다.

거리 척도는 기본 이동 속도 8유닛/초를 사용해 **1척도=8유닛**으로 계산한다. 기준 동선은 N1의 시작 X부터 N10의 종료 X까지 순서대로 진행하면서 고정 발판 위 걷기, 발판 사이 직선 점프 연결선, 이동형의 탑승 경로 편도를 합한 길이다. 점프 포물선, 대기 시간과 왕복 복귀는 포함하지 않는다. MP4는 탈출 전까지 두 변의 탑승 거리만 합한다. 이 정의는 모든 거리 수치에 동일하게 적용한다.

기준 동선 합계는 **99.257450유닛 / 척도 12.407181**다. 상세 분해와 동선 꼭짓점은 JSON의 `distance`에 저장했다. 기존 문서의 88.9유닛을 척도 89로 표현한 것은 단위 오류이며, 88.9유닛 자체의 환산값은 척도 11.1125이다. 새 동선은 위의 명시적 산식으로 재계산한 값이다.

## 6. 검증 결과와 적용 완료 조건

코드 계산 모델에서 인접 17쌍은 모두 수평 이동 속도 상한 6.4(기본 속도의 80%)에서 착지 가능한 시점이 존재했다. 점프 초기 속도 9, 중력 29.43, 실제 플레이어 폭 약 0.983을 사용했다. 60초 범위의 출발 시점을 0.1초, 비행을 0.01초 간격으로 샘플링했다. 이는 최대 속도를 80%로 제한한 도달성 검사이며 점프 높이까지 80%로 낮춘 검사는 아니다.

소멸 구간에서 중간 발판을 하나 이상 생략하는 6쌍은 최대 가속 5중첩(속도 10), 공중 대시 1회(거리 1.125, 지속 0.2초), 대시 중 수직 속도 초기화를 포함한 상한 계산으로 차단됐다. 최소 생략 틈 9.2에 대해 이상적 도달 상한은 7.965, 0.08초 시간 여유와 0.05유닛 접촉 여유까지 더한 상한은 8.815로, 최소 여유는 약 0.385유닛이다. 해당 착지면 도달 전에 두 번째 대시 쿨다운이 끝나지 않는 조건도 확인했다.

**Unity에서 구조 111개·물리 29개 검사와 소멸 구간 연속 통과, 실제 타이머, 종료점 전환을 확인했다.** 아래는 적용 완료 판정에 사용한 기준이다. 전체 구간의 수동 연속 완주 검사는 별도로 수행하지 않았다.

1. 18개 발판의 개수·콜라이더 좌표와 유효 Scale, Tiled/Continuous 설정이 저장 후에도 일치한다.
2. 이동·소멸 컴포넌트가 각 전용 프리팹 원본에 존재하고, 이동 경로 5개가 실제로 연결돼 한 주기 이상 정상 작동한다.
3. 기본 성능과 80% 이동 상한에서 17개 연결을 통과하며, D1→D2→D3 연속 점프를 실제 소멸 시간 내에 완주한다.
4. 기본·최대 가속·대시 사용 시 중간 소멸 발판 생략이 불가능한지 실제 물리로 확인한다.
5. 확장 카메라·후속 영역·하단 보스존이 겹치지 않고, N10 종료점에서 2-3으로 정상 이동한다.
6. 반복 무늬의 늘어짐·여백·이음새와 콘솔 오류가 없음을 확인한다. Unity 테스트는 프로젝트 수칙에 따른 임시 Test 씬에서 수행한다.
