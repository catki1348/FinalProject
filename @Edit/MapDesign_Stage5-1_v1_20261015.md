### 구간 1 — 1-1 (이동거리 15)
- 지상 레인: 0 → 116.8의 **긴 발판 하나**(규칙 13), 구멍 없음. 70%·88% 지점에 높이 0.8 단차 블록(폭 4) 2개. 동선 = 레인 길이 + 블록 상하 1.6 × 2 = 120.
- 상단 점프 체인(선택 경로): ST1(+0.8), ST2(+1.6), U1~U4(+2.4, 폭 8.8~9.0, 틈 3.4~3.6). 틈은 80% 점프(수평 약 4.4)로 닿고 걸어서 건널 수 없다. 상단에서 떨어지면 지상 레인에 착지한다.
- 1-1 원본의 6칸·블록 3개·몬스터 11마리 중 길이에 맞춰 4칸·블록 2개로 줄였다. 몬스터·가속 드랍은 이번 설계에 넣지 않았다.

### 구간 2 — 2-1 (이동거리 15)
- 2-1의 한 단위(시작 4.0 → 디딤돌 1.0 → 언덕 3.0(+0.8) → 중간 6.0 → 긴 발판 → 쉼터 4.5, 간격 2.5 / 2.5 / 2.0 / 3.5 / 2.5)를 3번 반복했다. 이동형·함정 없는 튜토리얼 구성 그대로다.

### 구간 3 — 3-1 (이동거리 15)
- 12구간(간격 단위), 중심 간 거리 120 / 12 = 10.0, 수평 간격 9.96, 폭 7.96, 공백 2.0. 일반 → 피해 → 이동 순서(3-1과 같음), 높이 ±0.9.

- 마지막 발판 P12(일반)는 4구간 고리의 시작 발판이다.

### 구간 4 — 4-1 (이동거리 15)

## 확인이 필요한 사항

1. **구간 길이 변환**: 1-1·3-1·4-1은 줄이고 2-1은 3번 반복해 늘렸다. 원본과 같은 발판 수·비율을 요구한다면 알려 달라.
2. **4구간 고리**: 원본 팔각형(이동형 6) 대신 이동형 4개 소형 고리다. 이동거리 15에서는 팔각형을 유지할 수 없었다.
3. **5구간 융합**: 네 맵의 요소를 단계별로 한 구간에 이어 붙이고 상단 체인·소멸 디딤돌을 섞은 구성이다. 레인이 교차하거나 서로의 요소가 겹치는 더 깊은 융합이 필요하면 알려 달라.
4. **몬스터·함정**: 요청에 없어 넣지 않았다. 각 맵의 몬스터·함정을 구간별로 가져올지 알려 달라.
5. **구간 경계의 점프 간격**(2.0~2.5)은 동선 길이에 합산하지 않았다.
