# 4-1 맵 설계 — 반시계 원형 동선 (11시 시작 → 12시 종료, 2-1 + 3-4 혼합)

2026-10-13 최초 설계, 2026-10-14 **시작을 11시, 종료를 12시로 재설계**. 나머지 조건(발판 22개, 동선 60 = 480유닛, 반시계, 이동형 6개, 함정 7, 몬스터 15)은 그대로다. 설계 코드와 배치 데이터만 갱신했다. **Unity 씬(Stage4)에 적용된 4-1은 재설계 전(6시 시작) 배치라서 다시 배치해야 한다**(아래 *Unity 적용 상태*).

## 요청과 해석

| 요청 | 적용 |
|---|---|
| 2-1 설계 + 3-4 설계 혼합 | 2-1의 발판 리듬(디딤돌·언덕, 간격 2.0~2.5)과 3-4의 발판 4종(일반·이동형·소멸형·피해형), 긴 직선 발판 + 이동형 구조 |

| 이동 경로 60 기준 | 규칙 15: 60 × 8 = **480 월드 유닛** |
| 반시계 원형 동선 | 접원에 접하는 팔각형 고리(접선 각 55°, 접원 반지름 67.40) |
| **시작 11시 → 종료 12시** | 시작 발판은 고리 왼쪽 위 모서리 V5(12시에서 반시계 방향으로 약 26°, 11시 방향). 종료 발판은 맨 위 가운데(12시, X = 0). 반시계로 약 330° 돌아 12시에 도착 |

## 이동형 발판 6개

- 경로 이동 거리: M1·M3·M4·M6 = 49.29, M2·M5 = 42.50. 모두 56(규칙 17) 이하. PingPong, 끝점 대기 0.4초.
- 속도는 동선 순서대로 6.0 / 6.5 / 7.0 / 7.5 / 8.0 / 8.5로 모두 다르고(규칙 23), 출발 지연은 0 / 0.7 / 1.4 / 2.1 / 2.8 / 3.5초로 모두 다르다(규칙 18). 규칙 21(대기 최소화)에 따라 3-4(약 3.5)보다 빠르게 잡았다.
- 이동형 중심은 모서리 발판 가장자리에서 7.5 떨어진 차선에 둔다(발판 가장자리와 이동형 가장자리의 간격 2.0).

## 데미지·소멸 발판

## 함정 7개 (3-4 절반: 투사체 5 + 텔레포트 2)

탄은 기존 `P_Trap_Projectile`(속도 14, 수명 2초 → 사거리 28, 피해 15), 예고 0.5초, 스위치 쿨다운 3초. 발사기는 공중 고정, 충돌체 없음. 하강 이동형은 정면으로 쏘면 발판 몸체에 먼저 닿아 탄이 사라지므로 탑승자 몸 높이에 맞춘 수평 발사로 했다.

## Unity 적용 상태 (재배치 필요)

- 2026-10-13에 `Stage4.unity`의 `Section_1/Generated_4-1`에 **재설계 전 배치(6시 시작, 발판 22개만)** 를 적용했다. 함정·몬스터는 적용하지 않았다. 4-2~4-4와 경계(+67 이동), 낙사 판정, 카메라 범위, Tiled 발판 이미지(`Platform_Stage4_Dungeon_Tiled.png`)는 새 설계에도 그대로 쓴다.
- 새 설계로 바꾸려면 `Tools/Deploy/Stage 4-1 배치`를 다시 실행한다(`DeployStage4-1.cs`는 JSON의 시작 기준 좌표와 `ring.bottom`으로 환산하도록 수정했다). 고리 맨 아래 접점은 월드 (1, 0)에 그대로 두므로 영역 크기·위치는 변하지 않고, 시작점/플레이어/종료점이 11시/12시 발판으로 옮겨진다.
- 함정(투사체 5 + 텔레포트 2)과 몬스터 15마리의 배치, 텔레포트 스위치 프리팹(`SwitchTeleportTrap`용)은 아직 없다.

## 확인이 필요한 사항

1. **11시 위치**: 시작 발판이 팔각형의 왼쪽 위 모서리라 12시에서 26° 지점이다(정확히 30°가 아님). 정확히 30°에 두려면 모서리 발판을 위쪽 변 쪽으로 옮겨야 하는데, 이동형 승강 위치가 바뀐다.
2. **종료 발판 폭**: 종료 발판은 2-1의 시작 발판 몫을 12로 넓힌 값이다. 2-1 원래 폭(4.0)을 유지하길 원하면 알려 달라.
3. **낙하**: 고리 안쪽이 비어 있고 높이가 약 135라 위쪽에서 떨어지면 아래까지 낙하한다. 낙하 시 처리(낙사 또는 텔레포트 추가)를 정해야 한다.
