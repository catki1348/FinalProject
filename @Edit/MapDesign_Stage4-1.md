# 4-1 맵 설계 — 반시계 원형 동선 (2-1 + 3-4 혼합)

2026-10-13 요청 기준. 설계 코드와 배치 데이터를 작성했고, 같은 날 Stage4 씬의 `Section_1`에 적용했다(아래 **Unity 적용 결과**). 플레이 검증은 하지 않았다.

## 요청과 해석

| 요청 | 적용 |
|---|---|
| 2-1 설계 + 3-4 설계 혼합 | 2-1의 발판 리듬(시작 발판·디딤돌·언덕, 간격 2.0~2.5)과 3-4의 발판 4종(일반·이동형·소멸형·피해형), 긴 직선 발판 + 연속 이동형 구조를 섞는다. |
| 할당된 발판의 절반, 소수점 이하 버림 | 종류별로 절반을 내림한다. 2-1 일반 6→**3**. 3-4 일반 17→**8**, 이동형 13→**6**, 소멸형 7→**3**, 피해형 5→**2**. 합계 **22개**. |
| 이동 경로 60 기준 | 규칙 15에 따라 60 × 8 = **480 월드 유닛**. |
| 시작점 기준 반시계 원형 동선 | 시작점은 원의 맨 아래 접점이다. 오른쪽 → 위 → 왼쪽(위쪽) → 아래 순서로 한 바퀴 돌고, 골인은 시작 왼쪽 30유닛 지점에 둔다. |

발판은 수평이라 곡선을 그대로 따라갈 수 없다. 그래서 **원에 접하는 팔각형 고리**로 원형을 만든다(접선 각 55°, 접원 반지름 67.40, 중심 (0, 67.40)). 평탄한 변(아래·위)은 정적 발판으로, 기울어지거나 수직인 변 6개(오른쪽 3·왼쪽 3)는 이동형 발판 6개가 이어 준다. 이동형 6개가 정확히 팔각형의 비수평 변 6개에 대응한다. 시작점은 원의 접점이다.

## 이동형 발판 6개

- 경로 이동 거리: M1·M3·M4·M6 = 49.29, M2·M5 = 42.50. 모두 56(규칙 17) 이하. PingPong, 끝점 대기 0.4초.
- 속도 6.0 / 6.5 / 7.0 / 7.5 / 8.0 / 8.5로 모두 다르고(규칙 23), 출발 지연 0 / 0.7 / 1.4 / 2.1 / 2.8 / 3.5초로 모두 다르다(규칙 18). 규칙 21(대기 최소화)에 따라 3-4(약 3.5)보다 빠르게 잡았다.
- 이동형 중심은 모서리 발판 가장자리에서 7.5 떨어진 차선에 둔다(발판 가장자리와 이동형 가장자리의 간격 2.0). 오른쪽·왼쪽 수직 변은 바깥쪽 차선, 사선 변은 진행 방향 쪽 차선을 쓴다.

## 적용 시 필요 사항 (Unity 미적용)

- 4영역 위치는 규칙 19에 따라 4스테이지의 1영역으로, 왼쪽부터 오름차순이며 규칙 12·16에 따라 겹치지 않게 오프셋을 정한다. 영역이 큰 편이라 카메라 범위와 낙사 판정(아래쪽)도 이 크기에 맞춘다.
- 발판 외형은 Stage4 던전 프리팹을 쓰고, 길이는 MapEdit의 발판 길이 조절 기준(Tiled, Scale (1,1,1))을 따른다.
- 이동형 중심 y는 3-1과 같이 윗면 − 0.25(JSON 경로 값에 반영). 모서리 발판 폭은 8(이동형 차선 기준 폭), 긴 발판은 고리 길이에 맞춰 늘린 값이다.

## 확인이 필요한 사항

1. **발판 22개**: 종류별 내림을 적용했다. 전체(6+42=48)의 절반으로 24개를 원하는 것이었다면 알려 달라.
2. **원형 표현**: 원에 접하는 팔각형 고리다. 이동형을 늘려 더 둥글게 하려면 발판이 22개를 넘는다.
3. **낙하**: 고리 안쪽이 비어 있고 높이가 약 135라 위쪽에서 떨어지면 아래 구간까지 낙하한다. 낙하 시 처리(낙사 또는 3-4식 텔레포트)를 정해야 한다.

### 스위치 투사체 5개
탄은 기존 `P_Trap_Projectile`(속도 14, 수명 2초 → 사거리 28, 피해 15), 예고 0.5초, 스위치 쿨다운 3초. 발사기는 공중 고정이고 충돌체가 없다.

| ID | 대상 | 방식 |
|---|---|---|
| T1 | M1 | 상승 사선 이동형의 탑승 경로 위(60% 지점)에 스위치, 위쪽 끝 너머에서 경로를 따라 정면으로 발사 |
| T2 | M2 | 수직 리프트 중간에 스위치, 위쪽 끝 위에서 아래로 발사 |
| T3 | V4 도보 | V4 왼쪽 끝 안쪽 1.5에 스위치, V5 오른쪽 끝의 발사기가 소멸 다리를 가로질러 수평 발사 |
| T4 | M4 | 하강 사선 이동형 위 스위치, 바깥(왼쪽)에서 탑승자 위치를 예측해 수평 발사 |
| T5 | M5 | 하강 수직 이동형 위 스위치, 바깥(왼쪽)에서 탑승자 위치를 예측해 수평 발사 |

하강 이동형은 정면으로 쏘면 발판 몸체에 먼저 닿아 탄이 사라지므로, 탑승자의 몸 높이에 맞춘 수평 발사로 했다.

### 검증 (스크립트가 생성 좌표로 재계산)
- 발사기 몸체가 어떤 발판·이동 경로와도 겹치지 않음. 탄이 사거리 안에서 다른 발판에 막히지 않음(대상 이동형 제외).
- 탑승자(이동형 위, T3은 걷는 플레이어) 이동을 시뮬레이션해 탄과의 최소 거리: T1 0.02 / T2 0.10 / T3 0.40 / T4 0.08 / T5 0.00, 모두 0.6 이내.
- 텔레포트 영역이 어떤 발판·이동 경로와도 겹치지 않고, 목적지가 발판 윗면이며, 모든 몬스터 영역이 텔레포트 영역에서 2 이상 떨어져 있음.
- 비행 몬스터 영역이 발판·이동 경로·탄도·다른 비행 몬스터와 겹치지 않음.
