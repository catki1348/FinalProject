# 3-5 화산 전갈 보스존 재설계

2026-10-14 · 설계 완료, Unity 미적용. 일반 5종·필살기 2종 설계를 기준으로 한다.

## 크기와 회피 성능 기준
`P_Boss_Stage3_VolcanicScorpion`의 Visual 배율 0.55, PPU 100, 이미지 캔버스 1536×1152를 기준으로 표시 캔버스는 8.448×6.336이다. 투명 여백까지 포함한 보수적인 예약 공간이며 실제 불투명 외곽선 크기와 구분한다. 몸체 콜라이더는 3×1.7, 중심 오프셋 (-0.6, 0.85). 루트와 Visual의 배율은 유지한다. 좌우 반전 때 콜라이더 X 오프셋도 방향에 맞춰야 한다.

`Player_Warrior` 프리팹 기준 이동 속도 8, 점프 초기 속도 9, 중력 배율 3. 콜라이더 폭 7.55×루트 배율 0.130208 ≈0.983, 높이 ≈1.286. 다른 플레이어·씬 오버라이드 적용 시 아래 수치를 다시 계산한다. 버프 없는 기준으로 중력 29.43, 점프 높이 약 1.376, 체공 시간 약 0.612초, 평지 수평 이동 약 4.893이다. 실제 입력 지연·접지 오차는 전투 검수에서 확인한다.

| 요소 | 재설계 |

| 영역 범위 | X 482~542, Y -308~-284, 중심 (512,-296) |
| 보스 루트 이동 범위 | X **491.3~532.7**, 바닥 Y -300 |
| 진입점 ★ | 발 접지 기준 (492,-300); 실제 루트 Y는 플레이어 발 피벗으로 환산 |
| 보스 시작점 | (520,-300), 진입 거리 28로 첫 화면의 즉시 공격 방지 |
| 종료점 ○ | 발 접지 기준 (535,-300), 처치 완료 후 생성·활성화 |
| 좌우 벽 | 안쪽 면 X 486 / 538, 높이 12 |
| 낙하 감지 | 중심 (512,-309), 64×2 |

기존 36 폭 바닥 대비 16을 추가한다. 중앙 전투 구간 498~526(28 폭), 양쪽 완충 구간은 각각 12 폭이다. 완충 구간은 이동·재진입 공간이며 공격 면역 지대가 아니다. 별도 낭떠러지·피해 바닥·추가 몬스터·상층 안전 발판은 두지 않는다. 한 장의 연속 평지로 모든 패턴을 관찰하고 회피할 수 있게 한다.

보스 루트는 벽에서 5.3 이상 떨어져 멈춘다. 캔버스 반폭 4.224+여유 1.076을 확보한다. 돌진은 목적지까지 루트 범위를 검사하고 남은 이동 거리만큼 감속한다. 뒤쪽 벽과 플레이어 사이에 보스를 끼우는 이동은 제한한다. 방향 고정·회복 시간은 기존 공격 계약을 따른다.

현 Stage3 파일의 Section_1~4는 X 방향으로 재배치되어 Section_2 중심 X486, Section_3 X587, Section_4 X629이다. 기존 3-5 중심 (-40,-56)은 현재 본선 아래 중앙과 어긋나므로 **(512,-296)**으로 재설계한다. 관찰된 다른 구간 최저 Y -266보다 새 존 상단 -284가 18 낮다. 적용 직전 실제 자식 오브젝트·플랫폼 bounds를 다시 검사한다. 3-4 종료는 새 진입점으로 명시 참조를 연결해 이동하며, 수백 단위 낙하나 점프로 연결하지 않는다.

맵 수칙의 이동 1초=설계 1 단위에 따라 바닥 폭은 52/8=6.5 설계 단위이다. 발판은 Scale (1,1,1), Tiled/Continuous, Full Rect 전용 용암 타일을 사용한다. BoxCollider2D는 52×1, autoTiling=false, 표면 Y -300을 맞춘다.

## 7종 패턴과 회피 공간
| 공격 | 공간 계약 | 보스존 대응 |
|---|---|---|
| 집게 연타 | 전방 2.8, 높이 2.3 | 점프로 넘기보다 준비 0.35초 동안 후퇴. 플레이어 2.8 이동 가능, 루트·플레이어 반폭을 판정에 포함 |
| 꼬리 찌르기 | 전방 4.2, 높이 1.15 | 후퇴 또는 점프. 점프 높이 여유는 0.226으로 작으므로 넓은 바닥에서 거리 회피도 보장 |
| 집게 내려찍기 | 전방 3.2, 높이 0.5 | 경고 뒤 점프 또는 3.2 밖으로 이동. 준비 0.8초 동안 6.4 이동 가능 |
| 꼬리 휩쓸기 | 전후 3.4, 높이 0.7, 유지 0.25초 | 플레이어 발 높이가 0.7 이상인 시간 약 0.429초. 0.25초 타격창 회피 가능; 벽 완충 구간에서도 후퇴 공간 제공 |
| 집게 돌진 | 4~9에서 선택, 최대 이동 4 | 별도 공격 상자 높이 **0.9 제안**, 몸체 콜라이더와 분리. 준비 0.75초에 6 이동 가능; 키 큰 몸체 전체를 피격 판정으로 삼지 않음 |
| 용암 탄막 | 선택 거리 4~14, 3발, 속도 8 | 장거리 조준·탄 사이 이동용 중앙 28 폭. 발사 방향은 확정 후 고정, 벽에 닿으면 소멸 |
| 지맥 폭발 | 좌우 2.5 간격, 준비 1.1초 | 경고 자리 고정, 폭 **0.9 제안**으로 줄여 빈 공간 **1.6** 확보 |

기존 분출 판정 폭 1.4에서는 안전 간격 2.5-1.4=1.1로, 플레이어 폭 0.983+여유 0.5=1.483보다 작다. 새 폭 0.9로 1.6을 확보한다. 경고 표식과 분출 이미지의 유효 폭도 0.9로 일치시킨다. 벽에서는 각 표식을 개별 clamp하지 않고 세 표식 묶음을 안쪽으로 평행 이동해 2.5 간격을 보존한다. 시작 때 계산된 위치를 유지하고 이동 후 플레이어를 다시 따라가지 않는다.

주의: 보스 몸체 높이 1.7은 점프 높이 1.376보다 크다. 몸통을 점프로 통과하는 회피를 강제하지 않는다. 돌진은 낮은 집게 타격 판정으로 피하고, 경로 바깥 이동도 가능하게 한다. 기존 몸체 충돌이 플레이어를 가로막는지, 공격창에서 겹침이 허용되는지는 적용 시 충돌 레이어와 함께 검수한다.

## 카메라와 진행
카메라 orthographicSize 10, Y -296. 전투 중 보스·플레이어 중점을 추적하고 바닥 양 끝을 벗어나지 않도록 clamp한다. 16:9 기준 보이는 폭 약35.56, 4:3 기준26.67. 14 거리+보스 캔버스 반폭4.224+플레이어 반폭0.492+양끝 여유4=22.716을 담는다. 더 좁은 종횡비에서는 해당 폭 이상이 보이도록 크기를 조정한다. 카메라 경계는 새 존과 함께 갱신하고 첫 진입 때는 플레이어를 추적한다.

진입→보스 인식 거리16 도달→전투 시작→체력0→공격·위험 요소 취소 및 사망→종료점 활성화→종료점 진입→Stage3 클리어→Stage4. 벽은 적절한 시점에 진입을 막되 종료점까지 접근할 수 있어야 한다.

## 적용 시 필요한 변경과 검수
현재 런타임 컨트롤러는 일반 2종·필살기 2종이며, 5+2는 설계·동작 시안 단계이다. 이 문서는 5+2 런타임 구현 완료를 의미하지 않는다. 기존 하드코딩 arenaLimits(-57,-23), groundY(-60), 기존 조립 코드의 -40 위치를 새 설정으로 갱신해야 한다. 재조립으로 과거 크기가 복원되지 않도록 생성 코드도 함께 바꾼다.

1. 모든 동작에서 발 접지·꼬리·집게가 벽 밖으로 나가지 않는지 확인.
2. 보스가 양쪽 벽에 있을 때 각 패턴의 무피해 회피 경로를 확인.
3. 분출 사이 1.6 폭·벽 쪽 묶음 이동·위험 예고 위치 일치를 확인.
4. 돌진의 벽 전 감속·높이0.9 판정·몸체 충돌과의 상호작용 확인.
5. 16:9·4:3 화면에서 보스·플레이어·최대14 공격 예고가 보이는지 확인.
6. 전체 Section_1~4 실제 bounds와의 비중첩, 새 진입 연결, 처치 후 Stage4 이동 확인.

설계 데이터는 `MapDesign_Stage3-5.json`, 영역 도식은 `MapPreview_Stage3-5.svg`. Unity 씬·프리팹·공격 코드는 이번 요청에서 변경하지 않았다.
