# 3-1 맵 설계 — 상하 반복 동선 (v4)

2026-10-12 요청 기준. 이전 v2의 거리 60·일방 상승·발판 개수·소멸 발판 추가 조건을 대체한다. 설계 코드와 배치 데이터 작성 완료. 2026-10-15 최신 설계를 Unity 씬에 반영했다. 전체 코스 플레이 통과는 미검증.

## 요청과 단위

- 동선: 오른쪽으로 진행하면서 상승 구간 5개와 하강 구간 5개를 교대로 배치한다. 각 구간은 연속 점프 3회로 구성한다.
- 이동 거리: 설계 척도 50 = 400 월드 유닛. MapEdit 규칙 15에 따라 플레이어 moveSpeed=8을 환산 기준으로 사용한다.
- 데미지 발판 10개, 움직이는 발판 10개, 발사체 함정 10개.
- 일반 발판 11개는 시작·골인·대기 공간으로 사용한다. 총 발판 31개, 함정은 발판과 별도 집계한다.

## 배치와 동선

순서: P00 일반(★) → [데미지 → 이동 → 일반] × 10 → P30 일반(○).

각 발판은 하나의 긴 수평 발판이며 직선 바닥을 여러 조각으로 나누지 않는다. 발판 간에는 반드시 점프해야 하는 빈 공간을 둔다. 높이 변화는 +0.9를 3회, -0.9를 3회씩 총 5회 반복한다. 최고 윗면 높이는 2.7, 시작과 골인은 높이 0이다.

| 구간 | 방향 | 시작 높이 → 끝 높이 |
|---|---|---|
| P00 → P03 | 상승 1 | 0 → 2.7 |
| P03 → P06 | 하강 1 | 2.7 → 0 |
| P06 → P09 | 상승 2 | 0 → 2.7 |
| P09 → P12 | 하강 2 | 2.7 → 0 |
| P12 → P15 | 상승 3 | 0 → 2.7 |
| P15 → P18 | 하강 3 | 2.7 → 0 |
| P18 → P21 | 상승 4 | 0 → 2.7 |
| P21 → P24 | 하강 4 | 2.7 → 0 |
| P24 → P27 | 상승 5 | 0 → 2.7 |
| P27 → P30 | 하강 5 | 2.7 → 0 |

좌표는 시작점을 기준으로 한 상대 좌표이며 Y는 발판 윗면이다. 루트 중심은 윗면보다 0.25 아래에 둔다. 두께 0.5. 상세 좌표는 MapDesign_Stage3-1_Placement.md, 정확한 값과 함정 좌표는 MapDesign_Stage3-1.json에 저장한다.

## 거리 정의

각 구간의 기준 길이는 400/30, 수평 간격은 sqrt((400/30)^2 - 0.9^2)이다. 모든 발판의 폭은 수평 간격 - 2.0로 정한다.

Σ sqrt(ΔX² + ΔY²) = 400 월드 유닛 = 설계 거리 50.

이는 이동 발판의 중립 위치에서 발판 윗면 중심을 잇는 기준 동선 길이다. 실제 점프 곡선, 대기, 발판 왕복, 회피에 따른 플레이어의 누적 이동 거리는 고정 50이 아니다. 발판 위 걷기와 점프를 포함한 실제 통과 시간도 50초로 보장하지 않는다.

## 움직이는 발판 10개

P02, P05, P08, P11, P14, P17, P20, P23, P26, P29.

각 발판은 중심 X의 -0.4~+0.4 사이에서 수평 왕복한다. 편도 0.8 월드 유닛(설계 척도 0.1), 속도 0.8, 끝점 대기 0.4초. 출발 지연은 순서대로 0, 0.35, …, 3.15초이다. 이동 범위는 MapEdit 규칙 17의 최대 56유닛 이내이며 서로 다른 출발 시점을 부여한다. PlatformPath와 MovingPlatform을 연결한다. JSON 경로는 절대 상대맵 좌표이므로 실제 배치 때 영역 오프셋을 더하고 기존 경로 좌표 방식에 맞춰 변환한다.

## 데미지 발판 10개

P01, P04, P07, P10, P13, P16, P19, P22, P25, P28.

DamageFoothold를 사용한다. 안전 2.5초 → 활성 1.5초, 첫 피해 지연 0.5초, 피해량 8, 피해 간격 0.5초. 순서별 cycleOffset을 0.3초씩 증가시킨다. 이전 일반 발판에서 안전 주기를 보고 진입하도록 한다. 상태와 피해 이펙트를 표시하고 기존 프리팹이 있으면 이를 사용한다.

## 발사체 함정 10개

T01~T10은 P00, P03, P06, P09, P12, P15, P18, P21, P24, P27에 각각 연결한다. 발판 오른쪽 끝에서 1.5유닛 안쪽에 스위치를 놓는다. 다음 데미지 발판의 왼쪽 끝보다 0.3유닛 앞, 양쪽 윗면 중 높은 곳보다 0.8유닛 위에서 왼쪽으로 발사한다. 발사기 몸체는 공중에 고정하고 점프 통로를 막는 충돌체를 두지 않는다.

기존 SwitchTrigger → ProjectileLauncher → TrapProjectile을 사용한다. 0.5초 발사 예고, 스위치 쿨다운 3초, 발사체 속도 6, 수명 0.8초, 피해량 8. 짧은 수명으로 해당 발판과 인접 점프 구간에 위험을 제한한다. 시작 위치는 P00 중앙이므로 시작 즉시 스위치에 닿지 않는다. 예고 후 이전 안전 공간에서 기다리거나 점프해 회피하도록 구성한다. 색 변화·경고음 참조, 발사체 프리팹과 지형 충돌 레이어는 실제 적용 시 연결하고 검사한다.

## 수치 검증과 적용 조건

Generate_Stage3-1.ps1을 실행해 동일한 설계 데이터를 재생성할 수 있다. 각 기능 주석과 생성 결과의 검증 코드를 포함한다.

- 상승 연속 구간: 생성 좌표의 높이 변화로 계산해 정확히 5개.
- 발판: 일반 11, 데미지 10, 이동 10. 같은 종류가 연속하지 않는다.
- 함정: 스위치/발사기 한 쌍을 함정 1개로 집계해 정확히 10개.
- 거리: 생성 좌표에서 재계산한 기준 동선 400/8 = 50, 오차 0.000001유닛 이내.
- 발판 간 공백: 중립 2.0, 이동 전 범위에서도 1.6~2.4유닛(MapEdit 규칙 14). 발판과 이동 경로는 겹치지 않는다.
- 점프: 현재 P_Player_HeroKnightTest 프리팹의 moveSpeed=8, jumpForce=9, gravityScale=3 기준으로 계산한다. 중력 29.43에서 최고 높이 약 1.376이며 +0.9 착지 시 하강 시점 수평 도달 약 3.888유닛. 최대 공백 2.4는 이 범위 안이며 점프 높이 80%(최고 1.10) 기준 도달 약 3.1에도 닿는다. 계산은 점프 가능성의 기하학적 검토이며 실제 조작·콜라이더·발사체 회피 통과는 플레이 검증이 필요하다.
- 영역 권장 범위: X=-10~골인X+10, Y=-8~12. 발판 전체와 이동 범위를 포함한다. 아래쪽에 낙사 판정을 둔다.
- Stage3에 적용할 때 3-1~3-4를 왼쪽부터 오름차순으로 두고 이 영역 경계가 인접 영역과 겹치지 않게 오프셋을 정한다. 3-5는 아래 단 중앙 유지. 카메라 범위·배경·시작/종료점·경계 트리거도 함께 맞춘다.
- Unity 실제 적용 시 공용 프리팹과 필요한 Inspector 참조를 연결하고 임시 테스트 씬에서 이동 발판 극점, 점프 도달, 데미지 주기, 함정 회피와 3-2 전환을 확인한다.
