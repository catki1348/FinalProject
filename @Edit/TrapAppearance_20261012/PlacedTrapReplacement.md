# 배치 함정의 테마 프리팹 교체 — 2026-10-13

Stage1~5를 조사했으며 실제 배치된 함정은 Stage3에만 있다. Stage3의 45개 오브젝트(스위치 20, 발사기 20, 스위치 연동 텔레포트 5)를 Stage3_Lava 프리팹으로 교체하고 씬을 저장했다.

- 기존 GameObject/행동 컴포넌트/콜라이더 ID를 유지하는 Unity 프리팹 교체·변환 API 사용.
- 부모, 로컬 위치·회전·스케일, 발사점 월드 좌표, 충돌 판정 보존.
- 외부 스위치, 텔레포트 목적지·구간·카메라, 쿨다운·예고·피해·효과음 설정 보존.
- 새 발사기에 기본 포함된 자식 스위치는 제거하여 기존 맵 스위치 수량을 유지.
- warningTarget은 실제 이미지 SpriteRenderer로 연결. 발사 방향에 맞게 외관 회전, 그림의 총구를 기존 발사점에 맞춤.
- 3-1용 투사체의 속도 6, 피해 8, 수명 0.8초를 보존한 용암 테마 투사체 변형 생성. 3-4의 기본 투사체는 기본 용암 테마 탄 연결.

## 검증

임시 Test984 씬에서 45개 모두 설정/참조/콜라이더/좌표 비교 통과. 저장 후 다시 로드했을 때 45개 프리팹, 필수 참조 누락 0. 앞/뒤/좌/우/위의 실제 맵 렌더를 확인했고 이미지의 배경 투명 처리와 발사 방향 표시가 정상이다. 2D 평면의 옆/위 시점은 보이지 않는 것이 정상이다. 검증용 씬/스크린샷은 정리했다.

실제 Stage3에도 동일한 검증을 거쳐 적용. Unity 콘솔 오류 없음. Play 모드의 피해/쿨다운/텔레포트 동작은 이번 작업에서 별도 실행하지 않았다.

백업: `@Backup/ThemedTrapReplacement_20261013/`. 실행 코드: `Assets/@Scripts/Editor/ReplacePlacedTrapsWithThemes.cs`. 다시 실행하면 이미 해당 테마 프리팹인 함정은 건너뛴다. Stage3-1 배치 생성기를 다시 실행하면 생성기가 구형 함정을 생성하므로 이 교체 코드를 재실행해야 한다.
