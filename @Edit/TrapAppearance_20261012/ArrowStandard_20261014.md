# 화살 함정 프리팹 표준 재구성

작업: OpenAI Codex (GPT-6), 2026-10-14.

## 새 표준

- 수직 정투영 이미지가 발사장치의 기본 외관이다. 원본 PNG는 변경하지 않았다.
- 기본 P_Trap_Launcher와 테마별 5개 발사장치를 재구성했다. 구형 Body/Barrel, 임시 도형과 중복 스위치를 제거했다.
- 구조: 루트 ProjectileLauncher + LauncherAppearance, 자식 FirePoint와 ThemedVisual. 기본 루트/FirePoint가 총구이고 이미지는 총구 뒤로 1.6 로컬 유닛 폭으로 배치된다.
- LauncherAppearance는 활성화 시 실제 발사점·방향·스케일에 외관을 맞춘다. 매 프레임 갱신하지 않는다.
- 발사장치 전용 M_LauncherOverhead 재질로 흰 배경을 제거한다. 다른 함정 재질은 기본 설정을 유지한다.
- 발사기 단품은 외부 스위치를 연결하는 모듈이다. 기본 단품은 용암 테마이며 다른 테마는 해당 테마 단품을 선택한다.
- 바로 배치할 수 있는 P_Trap_Arrow_Stage1_Forest ~ P_Trap_Arrow_Stage5_DemonCastle 세트 5종을 추가했다. 각 세트는 Switch/Launcher 중첩 프리팹과 내부 스위치 연결을 가진다.

저장 위치: `Assets/@ExternalAssets/@Prefab/Trap/Themed/<테마>/`.

## 기존 배치와 생성 코드

Stage1~5를 조사했다. 배치된 화살 발사기는 Stage3의 20개이며 모두 표준으로 갱신하고 저장했다. 기존 스위치 20개와 텔레포트 5개도 포함해 45개 오브젝트/50개 동작 컴포넌트를 비교했다.

루트 위치·회전·스케일, 부모, 스위치 연결, 탄 프리팹, 피해/속도/수명, 경고 시간, 텔레포트 목적지·카메라 연결을 유지했다. 발사점은 공통 FirePoint 자식으로 정리하되 기존 월드 발사 좌표를 유지했다. 이미지 총구를 발사점에 맞추고 오래된 Sprite/Material/색상 덮어쓰기를 정리했다.

DeployStage3-1.cs도 표준 스위치/발사기/탄 프리팹을 사용한다. 재배치 시 구형 스위치 그림이 발사장치에 다시 적용되지 않는다. BuildThemedTraps.Build() 역시 새 표준을 재사용한다.
