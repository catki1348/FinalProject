# 스테이지별 함정 외관 생성 결과

- 생성 서비스: https://3d.varco.ai/customWorkflow/fe151b90-92e9-4c56-bf67-f6aecbba9ef3
- 모델: Nano Banana Pro. 테마별 독립 Generate Image 노드 5개.
- 각 시트 구성: 스위치 / 발사기 / 투사체 / 텔레포트 장치.
- 스타일: 2D 판타지 픽셀 아트, 흰 배경, 오브젝트 분리.
- 모든 프롬프트에 4K resolution 요청을 포함했으나 실제 출력은 1024×1024.
- 외관 컨셉 시트이다. 일부 장치는 사선 시점이며 바로 사용할 투명 배경 스프라이트가 아니다. 용암 발사기의 룬은 문자처럼 보이는 부분이 있다.
- 원본 5개 PNG 및 Gallery.html 저장 완료. Unity 적용은 수행하지 않았다.
- 테마: Stage1 숲, Stage2 정글 유적, Stage3 용암, Stage4 마계 동굴, Stage5 마왕성.
