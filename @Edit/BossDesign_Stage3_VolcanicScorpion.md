# 3-5 보스 설계 — 화산 전갈 (Volcanic Scorpion)

작성일: 2026-10-07
상태: 설계 초안 확정. 이미지 생성, 스크립트 구현, Unity 적용 및 전투 검수는 미실행.

## 1. 적용 수칙과 범위
- LHS_Custumer.md의 공통 수칙 및 MapEdit.md의 보스존 진행 수칙을 적용한다.
- 사용자 지시: 보스는 일반 몬스터와 별도이다. Monster.md의 크기·스탯·패턴 규정은 적용하지 않는다.
- 기존 베이스의 검은 화산암 몸체, 주황 용암 균열, 두 집게와 발광 꼬리 침을 보존한다.
- 기준 이미지: Assets/Sprites/Bosses/Stage3_Lava/05_VolcanicScorpion_pixel.png
- 지정 워크플로우: https://3d.varco.ai/customWorkflow/49642cd6-4c2d-4dce-a5c2-88d90a5638d1
- 현재 워크플로우는 로그인 화면으로 연결되어 원본 노드 확인 및 생성이 불가능하다. 접속 복구 후 기존 베이스를 확인하고 생성한다.
- Unity 적용은 별도의 명시적 작업 지시에 따라 수행한다.
- 아래 수치는 초기 설계값이며 실제 전투 결과에 따라 조정한다.

## 2. 기본 동작
| 항목 | 설계값 |
|---|---|
| 체력 | 180 |
| 이동 속도 | 초당 2 Unity 단위 |
| 인식 거리 | 16 |
| 추적 정지 거리 | 2.4 |
| 보스 크기 | 집게·꼬리 포함 폭은 플레이어 약 3배를 초기 목표로 사용 |

상태: Idle, Walk, ClawCombo, TailSting, LavaVolley, GroundEruption, Hit, Groggy, Death.
우선순위: Death > Groggy > 진행 중 공격 > 사용 가능한 특수 공격 > 일반 공격 > Walk > Idle.
이동은 발판 위 좌우 추적을 기본으로 한다. 보스존 경계를 넘거나 낭떠러지로 이동하지 않는다.
공격 시작 시 방향을 고정하고 회복 동작까지 유지한다. 대기·이동 중에는 플레이어 위치에 따라 방향을 갱신한다.

## 3. 일반 공격 2종
| 모션 | 거리 | 준비 | 타격 시점 | 전체 길이 | 피해 |
|---|---|---|---|---|---|
| 집게 연타 ClawCombo | 2.8 이내 | 0.35초 | 0.35초 / 0.75초 | 1.2초 | 각 12 |
| 꼬리 찌르기 TailSting | 4.2 이내 | 0.65초 | 0.65초 | 1.4초 | 18 |

집게 연타: 앞 집게를 뒤로 당겼다가 전방으로 내밀고, 반대 집게로 한 번 더 공격한다. 몸체와 발 위치를 유지한다.
꼬리 찌르기: 꼬리를 높이 접어 준비한 뒤 전방 지면 가까이 침을 찌르고 회수한다. 집게 연타보다 길고 좁은 판정을 사용한다.
2.8 이내에서는 두 일반 공격을 번갈아 사용하며, 2.8 초과 4.2 이내에서는 꼬리 공격을 사용한다.
각 타격은 같은 대상을 한 번만 처리한다. 플레이어의 기존 무적 시간은 유지하므로 연타가 반드시 두 번 피해를 주지는 않는다.
회피: 집게 연타는 후퇴, 꼬리 찌르기는 점프 또는 사거리 이탈.

## 4. 특수 공격 2종
| 모션 | 거리 | 준비 | 발동 | 회복 | 피해 |
|---|---|---|---|---|---|
| 용암 탄막 LavaVolley | 4~14 | 0.8초 | 0.7초 | 0.8초 | 탄당 16 |
| 지면 분출 GroundEruption | 3~12 | 1.1초 | 0.4초 | 1.0초 | 분출당 22 |

용암 탄막: 꼬리 침이 밝아지고 용암탄 3개를 0.8 / 1.05 / 1.3초에 발사한다. 준비 종료 직전에 확정한 플레이어 위치를 기준으로 방향을 정하며, 발사 후 추적하지 않는다. 투사체는 보스 소유 판정을 가진다.
지면 분출: 두 집게로 지면을 누르고, 준비 시작 때 확정한 플레이어 발밑과 좌우 2.5 위치에 경고 표식을 표시한다. 1.1초에 세 지점이 동시에 분출한다. 위치는 보스존 발판 범위 안으로 제한하고 중복 지점은 하나로 합친다.
특수 공격은 번갈아 선택한다. 해당 공격의 거리 조건이 맞지 않으면 다른 사용 가능한 특수를 선택하며, 둘 다 불가능하면 일반 행동을 이어간다.
회피: 탄막은 탄 사이 이동·점프, 분출은 경고 표식 밖으로 이동.

## 5. 피격·그로기·사망
- 피해 판정은 기존 Boss 체력 구성과 연결한다. 일반 몬스터 방어 계산을 새로 적용하지 않는다.
- Hit 애니메이션 재생 시작 후 1초 동안 다음 Hit 애니메이션은 재생하지 않는다. 체력 감소는 계속 처리한다.
- Hit가 공격이나 그로기·사망 상태를 끊지 않도록 우선순위를 유지한다.
- 그로기는 기존 보스 방식에 맞춰 큰 단일 피해 20 또는 누적 피해 30을 초기 기준으로 사용한다. 구현 전 기존 Boss 이벤트의 실제 의미에 맞춰 연결한다.
- 그로기 길이 3초, 종료 후 재발동 유예 4초. 진입 시 공격 예약과 활성 투사체·분출·경고를 해제한다.
- 체력 0 시 Death를 한 번만 실행한다. AI·공격·피격·그로기 예약을 중단하고 공격 판정과 몸체 충돌을 해제한다.
- 사망 전용 동작: 집게 힘 풀림 → 다리 접힘 → 몸체 내려앉음 → 꼬리 침 소등 → 균열 빛 약화. 마지막 프레임을 유지한다.
- 3-5 종료점은 처치 이벤트로 활성화한다. 종료점 도달 시 스테이지 클리어 후 Stage4로 전환한다.
- Hit, Groggy, Death는 진입 직전 바라보던 방향을 유지한다.

## 6. 좌우 표시와 이미지 제작
모든 원본 프레임은 오른쪽을 바라보는 동일한 측면 시점으로 제작한다.
Visual 자식의 X 방향만 반전한다. Rigidbody2D 및 몸체 Collider가 있는 루트는 반전하지 않는다.
집게 타격 위치, 꼬리 발사 위치, 투사체 방향, 경고 표식과 판정은 같은 facingSign 기준을 사용한다.
Animator는 Visual의 스케일과 flipX를 애니메이션 키로 덮어쓰지 않는다.

| Idle | 4 | 1.0초 | O |
| Walk | 6 | 0.6초 | O |
| ClawCombo | 8 | 1.2초 | X |
| TailSting | 6 | 1.4초 | X |

총 보스 프레임 목표 53장. 별도 VFX는 용암탄·분출 경고·분출 효과.
공통 생성 프롬프트: 4K resolution, existing volcanic scorpion reference, game-ready pixel-art sprite, strict right-facing side profile, same body proportions and camera, consistent scale and ground contact, transparent background, entire claws and tail visible, no text, no border, no scenery.
프레임마다 행동과 시점을 덧붙인다. 생성된 알파·발 접지·집게·꼬리 방향을 확인하고 캔버스와 접지 피벗을 통일한다.
4K는 생성 요청 해상도이며 실제 출력 해상도는 결과 확인 후 기록한다.
워크플로우 Run All은 사용하지 않는다. 기준 프레임 승인 후 이를 참조하는 독립 노드를 병렬 실행하고 실패한 노드만 개별 처리한다.
Point 필터와 동일 PPU를 사용한다. 프레임별 임의 크기 조절로 몸체가 흔들리지 않도록 한다.
완성 검수는 공통 수칙 27의 다섯 방향 기준을 따르되, 2D 스프라이트 검수 방식과 충돌하면 사용자에게 적용 방법을 확인한다. 검수용 임시 캡처는 확인 후 삭제한다.

## 7. 사운드 지정 필드 설계
기존 BossSound의 battleBgm 및 sfxEntries(type, AudioClip[] clips)를 확장한다.
BossSfx의 기존 enum 순서는 유지하고 새 값은 끝에 추가한다. 기존 프리팹의 직렬화 값이 바뀌지 않게 한다.
각 필드는 독립된 클립 배열을 지정할 수 있으며 비어 있으면 무음으로 처리한다.

| 식별자 | 재생 시점 |
|---|---|
| Idle | 대기 주기의 지정 이벤트 |
| Walk | 발 접지 이벤트 |
| ClawWindup | 집게 연타 시작 |
| ClawStrike | 두 타격 시점 각각 |
| TailWindup | 꼬리 준비 시작 |
| TailStrike | 꼬리 타격 시점 |
| LavaCharge | 탄막 준비 시작 |
| LavaLaunch | 각 탄 발사 |
| LavaImpact | 투사체 충돌 |
| EruptionCharge | 분출 경고 시작 |
| EruptionBurst | 분출 발동 |
| Hit | 피격 애니메이션 시작, 1초 제한 적용 |
| Groggy | 그로기 진입 |
| Death | 사망 진입, 한 번 |

Groggy와 Death는 기존 BossSfx 값을 재사용한다. 나머지는 새 값으로 추가한다.
이동·대기 사운드는 매 프레임 호출하지 않고 애니메이션 이벤트 또는 정해진 간격으로 호출한다.
BossSound는 사운드 선택만 담당하고 실제 재생·볼륨·BGM 전환은 SoundManager가 담당한다.
Death 사운드는 기존 BossSound의 사망 이벤트 처리에서 한 번만 호출한다.
