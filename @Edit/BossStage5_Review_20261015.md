# 보스 5 수칙 및 설계 검수

검수·미리보기 제작: Codex (GPT-6), 2026-10-15 (KST).
원화·설계·기존 GIF 제작 표기: Claude Sonnet 5.5, 2026-10-15.

## 결과

조건부 확인. 기존 공격 8종/키포즈 19장을 활용한 로컬 HTML 미리보기를 생성했다. 신규 AI 이미지 생성이나 기존 원화 편집은 하지 않았다. 기존 이미지 제작 당시 워크플로우 사용 여부는 설계 문서의 자체 보고이며 이번 검수에서 독립 확인하지 못했다.

## 수칙 적용

LHS_Custumer.md 전체와 Monster.md를 검토했다. 한국어 보고(1), 기능 주석(40), 커밋·푸시 없음(46), 컨셉/프리뷰 분류(51), AI·날짜 기록(54), 이미지·애니메이션 프리뷰 제공(55)을 적용했다. Unity 작업은 하지 않았다(9·11). 3D 모델이 없는 2D 키포즈 작업이므로 Blender 5면 촬영과 모델/Prefab 복사 대상은 없다(27·34). 신규 워크플로우 이미지 생성이 없어 8·13·18·21의 실행 대상도 없다. 상태 확인용 스크린샷 파일은 만들지 않았다(22). 새 산출물은 3MB 미만(48). 기존 수칙과 설계 문서 자체의 “충돌 없음” 표기만으로 설계 통과를 판단하지 않았다.

## 발견 사항

1. **C5 연결 조건 모순**: N1→N4→N5에서 N5 직전은 기본 공격이 아닌 연계 N4다. 4.1절의 “기본 직후에만 연계”와 5절 규칙 2를 엄격히 적용하면 위반이다. 제안: C5를 N1→N3→N5로 바꾸거나 연계 뒤 연계 허용 여부를 명시한다. 원 설계는 변경하지 않았다.
2. **S2 높이 모순**: 중단 정의는 0.6~2.4인데 S2는 0~2.4로 두 분류에 걸친다. 중단을 유지하려면 0.6~2.4로 통일해야 한다. 판정은 구현하지 않았다.
3. **시간 표기/산출물 불일치**: 기존 GIF 매니페스트 합계 N2 0.90(설계 전체 0.85), N4 0.70(1.00), N5 0.90(0.95), S1 1.60(2.00), S2 1.40(2.40), S3 1.50(2.10)초. S2는 설계 타격 1.50초보다 GIF가 먼저 끝난다. N2의 준비/타격/전체 표기 의미도 불명확하다. 타격 시점과 회복 시간을 별도 정의한 뒤 재구성해야 한다. HTML은 기존 GIF를 그대로 표시하며 전투 타이밍 재현을 주장하지 않는다.
4. **N4 무적 설명 모순**: “둘째 타격이 무적에 막히지 않도록 0.65초”라는 설명은 첫 타격 0.35초와 피격 무적 1초 조건에서 성립하지 않는다. 같은 문단 후반의 “무적 중 둘째 미적용”을 기준으로 문구를 정리해야 한다.
5. **원화 비율·방향**: 전체 키포즈 시트에서 특수 준비 자세와 일반 자세의 신체 크기 차이, N5 회전의 정면에 가까운 자세를 확인했다. 고정 접지 캔버스만으로 동일 신체 비율이나 오른쪽 측면 조건을 보증하지 않는다. 검 끝 손상·세부 형태 변화는 클로드도 원 문서에 보고했다.
6. **4K**: 원 문서에 실제 생성 해상도가 4K가 아니라고 명시되어 있다. 2400×1600 정렬 캔버스를 4K 출력으로 표기하지 않는다.
7. **문서 최신성**: 상단에는 워크플로우 연결 후 제작 예정이라고 남아 있지만 10~11절은 제작 완료다. 상단 상태를 완료로 정리할 필요가 있다. Monster.md에 없는 보스 스탯 전면 비적용을 확정 규칙처럼 인용한 부분도 근거 보완이 필요하다.

## 검증과 범위

PNG 19장의 크기/알파 포맷과 공격 8종 파일 참조를 확인했다. 전체 키포즈 시트를 육안 확인했다. 미리보기는 기존 PNG/GIF를 재사용한 정적 HTML이며 전체 정지/재생 기능을 제공한다. 브라우저에서의 실제 재생과 Unity 전투·밸런스는 검증하지 않았다. 원 설계·이미지·매니페스트는 수정하지 않았다.
