## 아이템 효과와 UI

- 분노: **획득마다 공격력 정수+10**, 시간 만료·게임플레이 중첩 상한 없음. 장비와 방어 버프를 계산한 뒤 별도 가산한다.
- 분노 적용 범위: 4-3만. 4-4 진입·영역 이탈·실제 사망·씬 재시작 시 초기화. 가속은 기존 타이머를 유지한다.
- 가속: 중첩당 이동속도·대시거리·대시속도+5%, 대시대기시간−5%, 최대5중첩, 공유5초. 추가 습득은 타이머 갱신.
- HUD: 실제 가속 중첩·남은 시간 및 분노 중첩·공격력 보너스 표시. Stage3/4에 재사용 HUD 프리팹을 배치하고 플레이어 참조를 연결했다.
- 분노 아이템은 기존 가속 이미지의 붉은 틴트 변형이다. 전용 신규 원화나 음원 생성은 하지 않았으며 기존 획득음을 재사용한다.
- 기존 필드 아이템 전체 상한20개를 유지한다. 동시 대량 처치로 오래된 아이템이 제거될 수 있으므로 확정 드랍이 전부 획득을 보장하지 않는다.
- 공격 판정 버퍼를8→256으로 늘려 대량 처치 시8대상에서 잘리던 병목을 해소했다. 기존1몸체1회 피해 규칙은 유지했다.
- 분노 카운터는 long을 사용한다. 기존 int 피해 API의 한계에서는 공격력을 int.MaxValue로 포화시켜 음수 오버플로를 막는다.
