# 맵 설계 4-5 — 눈먼 동굴 괴수 보스존 재설계

작성일: 2026-10-14
상태: **Unity 적용 완료 (2026-10-14, 사용자 요청).** 적용 결과는 9절. 적용 중 실측으로 발판 높이를 바꿨고, 최종적으로 은신 지붕(밑면 1.5/윗면 2.0)이 되었다(10절).
대상: `Stage4.unity`의 `Section_5` / `P_Stage4_CaveArena.prefab`

## 1. 문제

현재 아레나는 바닥 20×1, 좌우 벽 2개의 단일 평면이다. 월드 20유닛은 플레이어 1초 이동 거리(8유닛) 기준 설계 크기 2.5뿐이다. 카메라 기본 `orthographicSize 4`에서는 화면 폭이 약 14유닛이므로 방 하나가 화면 1.4개 분량이다. 보스 이동·공격 설계 거리(아래)를 넣으면 공격 한두 번에 벽에 닿고, 점프·돌진·포효는 거의 쓸 수 없다.

## 2. 기준 수치 (월드 유닛)

| 항목 | 값 | 출처 |
|---|---|---|
| 플레이어 1초 이동 거리 | 8 | `MovingPlatform.PlayerSecondDistance` (MapEdit 15 기준 1.0) |
| 보스 걷기 | 2.0/초 | 보스 설계 2절 |
| 보스 표시 높이 / 몸 길이 | 약 3.3 / 약 3.5 | 보스 설계 2절, Visual 0.35 |
| 감지 거리 | 16 | 보스 설계 2절 |
| 근접 추적 정지 | 2.4 | 보스 설계 2절 |
| 발톱 베기 / 하단 휩쓸기 | 전방 2.6 / 3.6 | 보스 설계 3절 |
| 음파 포효 | 입 앞 6.5, 발동 2.5~7 | 보스 설계 3절 |
| 천장 낙석 | 발동 2.5~16, 폭 1.8 | 보스 설계 3절 |
| 점프 | 수평 최대 6, 최고 2.2, 발동 3.4~8 | 보스 설계 10절 |
| 돌진 | 경고선 8, 속도 7/초×0.9초 ≈ 6.3 전진, 발동 3.4~10 | 보스 설계 10절 |

플레이어 점프 높이는 Unity 실측으로 확정했다: `jumpForce 9`, 중력 배율 3 → 최고 높이 약 **1.39**(= 9² ÷ (2×9.81×3)). MapEdit 14(점프 성능 80%)로는 약 1.1까지가 안전한 도달 높이다. 처음 문서의 가정(점프 약 3.0)은 틀렸다.

## 3. 크기 산정

필요 폭 W는 다음을 동시에 만족해야 한다.

1. **감지·특수 거리**: 낙석(최대 16)이 의미 있으려면 양 끝에서 서로 16 이상 떨어질 수 있어야 한다. 보스 몸 길이 3.5와 양쪽 벽 여유 3씩을 더하면 16 + 3.5 + 6 = 25.5 이상.
2. **돌진 도망·회피 공간**: 보스가 방 중앙에서 돌진해도 플레이어가 한쪽으로 8 이상 후퇴할 수 있어야 한다. 반폭 ≥ 8 + 벽 여유 3 + 몸 길이 절반 약 2 ≈ 13.
3. **포효 뒤로 회피**: 보스 뒤로 돌아가 사거리 밖(7 초과)에 서려면 반폭 ≥ 7 + 몸 3.5 + 여유 3 = 13.5.
4. **점프 착지 여유**: 점프 도약 거리 6 + 착지 후 일반 행동 거리 3.4 → 반폭 ≥ 10.
5. **플레이어 접근 시간**: 플레이어가 감지 16까지 들어와 첫 특수(4초 후)를 보고 대응할 시간 확보.

반폭 13.5 이상이 필요하므로 W ≥ 27. 여기에 돌진 후 보스가 반대편 벽까지 전진해도 몸이 벽에 박히지 않는 여유, 낙석 목표 위치 다양성, 은신 지붕 2개를 넣을 간격(지붕 사이 포함)을 위해 **W = 48 (설계 크기 6.0)**로 정한다. 기존 대비 2.4배.

## 4. 확정 설계 (영역 로컬 좌표, 바닥 윗면 y=0)

| 구성 | 값 |
|---|---|
| 바닥 | x −24 ~ +24 (폭 48), 두께 1, 윗면 y=0. 하나의 긴 발판으로 만들고 길이 조절은 MapEdit 13의 Tiled 기준을 따른다 |
| 좌우 벽 | x = ±24.5, 높이 14. 점프 최고 2.2 + 보스 3.3 + 낙석 출현 3의 합보다 충분히 높게 둔다 |
| 은신 지붕 `Ledge_L`/`Ledge_R` | 폭 6, 두께 0.5, **밑면 y=1.5 / 윗면 y=2.0**, 중심 x = −12, +12. 플레이어(키 1.29)가 아래에 숨고, 천장 낙석은 지붕에 막힌다. 보스·플레이어는 옆·아래에서 통과하는 한 방향 지붕이며 `RockShelter` 표시 컴포넌트가 붙어 있다. 점프 최고 1.39로는 윗면에 올라설 수 없다 |
| 플레이어 시작 | x = −21 (왼쪽 끝 근처), 낙하 진입 후 왼쪽 바닥에 착지 |
| 보스 시작 | x = +18 (오른쪽 은신 지붕 폭 9~15 바깥), 플레이어와 39 떨어져 감지(16) 전에는 Idle |
| 보스 종료점 | 처치 후 활성화, x = +20 바닥 위 |
| 낙사 방지 | 바닥 아래 y = −10에 `OutOfBounds` 기존 방식 유지 |
| 카메라 구간 | `CameraBoundsZone.size` = (52, 18), `orthographicSize` = 5.5로 키워 화면 폭 약 19.6을 확보. 보스·플레이어 거리 16이 한 화면에 들어오게 한다 |

지붕 밑면 1.5는 플레이어 키 1.29보다 높아 아래에 들어가 숨을 수 있다. **지붕은 천장 낙석만 막는다.** 발톱 베기(높이 0.8~2.6)·하단 휩쓸기·포효(높이 2.2)·돌진 접촉(높이 0~0.9)은 지붕 아래에서도 맞는다. 돌진 접촉 높이를 0.9로 낮췄으므로 점프 정점(1.39)에서는 접촉 판정을 피할 수 있고, 폭 48에서 플레이어(8/초)가 돌진(7/초, 약 6.3 전진)보다 빨라 반대로 달려 피할 수도 있다.

## 5. 패턴별 검증

| 패턴 | 검증 |
|---|---|
| 걷기 추적 | 보스 2.0/초로 최대 거리 35를 다 가려면 약 17초. 점프·돌진이 조건 거리(3.4 초과)에서 간격을 줄이는 역할을 한다 |
| 발톱 베기 / 하단 휩쓸기 | 거리 2.4~3.4에서 발동. 벽 쪽 구석에 몰려도 보스 몸(3.5)이 벽 여유 안에서 멈추도록 정지 거리 2.4를 유지 |
| 음파 포효 | 발동 2.5~7. 양 끝 모두 반폭 24이므로 보스 뒤로 돌아 7 밖에 설 공간이 충분 |
| 천장 낙석 | 발동 2.5~16. 낙석 폭 1.8을 발밑에 확정. 아레나 전 구간이 유효 지면이라 대상 지면 탐색 실패가 거의 없다 |
| 점프 | 수평 6 이내 착지. 벽·발판 끝 앞에서 착지점이 짧아지는 기존 규칙 유지. 지붕 아래에 숨은 플레이어도 목표가 될 수 있음(낙석만 지붕에 막힘) |
| 돌진 | 경고선 8, 실제 전진 약 6.3. 플레이어가 반대로 달려 피하려면 뒤쪽에 6.3 이상의 공간이 필요하다. 구석에 몰리면 피할 수 없으므로 구석 몰림이 전투의 위험 요소가 된다(점프로는 회피 불가) |

## 6. 시간 기준 점검 (플레이어 속도 8/초)

- 돌진 경고 0.6초 동안 플레이어는 4.8 이동하고, 돌진은 이후 0.9초에 6.3 전진한다. 플레이어가 즉시 반대로 달리면 거리가 벌어진다(8/초 > 7/초). 1차원 아레나에서는 옆으로 피할 수 없고 점프로도 피할 수 없으므로, 보스 설계의 "점프 또는 옆으로 이동" 회피 문구는 실제와 맞지 않는다.
- 포효 사거리 7을 벗어나려면 플레이어는 약 0.9초 필요. 포효 준비 0.5초 + 1틱 1.0초 간격 안에 가능.
- 낙석 경고 후 0.8초에 낙하. 폭 1.8 밖으로 약 1~2 이동하면 되므로 6.4 이동 능력이면 충분.

## 10. 후속 변경 (2026-10-14)

### 돌진 접촉 높이 2.0 → 0.9
`BlindCaveHorrorController`의 돌진 접촉 상자를 높이 0~2.0에서 0~0.9로 낮췄다(길이 1.2, 피해 18 그대로). 플레이어 점프 최고 1.39이므로 정점 근처에서 점프하면 맞지 않는다. 임시 씬에서 접촉 판정만 시험했다: 바닥 위(발 0.0) 맞음, 낮은 점프(발 0.7) 맞음, 발 1.0과 정점 1.39는 맞지 않음. 보스 몸체 콜라이더(2×3)는 그대로라 점프로 보스를 넘어갈 수는 없고, 접촉 피해만 피한다.

### 은신 지붕과 천장 낙석
- `Ledge_L`/`Ledge_R`를 올라서는 발판에서 **지붕**으로 바꿨다. 밑면 1.5, 윗면 2.0, 폭 6, `RockShelter` 컴포넌트(`Assets/@Scripts/Boss/RockShelter.cs`) 부착. 플레이어 키 1.29로 아래에 숨을 수 있다.
- `BossCaveEffect`는 낙석 생성 시 목표 바로 위에서 `RockShelter`를 찾는다. 있으면 돌이 지붕 윗면까지만 떨어지고, 낙하 충격 상자가 지붕 윗면 위로 올라가 아래에 있는 플레이어에는 피해가 없다. 지붕 윗면에 서 있는 플레이어만 맞는다(점프로는 올라갈 수 없다). 낙석 목표 위치와 경고는 그대로라 보스가 헛공격을 하게 된다.
- 임시 씬 시험: 열린 바닥(맞음, 15=20−방어 5), 왼쪽 지붕 중앙(안전), 왼쪽 지붕 가장자리 안쪽 x=−5.4(안전), 지붕 바깥 0.6(맞음), 오른쪽 지붕 중앙(안전).
- 지붕은 낙석만 막는다. 포효·발톱 베기·돌진은 지붕 아래에서도 맞는다. 지붕 폭 6이므로 안전 구간은 지붕 아래 폭(경계에서 낙석 중심이 지붕 안일 때) 전체다.
- 점프로는 지붕 윗면에 올라설 수 없고(상승 1.39 < 2.0), 점프하면 머리가 한 방향 지붕을 통과해 지붕 위로 나온다.
