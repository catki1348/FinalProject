# 전체 스테이지 - 영역(1~5) 배치 레이아웃

> 이 문서는 사용자가 제공한 배치 다이어그램(1-1~1-4 가로 한 줄 + 낙사 영역 + 1-5 대형 보스존)을 기준으로,
> Stage1~5.unity에 실제로 적용한 Section 좌표를 기록합니다(MapEdit.md 규칙 1: 코드/문서 우선 기록).
> 이미 Unity에 적용 완료된 상태이며(사용자 명시적 요청), 각 영역 내부의 발판/배경/시작지점 등 세부 설계는
> 전혀 변경하지 않았습니다 — Section 컨테이너의 위치만 이동했습니다.

## 1. 레이아웃 규칙

- 1~4영역: Y=0 기준 가로 한 줄로 배치, 서로 겹치지 않도록 각 영역의 실측 콘텐츠 폭 + 15유닛 여백을 두고 순서대로 배치.
- 5영역(보스존): 1~4영역 행 아래로 충분히 띄워 배치(낙사 영역에 해당하는 수직 여백 확보). X는 1영역과 동일한 좌측 정렬.
- Boundary_N_N+1(구간 경계 트리거)은 해당 영역(N)의 이동량만큼 함께 이동해 새 위치에서도 두 영역 사이 여백에 위치하도록 함.

## 4. 기존 문서와의 정합성 참고

- `MapDesign_Stage1-2.md`, `MapDesign_Stage1-3.md`, `MapDesign_Stage1-4.md`에 적힌 Section 폭/좌표(예: "Section_2 폭 10.5유닛", "Section_3: x=90~128")는 이번 재배치로 **더 이상 유효하지 않습니다**. 각 영역 내부 좌표(로컬 기준)는 문서 그대로지만, Section 자체의 월드 위치가 바뀌었으므로 절대좌표를 참조하는 부분은 위 표를 기준으로 갱신해야 합니다.
- 각 영역의 배경(`Background_Forest`)이 영역 폭 전체를 덮는지 여부는 이번 작업 범위에 포함되지 않았습니다(기존에도 미해결로 언급된 사항).

## 5. 미해결 사항

- `Boundary_4_5`(4→5영역 전환)는 좌우 이동 감지 트리거인데, 1-5가 이제 행 아래에 위치해 "걸어서 진입"이 아니라 "낙사(추락)로 진입"하는 구조가 되어야 할 가능성이 있습니다. 이 트리거의 판정 방식(수평 속도 기준)을 그대로 둘지, 낙하 진입용으로 별도 처리할지는 별도 논의가 필요합니다(이번 작업 범위 밖).
