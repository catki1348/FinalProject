# MapEdit.md — 맵 제작 수칙

`LHS_Custumer.md`와는 별개로, 맵/스테이지 제작에 적용되는 수칙입니다.

1. 모든 맵 제작은 최초에 코드로 설계하고, 유니티 적용은 사용자에게 요청받은 경우에만 처리한다.
2. 컨셉 이미지를 등록하면, 해당 이미지에서 검은 선으로 표시된 부분을 플레이어가 실제로 이동하는 발판으로 정의한다.
3. 게임 설계상 스테이지는 총 5개이며, 하나의 스테이지는 1~5번 영역을 가진다.
4. 영역 표기는 `스테이지-영역` 형식을 따른다. 예: 1스테이지 1영역 → `1-1`, 2스테이지 2영역 → `2-2`.
5. 별표(★)는 해당 영역의 스타팅 지점, 원형(○)은 해당 영역의 골인 지점을 의미한다. 스타팅 지점에서 시작해 골인 지점에 도달하면 다음 영역으로 이동한다.
6. 각 스테이지의 5영역에는 별도로 보스존이 위치한다.
7. 영역 및 스테이지 이동은 플레이어가 종료점(골인 지점)에 도달하면 실행된다.
8. 5영역은 보스를 처치해야 종료점이 생성되는 구조로 한다.
9. 5영역의 종료점에 도달하면 해당 스테이지의 클리어 화면을 출력한 뒤 다음 스테이지로 넘어간다.
10. 5-5(최종 스테이지의 최종 영역)에서 종료점에 도달하면 엔딩 화면을 출력한다.
11. 해당 영역의 크기는 그 영역에 배치되는 모든 발판이 영역 안에 들어올 정도로 커야 한다.
12. 다른 영역을 침범하는 경우, 서로의 영역이 겹치지 않도록 위치를 조정한다.
13. 맵 설계 과정에서 발판을 직선으로 배치할 경우, 발판을 여러 개로 나눠 배치하지 않고 발판 하나의 길이를 늘려서 배치한다. 길이를 늘리는 2D 발판은 아래의 **발판 길이 조절 기준**을 반드시 적용한다.
14. 발판과 발판 사이의 거리는 반드시 캐릭터가 점프해야만 닿을 수 있는 거리여야 한다. 단, 플레이어 점프 성능(100%) 기준으로 난이도를 높이려고 특별히 설정한 구간이 아닌 경우, 점프 성능의 80% 정도로도 닿을 수 있는 거리로 설정해야 한다.
15. 플레이어 캐릭터가 1초간 이동하는 거리를 1로 잡고, 각 맵의 설계 크기를 1~100 사이로 나타낸다.
16. 설계한 맵을 유니티에 적용할 때, 각 맵들이 서로 겹치지 않도록 위치를 이동시킨다.
17. 이동형 발판의 최대 이동 거리를 제한한다. 플레이어 캐릭터가 1초간 이동하는 거리를 1로 잡았을 때, 이동형 발판의 이동 거리는 7을 초과할 수 없다.
18. 이동형 발판을 연속으로 배치하는 경우, 인접한 두 발판이 움직이기 시작하는 시점은 반드시 서로 달라야 한다.
19. 맵(영역)을 배치할 때는 왼쪽부터 오름차순(1영역, 2영역, 3영역, 4영역 순)으로 배치한다. 예외적으로 5영역만 기존 설계 수칙대로 1~4영역의 아래 단 중앙에 배치한다.
20. 이동형 발판이 연속해서 배치된 경우 이 발판들은 1쌍의 발판으로 인식해서 플레이어가 이동할 수 있게 플레이어의 점프 거리 내로 존재하는 구간이 반드시 존재해야 한다.
21. 플레이어 대기 시간을 최소화한다.
22. 시야 밖 가속에는 고정 배율을 요구하지 않는다.
23. 인접한 1쌍의 발판은 기본 속도 값은 무조건 다르게 설정 해야 한다.

## 발판 길이 조절 기준

2026-10-12 사용자 지시로 확정. 이후 모든 스테이지의 신규 배치, 재배치, 발판 길이 변경 및 자동 배치 코드에 적용한다. 3-1에서 확인한 Tiled 방식이 기본 기준이다.

- 발판 길이를 늘릴 때 `Transform.localScale.x`로 이미지를 늘리지 않는다. 발판의 Scale은 `(1, 1, 1)`을 기본으로 하고, 부모의 Scale로 외형이 늘어나지 않는지도 확인한다.
- `SpriteRenderer.drawMode = SpriteDrawMode.Tiled`, `tileMode = SpriteTileMode.Continuous`로 설정하고, `SpriteRenderer.size`로 설계한 폭과 두께를 지정한다.
- 원본 스프라이트는 `Mesh Type = Full Rect`로 설정한다. 양쪽 끝 모양을 보존할 필요가 있으면 Sprite Editor의 Left/Right Border를 지정해 가운데만 반복한다. Border는 스프라이트 데이터로 설정하며 이미지에 선을 그려 표현하지 않는다.
- 원본에 여백이 있거나 반복 시 빈틈이 생기면 발판 영역을 잘라 사용하거나 반복용 스프라이트를 별도로 준비한다. 기존에 사용하는 원본의 설정을 무조건 바꾸지 말고, 다른 발판에 영향을 주는 경우 전용 에셋을 사용한다.
- 콜라이더는 설계한 폭·두께·표면 높이를 유지한다. 3-1처럼 `BoxCollider2D.autoTiling = false`로 두고 `size`와 `offset`을 명시적으로 맞추는 방식을 기본으로 한다. Auto Tiling은 실제 충돌 영역이 설계와 일치하는 것을 확인한 경우에만 사용한다.
- 이동형·피해형 발판에도 동일한 외형 기준을 적용하며, 길이 조절 때문에 이동 경로·속도·피해 주기 등의 동작 설정이 바뀌지 않도록 한다.
- 자동 배치 코드에도 동일한 설정을 넣어 재배치 후 Scale 방식으로 되돌아가지 않게 한다.
- 저장 후 다시 확인하여 Scale, Tiled/Continuous, Size와 콜라이더의 일치 여부를 검증한다. 렌더링에서 무늬가 늘어나거나 반복 사이에 빈틈이 생기지 않는지 확인한다.
