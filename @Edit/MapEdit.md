# MapEdit.md — 맵 제작 수칙

`LHS_Custumer.md`와는 별개로, 맵/스테이지 제작에 적용되는 수칙입니다.

1. 모든 맵 제작은 최초에 코드로 설계하고, 유니티 적용은 사용자에게 요청받은 경우에만 처리한다.
2. 컨셉 이미지를 등록하면, 해당 이미지에서 검은 선으로 표시된 부분을 플레이어가 실제로 이동하는 발판으로 정의한다.
3. 게임 설계상 스테이지는 총 5개이며, 하나의 스테이지는 1~5번 영역을 가진다.
4. 영역 표기는 `스테이지-영역` 형식을 따른다. 예: 1스테이지 1영역 → `1-1`, 2스테이지 2영역 → `2-2`.
5. 별표(★)는 해당 영역의 스타팅 지점, 원형(○)은 해당 영역의 골인 지점을 의미한다. 스타팅 지점에서 시작해 골인 지점에 도달하면 다음 영역으로 이동한다.
6. 각 스테이지의 5영역에는 별도로 보스존이 위치한다.
7. 영역 및 스테이지 이동은 플레이어가 종료점(골인 지점)에 도달하면 실행된다.
8. 5영역은 보스를 처치해야 종료점이 생성되는 구조로 한다.
9. 5영역의 종료점에 도달하면 해당 스테이지의 클리어 화면을 출력한 뒤 다음 스테이지로 넘어간다.
10. 5-5(최종 스테이지의 최종 영역)에서 종료점에 도달하면 엔딩 화면을 출력한다.
11. 해당 영역의 크기는 그 영역에 배치되는 모든 발판이 영역 안에 들어올 정도로 커야 한다.
12. 다른 영역을 침범하는 경우, 서로의 영역이 겹치지 않도록 위치를 조정한다.
