# MapEdit.md — 맵 제작 수칙

`LHS_Custumer.md`와는 별개로, 맵/스테이지 제작에 적용되는 수칙입니다.

1. 컨셉 이미지를 등록하면, 해당 이미지에서 검은 선으로 표시된 부분을 플레이어가 실제로 이동하는 발판으로 정의한다.
2. 게임 설계상 스테이지는 총 5개이며, 하나의 스테이지는 1~5번 영역을 가진다.
3. 영역 표기는 `스테이지-영역` 형식을 따른다. 예: 1스테이지 1영역 → `1-1`, 2스테이지 2영역 → `2-2`.
4. 별표(★)는 해당 영역의 스타팅 지점, 원형(○)은 해당 영역의 골인 지점을 의미한다. 스타팅 지점에서 시작해 골인 지점에 도달하면 다음 영역으로 이동한다.
5. 각 스테이지의 5영역에는 별도로 보스존이 위치한다.
6. 보스를 처치하면 다음 스테이지로 이동한다.
