# 5-2 Unity 구현 완료

사용자의 “5-2 유니티에 구현해라” 지시로 `Assets/Scenes/Stage5.unity`에 실제 배치·저장했다. 설계 거리 75(600유닛), 5개 구간의 상대 좌표와 이동 경로/속도/지연을 유지했다. 5-2는 하나의 영역이다.

## 적용 내용

| 구성 | 구현 |
|---|---|
| 1-2 방식 | Z 점프와 교차 이동형 경로 |
| 2-2 방식 | 정글 짐 형태의 고정·이동·소멸 발판 |
| 3-2 방식 | 층별 하강, 승강·대각 이동, 점멸·피해 발판 |
| 4-2 방식 | 끊김 없는 질주 바닥, 0.5초마다 실제 체력 1 감소, 처치 회복·가속 |
| 융합 | 위 네 방식을 연결하고 마지막 질주는 왼쪽으로 반환 |
| 총 구성 | 발판 67 / 이동형 20 / 공중 몬스터 31 / 추락 띠 13 |
| 드롭 | 추격형 22마리는 매 처치 회복·가속 각각 100%, 혼합 비행 9마리는 기존 일반 드롭 |

시작 발판 윗면은 (532,0), 실제 스폰은 (532,0.03), 최종 발판 윗면은 (847.190,-142.184)다. 카메라는 X=501~916, Y=-152~10의 한 영역을 사용한다. 발판은 Scale 1, Tiled/Continuous, 명시적 콜라이더 크기를 유지하며 실제 저장 좌표·경로는 `Stage52_SavedStructure_20261015.json`으로 검증했다.

5-1은 아직 기존 임시 배치 상태이며, 이번 작업으로 그 콘텐츠를 구현했다고 간주하지 않는다. 기존 시작점 (1,0)과 발판 위치를 유지하면서 5-1 설계 공간 오른쪽에 5-2를 배치했다. 5-3·5-4와 경계는 X+851 이동, 5영역은 하단 중앙 (495.5,-210)으로 이동했다.

기존 넓은 추락 판정은 5-2의 정상 하강 경로를 잘라버리므로 5-1용으로 제한했다. 5-3·5-4 아래에는 별도 추락 판정을, 하단 5영역 아래에도 추락 판정을 배치했다. 새 추락 판정은 모두 기존 `P_OutOfBounds_Zone` 프리팹을 재사용한다.

전용 에셋은 GUID를 보존한 채 `Assets/@ExternalAssets/@Prefab/Stage5_2`로 승격했다. 원본 공용 PNG와 다른 스테이지 프리팹은 변경하지 않았다. 배치 메뉴는 **Tools → Deploy → Stage 5-2 Composite Map**이며, `PrepareStage52.Deploy`가 본 씬을 저장한다. 임시 준비 메뉴는 별도로 유지하며 본 씬 배포 없이 테스트 씬만 만든다. 본 씬의 WarpManager 테스트 값은 변경하지 않는다.
