중앙에 피라미드를 추가하여 총 3개를 배치했다. 각 피라미드는 5단, 아래부터 5·4·3·2·1개로 총 15개이며 영역 전체 발판은 45개다. 기존 단차 0.8, 폭 0.6, 두께 0.36과 잔디·흙·돌 단면을 유지했다.

사용자 후속 지시로 바닥 전체 폭 28을 3등분하고 각 구간 중앙에 피라미드를 균등 배치했다. 구간 폭은 9.333333이며, 로컬 경계는 −14 / −4.666667 / +4.666667 / +14다. 좌우 피라미드는 이전 중심 ±4.5에서 각 3등분 구간 중앙인 ±9.333333으로 이동했다. 인접 피라미드의 최하단 발판 외곽 사이 간격은 약 5.038로 서로 겹치지 않는다. 정삼각형의 밑변·빗변은 각각 약 3.695, 높이는 3.2다. 층 윗면은 바닥 기준 0.8·1.6·2.4·3.2·4.0이다.

`Generate_Stage1-5_Redesign.ps1`이 45개 좌표와 SVG를 생성한다. `DeployStage1BossRedesign.ApplyLayoutOnly()`는 기존 보스의 크기·머리 판정·하단 공격·애니메이션을 보존하고 아레나 원본 프리팹과 씬 발판만 갱신한다. 지면 전체 공격이 새 바닥과 표시기를 참조하도록 연결했다. 재배치 코드도 L/C/R 명칭과 45개 기준을 사용한다.
