# Monster.md — 몬스터 설계 수칙

`LHS_Custumer.md`와는 별개로, 몬스터 설계에 적용되는 수칙.

1. 몬스터는 체력(Health), 공격력(Attack), 방어력(Defense)을 기본 스탯으로 가진다. 공격력과 방어력의 기본값은 각각 10이다.
2. 몬스터의 행동 패턴은 몬스터 본체 스크립트에 하드코딩하지 않고, 별도의 패턴 스크립트로 구현한다. 몬스터마다 원하는 패턴 스크립트를 지정(연결)하여 서로 다른 패턴을 부여할 수 있어야 한다.
3. 스탯(체력/공격력/방어력)을 관리하는 스크립트와 패턴을 관리하는 스크립트는 서로 분리한다(`LHS_Custumer.md` 규칙 39, SRP).
4. 패턴 스크립트를 몬스터에 연결할 때는 `GameObject.Find` 등 계층 탐색을 쓰지 않고, Inspector 할당 또는 공통 인터페이스(예: `IMonsterPattern`)를 통한 참조로 연결한다(`LHS_Custumer.md` 규칙 40, 41).
5. 몬스터 인스턴스는 싱글톤으로 만들지 않는다(`LHS_Custumer.md` 규칙 39).
6. 몬스터는 전용 에셋(스프라이트/모델)이 들어와 외형이 확정되기 전까지, 사각형(Square) 오브젝트로 배치할 수 있도록 만든다. 이후 전용 에셋이 확정되면 외형만 교체한다.
7. 방어력은 받는 피해량에서 방어력 수치만큼 그대로 감소시키는 값이다(실제 피해 = 들어온 피해 - 방어력, 단 최소 1의 피해는 항상 적용).
