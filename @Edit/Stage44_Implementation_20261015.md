발판은 원본 공용 프리팹을 변경하지 않고 `Assets/@ExternalAssets/@Prefab/Stage4_4` 안에 폭8·폭12 변형을 저장했다. Scale1, Tiled/Continuous, Renderer와 BoxCollider 치수 일치를 유지한다. 149개 이음매를 하나의 물리 표면으로 합치고 발판이 낙하할 때 해당 BoxCollider 입력을 제거한다. 외형의 낙하 동작은 충돌이 없어서 플레이어를 받치거나 몬스터·아이템을 밀지 않는다. 전용 무마찰 재질을 사용한다.

## 검증 근거

- 저장 씬 재조회 구조 검사 **307개 통과**: 150개 프리팹 연결·Scale·Tiled·충돌 치수, 149개 이음매, 1200유닛 거리, 30마리, 영역 비중첩 등. `Stage44_Structure_20261015.txt`.
- 소유 임시 씬 **Test001**에서 제어된 런타임 검사 **16개 통과**. `Stage44_Runtime_20261015.txt`.
- 최대 가속 부여·일반 아이템 만료와 분리·네 가지 배율, t=0/1/3.4/150 낙하, 낮은 프레임 시 누락 없는 순서, 합성 충돌면에서 낙하 입력 제거, 일시정지, 일반 몬스터의 기본 공격 피해2회 사망, 종료·게임오버 시 효과 해제 등을 확인했다.
- 실제 PlayerMovement.FixedUpdate와 Physics2D.Simulate(0.02초)를 사용한 경로 검사에서 종료 트리거를 **119.94초**에 통과하고 4-5로 이동했다. 이 검사는 적의 Rigidbody.simulated를 꺼 지형과 이동을 분리했다. 전투2타 검사는 실제 검 충돌이 아닌 기본 공격력의 TakeDamage 호출이다.
- 씬 재시작 경계에서 150개 발판과 Manager의 초기 상태 복구 확인. 새 시도는 기존 씬 재로드 흐름을 따른다.
- 최종 Unity Console 오류·경고 **0건** 확인.
- 정면·후면·좌측·우측·상단을 포함한6방향과 정면 상세 화면을 검수했다. 2D 맵이므로 측면·상단은 평면 에셋의 두께 확인 용도다. 검수 스크린샷 파일은 확인 후 삭제했다.
- Test001 및 .meta 삭제, 기존 Test000 보존, Stage4 씬으로 복귀했다. 본 씬을 테스트용으로 실행·변경하지 않았다.

직접 조작으로 적을 처치·회피하는 전체 완주, 실제 점프·대시·피격 난이도는 남은 검증이다. API 물리 검사를 직접 플레이 완료로 표현하지 않는다.
