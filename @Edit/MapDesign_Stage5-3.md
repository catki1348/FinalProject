# 5-3 맵 설계 — 계승과 융합: 분노의 공중 회랑

상태: **설계 완료 / Unity 미적용**. 사용자 최종 지정 이동거리 **75**를 적용한다. 최초 50 지시는 75로 대체한다.

5-1의 ‘각 스테이지 1영역 계승 + 융합’, 5-2의 ‘각 스테이지 2영역 계승 + 융합’ 구성을 이어서 **1-3 → 2-3 → 3-3 → 4-3 → 네 방식의 융합**으로 구성한다. 구간별 수량·속도·함정 밀도는 아래 초안이며, 원본 맵 전체를 같은 비율로 축소하지 않는다.

## 거리와 연결

- 5구간 × 거리15 = **75**, 기본 속도8 환산 **120×5=600유닛**.
- ★=(0,0), ○=(582.124,11.400). 모든 좌표는 ★ 기준, Y는 발판 윗면이다.
- 구간 연결 K를 공유한다. 구간 시작 기준점 → 다음 발판의 탑승 끝점 → 이동형 경로 → 다음 발판 기준점을 순서대로 잇는 **설계 기준선**을 측정한다. 이동형은 왕복 중 진행에 필요한 편도만 센다.
- 긴 질주 바닥은 시작 기준점부터 종료 마커까지 잰다. 연결 점프도 해당 다음 구간 거리에 포함한다. 구간 경계에서 거리를 제외하거나 중복 합산하지 않는다.
- 공중 포물선, 발판 왕복 대기, 아이템 수집 우회는 기준 거리에서 제외한다. **75초 완주 보장이 아니다.** 5-1의 혼합 거리 정의 대신 재계산 가능한 단일 경로 기준을 사용한다.
- 한 영역 안에 5구간을 연속 연결하며 중간 K는 영역 전환이나 자동 체크포인트가 아니다. ○ 도달 시 5-4로 이동하고 보스는 5-5에 둔다.

| 구간 | 계승 원본 | 거리 | 핵심 흐름 |
|---|---|---:|---|
| P1 | 1-3 | 15 | 승강 → 대각 하강 → 지그재그 등반 → 점프 회랑 |
| P2 | 2-3 | 15 | 5점 파형 이동형 2개, 탑승 중 비행 적 대응 |
| P3 | 3-3 | 15 | 화살 이후 특수 발판, 텔레포트 회피 |
| P4 | 4-3 | 15 | 일반 바닥 위 5→10→15마리, 분노·가속 질주 |
| P5 | 융합 | 15 | 승강·5점 경로 전투·화살+피해 발판·분노 마무리 |

## P1 — 리프트 계승

일반 발판 사이에 이동형 4개를 둔다. 수직4 상승(속도3.2) → 대각(오른쪽14, 아래4, 속도4.2) → 수직1.6 상승(1.8) → 수직1.6 상승(2.0). 출발 지연은 0/0.35/0.5/1.0초, 끝점 대기는 0.25초다.

1-3의 연속 리프트에서 발견된 좁은 갈아타기 타이밍을 고려해 두 짧은 승강기 사이에 **일반 발판**을 둔다. 높이 차는 탑승 지점 기준 최대 +0.6으로 제한하고 승하차를 독립적으로 판단하게 한다. 강제 점프 성능 상향으로 해결하지 않는다. 마지막은 폭4의 독립 점프 발판을 거쳐 연결 K로 이동한다. 몬스터·함정은 두지 않아 탑승 규칙을 먼저 읽게 한다.

## P2 — 5점 경로와 동선 전투

2-3의 ‘일반 발판 + 5개 이상 경유점을 가진 이동형 + 플레이어 동선의 몬스터’를 계승한다. 이동형 2개의 경로는 각각 **(0,0)→(5,1.5)→(10,-1.5)→(15,1.5)→(20,0)**, 속도5.0/5.5, 지연0.4/0.8, 끝점 대기0.25초, PingPong이다. 각 이동형 사이에는 폭5 일반 발판을 둔다.

각 경로의 중간 경유점 3곳 위에 비행 경로형을 1마리씩, 총 **6마리** 배치한다. 중력0, 경유점 중심 기준 Y+2에서 접근하는 짧은 경로로 설정하고 플레이어가 탄 발판에 억지로 지상 몬스터를 고정하지 않는다. 해당 이동형 도입 시 한 번 활성화하며 기존 일반 몬스터 드롭을 사용한다. 몬스터 실제 경로·공격 높이·드롭 획득 가능성은 적용 때 조율한다.

## P3 — 함정 회랑

화살 스위치 일반 발판 → 특수 발판을 4번 반복한다. 특수 순서는 **피해 → 점멸 → 수평 이동 → 피해**. 스위치는 발판 오른쪽 끝에서1.5 안쪽, 다음 특수 발판 방향으로 발사한다. 예고0.5초, 쿨다운3초, 화살속도6, 수명0.8초, 피해8의 원본 기준을 사용한다. 발사점은 다음 발판 왼쪽 끝보다0.3 앞, 양쪽 윗면 중 높은 곳+0.8이다.

- 피해 발판: 안전2.5초/활성1.5초, 첫 피해 지연0.5초, 피해8, 간격0.5초, 시차0.3초씩. 4-2식 지속 피해 바닥과 구분한다.
- 점멸: 켜짐2초/꺼짐1초. 수평 이동형: 경로4, 속도2.4, 지연0.7초, 끝점 대기0.25초.
- 후반 일반 발판 2곳(폭6)에 텔레포트 마법진을 하나씩 둔다. 화살과 발판을 공유하지 않는다. 폭0.8의 중앙 센서, 피해0, 쿨다운3초, 목적지는 **5-3 시작점**이다. 점프로 센서를 넘어 피할 수 있어야 한다.
- 원본 텔레포트30개를 그대로 옮기지 않고 영역당 권장 범위인 **2개**로 축소한다. 두 센서는 전체 거리의1/4 이후다. P3에서 실패하면 P1/P2를 다시 지나므로 패널티가 크다. 적용 시 회피 가능성을 먼저 검증한다.

## P4 — 분노의 질주

연결 K 뒤로 끊김 없는 **일반 바닥 하나**를 잇는다. 피해 바닥·구덩이는 없다. 120유닛을 40씩 세 전투 구간으로 나누어 추격형 **5→10→15마리**, 총30마리를 배치한다. 구간 시작선을 처음 통과할 때 한 번 활성화하고 생존 적은 유지한다. 반복 리젠은 없다.

각 적은 사망 위치에 **분노1개+가속1개 각각100%** 드롭한다. 확정 회복은 두지 않는다. 분노당 공격력 정수+10, 효과시간·게임플레이 중첩 상한 없음. 가속은 기존5중첩/공유5초 규칙을 사용한다. 후반 적 체력을 누적 공격력에 비례해 올리지 않아 대량 처치 보상을 유지한다. 초기 체력은 기준 장비2타, 분노 누적 후1타를 목표로 실제 피해 계산에서 정한다.

**이번 계승 설계의 확장 제안:** 분노 유효 범위를 5-3 전체로 추가한다. 현재 구현은 4-3 전용이므로 아이템을 복사하는 것만으로 동작하지 않는다. 5-3 진입·사망·재시작 때 분노0, P4→P5에서는 유지, 5-4 진입·영역 이탈 때 초기화하도록 적용 조건과 HUD를 확장해야 한다. 4-3에서 얻었던 중첩을 가져오는 방식은 아니다. 가속은 기존 타이머를 따른다.

## P5 — 융합

① 수직4 상승 리프트(1-3) → ② 5점 파형 이동형과 비행 경로형3마리(2-3) → ③ 화살 스위치 다음 피해 발판(3-3) → ④ 일반 바닥에서 **3→5→7마리**, 총15마리 처치(4-3) → ○.

P4에서 얻은 분노는 리프트와 함정을 지나는 동안 유지된다. 가속은 5초가 지나면 만료될 수 있으며 마지막 처치로 다시 쌓는다. 함정에서 기다리는 동안 분노까지 잃는 구조는 사용하지 않는다. 마지막 질주 바닥은 진입대를 합쳐 약66.855유닛으로 한 발판이며, 몬스터는 분산 배치하고 세 진입선에서 한 번씩 활성화한다. 융합 구간에는 추가 텔레포트를 두지 않는다.

총 몬스터 **54마리**(P2 6 + P4 30 + P5 18), 그중 분노 확정 드롭45마리. 전부 획득하면 공격력 보너스+450이지만 이는 보상 예시이며 상한이 아니다. 일반 비행형9마리는 기본 드롭을 사용한다. 아이템은 사망 위치에 생성하고 자동 획득하지 않는다. 기존 필드 상한20개에 따라 동시 대량 처치 때 잔여 아이템이 소멸할 수 있으므로 획득률은 별도 플레이 검증한다.

## 배치 및 구현 기준

- 발판 **45개**: 정확한 상대 좌표·폭·경로는 `MapDesign_Stage5-3_Placement.md` 및 JSON 참조. 함정7개(화살5/텔레포트2).
- 독립 발판 사이 가장자리 공백은2.4. 고정 발판은 평지 또는+0.6, 기본 점프 성능80% 도달을 목표로 한다. 이동형은 승하차 끝점에서 이 간격을 맞춘다. 실제 이동 중 목표가 달라지므로 좌표상 간격만으로 착지를 보장하지 않는다.
- 이동형 경로끼리 직접 이어지는 쌍은 없다. 이동형 최대 편도 경로는 약22.104로 거리 한계56 이내다. 모든 경로는 발판 외부의 독립 오브젝트로 연결한다.
- 발판 Scale1, Tiled/Continuous, 명시적인 BoxCollider2D 크기·offset, autoTiling=false. 긴 바닥을 짧은 발판 여러 개로 쪼개지 않는다. P3 종료 K→P4, P5 최종 진입대→질주 바닥은 동일 높이로 맞닿아 연결되는 일반 바닥이므로 설계 데이터에서 각각 하나의 긴 일반 발판으로 합쳤다. 논리 마커와 거리 기준은 유지한다.
- 영역 제안 상대 X=-10~600, Y=-12~25. 월드 위치는 현재5-2 오른쪽 경계 이후에 전체를 평행 이동해 정하고 기존5-4와5-5 카메라·경계·낙사선의 비중첩을 검사한다. 기존 씬의 경계 좌표를 이 설계로 확정하지 않는다.
- 전체가 오른쪽으로 전진하는 구조라 깊은 층을 겹쳐 건너뛰게 만들지 않는다. 전폭 낙사선 Y=-8 제안. 승강 경로·몬스터 경로와 교차하지 않아야 한다.
- 재시작 때 몬스터·활성화 플래그·드롭을 초기화한다. P3 텔레포트는 재시작이 아니므로 처치한 적을 되살리거나 보상을 재생성하지 않는다.

## 검증과 남은 확인

`Generate_Stage5-3.ps1` 실행으로 데이터와 배치표를 재생성한다. 생성 좌표의 기준점들을 독립 재합산해 **120×5=600**, 이동형 경로 한계, 함정 발판 비공유, 발판 전체 이동 범위의 보수적 사각형 겹침0을 확인했다. 정적 접합면은 허용한다.

아직 수행하지 않은 검증: 이동형 접근 시점별 점프·착지, 화살/마법진 회피, 비행 적의 실제 동선, 분노 적용 범위 확장, 가속·공격 중 이동에 따른 난도,5-2→5-3→5-4 전환, 실제 씬 영역 비중첩과 전체 연속 완주. 기본 이동 환산75초에 승강·전투·대기가 더해지는 구성이며 플레이 시간은 실측 후 정한다. 이번 산출물은 설계 코드와 데이터이며 본 게임을 변경하지 않았다.
