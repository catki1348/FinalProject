---
description: 현재 진행 중인 작업을 요약해 HANDOFF.md에 저장 (다른 PC에서 이어서 작업하기 위함)
---

지금까지의 대화와 작업 내용을 바탕으로, 다른 PC에서 이 세션 없이도 작업을 이어갈 수 있도록
프로젝트 루트의 `HANDOFF.md` 파일을 새로 작성(덮어쓰기)하라.

파일에는 다음 항목을 포함할 것:

1. **작성 시각** (예: 2026-09-16 14:30)
2. **현재 목표** — 지금 무엇을 하려고 하는지 한두 문장
3. **진행 상황** — 지금까지 완료한 것 (완료된 파일/기능 위주로, 불릿 리스트)
4. **다음 할 일** — 이어서 해야 할 작업 (구체적인 순서가 있으면 순서대로, 불릿 리스트)
5. **중요 결정/맥락** — 왜 이렇게 하기로 했는지, 시행착오, 주의할 점 (있는 경우만)
6. **관련 파일 경로** — 이번 작업과 관련된 주요 파일/디렉터리 목록
7. **커밋되지 않은 변경사항 여부** — `git status`로 확인해서, 커밋 안 된 변경이 있으면 그 목록을 적어둘 것 (이 명령은 git add나 commit을 하지 않는다 — 파일만 작성한다. 커밋은 사용자가 원할 때 직접 한다)

간결하게 작성하되, 다른 PC에서 이 파일만 읽고 새 세션을 시작해도 맥락을 파악할 수 있을 정도로 충분히 구체적으로 쓸 것.
기존 `HANDOFF.md`가 있다면 내용을 덮어써서 최신 상태로 갱신한다.

작성이 끝나면 git add나 commit은 하지 말고, 파일 경로만 알려줘라. 커밋은 사용자가 직접 원할 때 진행한다.
